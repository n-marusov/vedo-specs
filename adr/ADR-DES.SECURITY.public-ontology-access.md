# ADR-DES.SECURITY.public-ontology-access

**Дата:** 2026-05-13  
**Статус:** Принято

## Контекст

VEDO Publisher публикует онтологии для внешнего просмотра. Требования:
- Только публичный доступ (без авторизации)
- Только 2D/3D навигация и полнотекстовый поиск
- Интеграция с внешними системами НЕ планируется

## Требование-источник
- [organization-access-model.md](requirements/REQ-NFR.SECURITY.organization-access-model.md)

## Решение

Предоставить публичный просмотр опубликованных онтологий без аутентификации через Browse UI, который обращается к Public Browse API с изолированным read-only Neo4j.

Простой доступ без login для внешних пользователей (открыл ссылку — видишь онтологию) в сочетании с полной изоляцией от рабочей онтологии, rate limiting, allowlisted read endpoints и XSS/CSP-защитой обеспечивает безопасность публичного периметра без избыточности OAuth2 для read-only сценария.

Browse UI доступен по публичной ссылке без login; только GET-запросы через Public Browse API с allowlisted endpoints; Public Neo4j изолирован, не содержит служебных данных и не опубликован во внешнюю сеть.

## Рассмотренные альтернативы

| Альтернатива | Причина отклонения |
|--------------|--------------------|
| OAuth2/OIDC для внешних пользователей | Избыточно для read-only навигации |
| Token-based доступ | Не запрошено, усложняет UX |
| SPARQL endpoint | Не планируется интеграция с внешними системами |
| Прямой доступ Browse UI к Public Neo4j | Раскрывает протокол/credentials БД и не даёт централизованного rate limiting/query limiting |

## Последствия

**Положительные последствия:**
- Простой доступ для внешних пользователей: открыл ссылку — видишь онтологию
- Нет необходимости создавать аккаунт
- Полная изоляция от рабочей онтологии

**Отрицательные последствия:**
- Ограниченный функционал (только навигация и поиск)
- Публичная ссылка потенциально может быть распространена
- Public Browse API требует отдельного мониторинга и защиты от злоупотреблений

**Меры снижения рисков:**
- Rate limiting на уровне Public Browse API
- Публичный Neo4j не содержит персональных данных или служебной информации
- Public Browse API не принимает произвольный Cypher/SPARQL, а формирует запросы только из внутренних шаблонов
