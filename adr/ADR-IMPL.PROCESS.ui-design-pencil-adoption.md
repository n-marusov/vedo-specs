# ADR-IMPL.PROCESS.ui-design-pencil-adoption

**Дата:** 2026-05-09  
**Статус:** Принято

## Контекст

Необходимо выбрать инструмент для создания wireframes, прототипов и дизайн-спецификаций.

## Требование-источник
- [ui-design-tool.md](requirements/REQ-CON.STACK.ui-design-tool.md)

## Решение

Принять Pencil.dev как единый инструмент для создания wireframes, прототипов и дизайн-спецификаций.

Pencil.dev предоставляет низкопороговый командный инструмент для проектирования UI, экспорт в .pen-формат и нативную интеграцию с рабочим процессом HLV, что обеспечивает прозрачность дизайн-решений для всей команды.

Все UI-проектирования выполнять в Pencil.dev, спецификации хранить в репозитории вместе с кодом.

## Последствия

- Простой инструмент для командного проектирования
- Экспорт в .pen формат
- Интеграция с рабочим процессом HLV
