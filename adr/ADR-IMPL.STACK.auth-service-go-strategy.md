# ADR-IMPL.STACK.auth-service-go-strategy

**Дата:** 2026-05-09
**Статус:** Принято

## Контекст

Auth Service — HTTP сервис без состояния для OAuth, JWT, прав доступа. Должен обрабатывать high request rate, быть horizontally scalable.

## Требование-источник
- [backend-service-stack.md](requirements/REQ-CON.STACK.backend-service-stack.md)

## Решение

Реализовать Auth Service на Go с простыми HTTP-обработчиками и JWT-библиотеками.

Go обеспечивает высокую пропускную способность HTTP-точек доступа без состояния и лёгкое горизонтальное масштабирование — достаточно для high-rate auth-запросов без избыточной сложности Rust или медленной обработки Python.

Спроектировать сервис без состояния для простого масштабирования; предусмотреть расширяемость для новых OAuth-провайдеров.

## Рассмотренные альтернативы

- **Rust** — overkill для простых JWT операций
- **Node.js** — достаточно для I/O-bound auth, но goroutines предпочтительней
- **Python** — медленнее для high-throughput точек доступа auth

## Последствия

- Простой, читаемый код для security-critical компонента
- Быстрая скорость запросов
- Легко добавить новые OAuth providers
- Дизайн без состояния = простое горизонтальное масштабирование
