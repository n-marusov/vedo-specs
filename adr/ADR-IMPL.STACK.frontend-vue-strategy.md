# ADR-IMPL.STACK.frontend-vue-strategy

**Дата:** 2026-05-09  
**Статус:** Принято

## Контекст

Необходимо выбрать стек для клиентской части VEDO Core — веб-платформы для редактирования онтологий.

## Требование-источник
- [frontend-stack.md](requirements/REQ-CON.STACK.frontend-stack.md)

## Решение

Использовать Vue 3 (Composition API, TypeScript) с Apollo Client для управления состоянием на основе GraphQL.

Vue 3 обеспечивает низкий порог входа для команды и реактивность через встроенные ref/reactive, а Apollo Client предоставляет нормализованный кэш, cursor-пагинацию и встроенную работу с GraphQL — идеальное сочетание для навигации по вложенным данным онтологий.

Локальное UI-состояние управлять через Vue reactivity, серверное состояние — через Apollo Client кэш; типобезопасность обеспечить через Codegen для GraphQL-схемы.

## Рассмотренные альтернативы

- **React 18** — более высокая сложность обучения, шаблонный код
- **Svelte 4** — меньшая экосистема, меньше готовых компонентов для графов
- **Vue 3 + Apollo Client** — GraphQL-first state management, встроенный кэш и нормализация данных

## Последствия

- Apollo Client предоставляет встроенный кэш и нормализацию данных
- Локальное UI-состояние управляется через Vue reactivity (`ref`, `reactive`)
- GraphQL API упрощает работу с вложенными данными онтологий
