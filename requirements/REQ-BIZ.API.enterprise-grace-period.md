## Назначение

Предоставить Enterprise-клиентам дополнительное время для миграции при отключении endpoint'ов.

## Требование

Параметры grace period: до 30 дополнительных дней, основание — критическая интеграция, одобрение — команда VEDO.

**Процесс:** Клиент → заявка в поддержку → оценка VEDO → подтверждение с новой датой → обновление заголовка `Sunset`.

## Критерии приёмки

1. Enterprise могут запросить grace period.
2. Предоставляется по решению VEDO.
3. `Sunset` обновляется.
4. Документируется.
5. Клиент получает подтверждение.
