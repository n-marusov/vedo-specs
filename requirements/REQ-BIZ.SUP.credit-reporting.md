## Назначение

Определить отчётность по использованию AI Credits для финансового учёта.

## Требование

Система предоставляет отчётность по использованию AI Credits для финансового учёта.

**Доступные отчёты:**

1. **Ежемесячный отчёт:** Использование Credits по пользователям, провайдерам, моделям, функциям.
2. **Финансовый отчёт:** Стоимость в USD, прогнозы, сравнение с предыдущими периодами.
3. **Аудит-отчёт:** История пополнений и списаний с детализацией по провайдерам.
4. **Рекомендации:** Оптимизация использования (выбор более дешёвых моделей, кэширование).

## Критерии приёмки

1. Ежемесячный отчёт генерируется автоматически.
2. Отчёт доступен для скачивания в CSV/PDF.
3. Возможность отправки отчёта на email администратору.
4. Аудит-отчёт доступен для финансового контроля.
5. Рекомендации по оптимизации — опционально.
