# Учёт стоимости генерации AI-подсказок

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-BIZ.SUP.suggestion-cost |
| **Уровень** | BIZ |
| **Атрибут качества** | — |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | `REQ-BIZ.SUP.credit-consumption` |

---

## Назначение

Определить модель учёта стоимости генерации AI-подсказок в системе AI Credits.

## Требование

Генерация AI-подсказок расходует AI Credits так же, как и остальные AI-функции. Стоимость рассчитывается на основе фактического использования токенов.

**Особенности:**

- Подсказки генерируются при открытии сущности (автоматически) или по запросу пользователя.
- Стоимость списывается с общего пула Credits организации.
- Пользователь видит ориентировочную стоимость генерации подсказок (если включено в настройках).

## Критерии приёмки

1. Генерация подсказок расходует AI Credits.
2. Стоимость рассчитывается по фактическому использованию токенов согласно `REQ-FUN.INTEGRATION.cost-calculation`.
3. При балансе Credits = 0 подсказки не генерируются.
4. В дашборде отображается стоимость генерации подсказок отдельной строкой.
5. Пользователь видит уведомление о стоимости при первом открытии сущности (опционально, настраивается администратором).
