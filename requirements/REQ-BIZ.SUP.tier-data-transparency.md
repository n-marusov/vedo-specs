## Назначение

Зафиксировать различие условий передачи данных LLM-провайдерам по тарифным планам.

## Требование

| План | Передача данных | Примечание |
|------|----------------|------------|
| **Community** | ✅ Да | Данные публичных онтологий; явное информирование |
| **Pro / Team** | ✅ Да (включая приватные) | Явное согласие (consent) |
| **Enterprise** | ✅ Да (в SaaS) | Индивидуальное соглашение; приоритетная опция on-premise |
| **On-premise** | ❌ Нет | Локальная LLM, данные не покидают периметр |

Для всех SaaS-планов: передача данных — архитектурный факт, явно указанный в договоре и privacy policy.

## Критерии приёмки

1. Условия передачи данных указаны для каждого тарифа.
2. Community: предупреждение при использовании AI-функций.
3. Enterprise: индивидуальное соглашение, приоритетная опция on-premise.
4. On-premise: документация по локальной LLM.
5. Тарифная страница содержит информацию о передаче данных.
