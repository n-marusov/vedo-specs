# Ограничение максимальной длины property path в SPARQL-запросах

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-CON.API.property-path-limit |
| **Уровень** | CON |
| **Атрибут качества** | — |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.3 матрицы качества M2 |

---

## Назначение

Ограничить длину property path в SPARQL-запросах для предотвращения DoS через экспоненциальный обход графа.

## Требование

**Пороговое значение:** **≤ 10 hops** (количество шагов в property path).

**Запрещённые паттерны без явного ограничения:**
- `rdfs:subClassOf*`, `owl:sameAs*`, `rdfs:subPropertyOf*`
- Любые property path с `*` или `+` без явного `LIMIT` или ограничения длины

**Сообщение при блокировке:** «Запрос содержит property path без ограничения длины. Максимальная длина — 10 hops. Добавьте LIMIT или используйте фиксированный path.»

## Критерии приёмки

1. Запросы с property path ≤ 10 hops принимаются.
2. Запросы с property path > 10 hops блокируются.
3. Запросы с `*`/`+` без явного ограничения блокируются.
4. Сообщение об ошибке содержит рекомендацию (например: `rdfs:subClassOf{1,10}`).
5. Блокировка логируется в audit.
