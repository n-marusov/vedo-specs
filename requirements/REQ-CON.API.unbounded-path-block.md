## Назначение

Блокировать SPARQL-запросы с операторами `*` и `+` без явного ограничения длины для предотвращения бесконечных обходов графа.

## Требование

**Блокируемые паттерны:**

| Паттерн | Пример | Причина |
|---------|--------|---------|
| `rdfs:subClassOf*` | `?class rdfs:subClassOf* :Vehicle` | Обход всего графа классов |
| `owl:sameAs*` | `?x owl:sameAs* :entity` | Обход эквивалентных сущностей |
| `rdfs:subPropertyOf*` | `?prop rdfs:subPropertyOf* :hasPart` | Обход иерархии свойств |
| `(path)+` | `(:parentOf)+` | Цикл при наличии циклов |
| `(path)*` | `(:parentOf)*` | Цикл при наличии циклов |

**Разрешённые альтернативы:**
- `rdfs:subClassOf{1,10}` — явное ограничение длины
- `rdfs:subClassOf+` с `LIMIT 100` — ограничение результата

## Критерии приёмки

1. Запросы с `*`/`+` без ограничения блокируются.
2. Запросы с `*`/`+` и явным `LIMIT` принимаются (с проверкой длины path).
3. Сообщение: «Используйте ограничение длины: rdfs:subClassOf{1,10}».
4. Блокировка логируется в audit.
