# Лимит длины NL-запроса

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-CON.SECURITY.nl-query-length-limit |
| **Уровень** | CON |
| **Атрибут качества** | — |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.1 матрицы качества M2 |

---

## Назначение

Ограничить максимальную длину NL-запроса для предотвращения атак через превышение размера и контроля стоимости токенов.

## Требование

Максимальная длина NL-запроса ограничена.

**Пороговое значение:** **≤ 2000 символов**.

**Поведение при превышении:**
Запрос блокируется с сообщением: «Запрос превышает максимальную длину в 2000 символов. Пожалуйста, сократите запрос.»

## Критерии приёмки

1. Запросы с длиной ≤ 2000 символов принимаются.
2. Запросы с длиной > 2000 символов блокируются.
3. Сообщение об ошибке содержит лимит.
4. Enterprise-тенанты могут иметь увеличенный лимит (конфигурируется).
5. Блокировка логируется в audit.
