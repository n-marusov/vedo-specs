## Назначение

Определить стек технологий для клиентской части VEDO Core — веб-платформы для редактирования онтологий.

## Требование

Клиентская часть VEDO Core должна использовать современный реактивный JavaScript-фреймворк с поддержкой TypeScript, GraphQL и экосистемой для работы с графами и сложными вложенными данными.

Ключевые критерии выбора:
- Реактивность для работы с вложенными данными онтологий
- Интеграция с GraphQL (кэширование, нормализация, cursor-пагинация)
- Достаточная экосистема для визуализации графов и сложных UI-компонентов
- Низкий порог входа для команды
