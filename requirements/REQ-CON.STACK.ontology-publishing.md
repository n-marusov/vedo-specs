## Назначение

Определить требования к публикации онтологий для внешнего просмотра без авторизации.

## Требование

VEDO Core должен позволять инженерам знаний делиться опубликованными онтологиями с внешними партнёрами и клиентами без создания аккаунта и раскрытия внутренних данных.

Требования к публикации:
- Read-only просмотр опубликованных онтологий без аутентификации
- 2D/3D навигация по структуре онтологии
- Полнотекстовый поиск по элементам
- Полная изоляция опубликованных данных от рабочей онтологии
