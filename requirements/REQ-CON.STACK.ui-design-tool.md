## Назначение

Определить инструмент для создания wireframes, прототипов и дизайн-спецификаций VEDO Core.

## Требование

Команда VEDO Core должна использовать единый инструмент для UI-проектирования, который:
- Обеспечивает низкопороговый командный доступ к проектированию
- Поддерживает экспорт в формат, пригодный для хранения в репозитории
- Интегрируется с рабочим процессом разработки
- Позволяет хранить спецификации вместе с кодом
