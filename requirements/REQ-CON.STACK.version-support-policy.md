## Поддерживаемые версии

| Версия | Статус | Поддержка | Миграция |
|--------|--------|-----------|----------|
| n (current) | Активная | Полная | Не требуется |
| n-1 | Limited | Только security-фиксы | Путь миграции документирован |
| n-2 | Устаревшая | Нет | Путь миграции может отсутствовать |
| n-3 и старше | End-of-life | Нет | Миграция через несколько мажорных версий не поддерживается |

## Путь обновления

Если заказчик пропустил одну мажорную версию, он должен выполнить последовательную миграцию: `n-2 -> n-1 -> n`.

Прямой upgrade через несколько мажорных версий, например `1.0 -> 3.0`, не поддерживается.
