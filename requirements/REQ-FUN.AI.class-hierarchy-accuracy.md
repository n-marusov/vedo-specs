## Назначение

Определить требования к корректности иерархии классов при NL→OWL генерации онтологии.

## Требование

При NL→OWL генерации онтологии система должна корректно определять иерархию классов. Класс считается корректным, если его родительский класс (`rdfs:subClassOf`) соответствует NL-описанию.

**Метрика:** Доля классов с корректно определённым родительским классом.

**Пороговое значение:** **≥ 80%** классов должны иметь корректную иерархию.

**Метод верификации:**

1. Сравнение с эталонной онтологией (созданной вручную экспертом) для тестового набора из 50 NL-описаний.
2. Автоматический подсчёт: `(количество классов с корректным parent) / (общее количество классов) * 100%`.
3. Тест считается пройденным, если значение ≥ 80%.

## Критерии приёмки

1. Evaluation suite содержит 50 тестовых NL-описаний с эталонными онтологиями.
2. CI/CD автоматически запускает проверку при каждом изменении промптов или модели.
3. При значении < 80% билд блокируется.
4. Результаты отображаются в CI/CD отчёте с детализацией по каждому тесту.
