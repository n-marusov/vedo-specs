# Итеративное уточнение с сохранением контекста

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.AI.iterative-refinement-context |
| **Уровень** | FUN |
| **Атрибут качества** | Functionality |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.2 матрицы качества M2 |
| **Связанные REQ** | `REQ-FUN.AI.max-refinement-iterations` |

---

## Назначение

Определить механизм итеративного уточнения (F14.2), при котором LLM модифицирует существующую структуру, а не генерирует её заново с нуля.

## Требование

При итеративном уточнении система сохраняет контекст предыдущей генерации и модифицирует существующую структуру, а не генерирует заново.

**Поведение:**

1. Пользователь вводит дополнительное описание (уточнение).
2. Система формирует промпт для LLM, содержащий:
   - Исходное NL-описание.
   - Уже сгенерированную OWL-структуру (сериализованную).
   - Новое уточнение пользователя.
   - Инструкцию «модифицируй существующую структуру, не пересоздавай с нуля».
3. LLM возвращает модифицированную OWL-онтологию.
4. Система вычисляет и отображает diff относительно предыдущей версии:
   - 🟢 Добавленные классы/свойства.
   - 🟡 Изменённые классы/свойства (изменён parent, domain, range, label).
   - 🔴 Удалённые классы/свойства.

**Сохранение контекста:**

Все ранее сгенерированные элементы, не затронутые уточнением, должны сохраняться без изменений (детерминированное поведение).

**Откат:**

Пользователь может откатить уточнение — вернуться к предыдущей версии онтологии. История версий в рамках одной сессии генерации хранится до 3 шагов назад.

## Критерии приёмки

1. При уточнении сохраняются все ранее сгенерированные элементы, не затронутые уточнением.
2. Отображается diff изменений (добавлено/изменено/удалено) в экране предпросмотра.
3. Пользователь может откатить уточнение (вернуться к предыдущей версии) через кнопку «Отменить уточнение».
4. Контекст сохраняется в пределах лимита — 3 цикла уточнения (см. `REQ-FUN.AI.max-refinement-iterations`).
5. При превышении лимита кнопка «Уточнить» деактивируется, система предлагает ручное редактирование.
