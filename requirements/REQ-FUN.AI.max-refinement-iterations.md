# Ограничение на количество циклов итеративного уточнения

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.AI.max-refinement-iterations |
| **Уровень** | FUN |
| **Атрибут качества** | Functionality |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.2 матрицы качества M2 |

---

## Назначение

Определить ограничение на количество циклов итеративного уточнения NL→OWL генерации (F14.2).

## Требование

При использовании итеративного уточнения (F14.2) пользователь может вносить дополнительные описания для доработки сгенерированной онтологии. Количество таких циклов ограничено.

**Метрика:** Максимальное количество циклов уточнения для одной онтологии.

**Пороговое значение:** **≤ 3 цикла** уточнения.

**Метод верификации:**

1. Подсчёт количества уточнений для каждой онтологии.
2. При достижении лимита — система предлагает перейти к ручному редактированию.

## Критерии приёмки

1. При 3-м уточнении система показывает предупреждение: "Достигнут лимит циклов уточнения. Вы можете продолжить ручное редактирование."
2. После 3-го цикла кнопка "Уточнить" становится неактивной.
3. Лимит сбрасывается при начале новой генерации (с чистого листа).
4. Для Enterprise-тира лимит может быть увеличен через конфигурацию.
