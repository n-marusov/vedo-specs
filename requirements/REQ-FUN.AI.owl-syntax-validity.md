## Назначение

Гарантировать синтаксическую валидность сгенерированной OWL-онтологии.

## Требование

Сгенерированная OWL-онтология должна быть синтаксически валидной и проходить парсинг без ошибок.

**Метрика:** Процент онтологий, проходящих синтаксическую валидацию.

**Пороговое значение:** **100%** (абсолютный запрет).

**Метод верификации:**

1. Автоматическая проверка с использованием OWL API или RDF парсера.
2. Проверка: (a) корректность IRI, (b) валидность XML (для RDF/XML), (c) корректность Turtle синтаксиса.
3. При ошибке парсинга — генерация считается неуспешной.

## Критерии приёмки

1. Validation suite включает синтаксическую проверку.
2. При синтаксической ошибке пользователю показывается сообщение с указанием проблемы.
3. Онтология с синтаксическими ошибками не может быть сохранена.
4. Валидация покрывает все поддерживаемые форматы сериализации (Turtle, RDF/XML, JSON-LD).
