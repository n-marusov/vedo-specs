## Назначение

Определить поддерживаемые форматы файлов для извлечения онтологии (document-extractor service).

## Требование

Система поддерживает загрузку файлов для извлечения OWL-онтологии в следующих форматах:

| Категория | Формат | Расширение | Примечание |
|-----------|--------|-----------|------------|
| **Текстовые документы** | Markdown | `.md` | Заголовки → классы, списки → свойства |
| | Plain Text | `.txt` | Сплошной текст → LLM без структуры |
| | PDF | `.pdf` | Текстовые PDF (не сканированные) |
| | Word | `.docx` | Заголовки, параграфы, таблицы |
| **Структурированные данные** | Excel | `.xlsx` | Колонки → класс/родитель/свойство/тип |
| | CSV | `.csv` | Разделители `,` или `;`, UTF-8 |
| | JSON | `.json` | Вложенные ключи → иерархия классов |
| | XML | `.xml` | Теги → классы, атрибуты → свойства |

**НЕ поддерживаются:**
- Сканированные PDF без OCR
- PDF с паролем
- .xls (старый бинарный Excel)
- HTML (планируется на Этап 3)
- Зашифрованные/запароленные файлы любых форматов

## Критерии приёмки

1. Все перечисленные форматы принимаются системой.
2. Для PDF/DOCX: система извлекает структурные элементы (заголовки, параграфы, таблицы) с учётом форматирования.
3. Для JSON/XML: система преобразует вложенность в иерархию классов.
4. Для XLSX/CSV: поддерживается маппинг колонок (класс, родитель, свойство, тип) через LLM.
5. При нераспознаваемом формате — ошибка с предложением поддерживаемых форматов.
6. Файлы с паролем отклоняются с соответствующим сообщением.
