## Назначение

Определить стратегии обработки дубликатов при импорте Excel-файла.

## Требование

При обнаружении дубликатов (сущность с таким же IRI или name уже существует в онтологии) система применяет одну из трёх стратегий.

**Стратегии:**

| Стратегия | Поведение | Применение |
|---|---|---|
| **Skip** | Пропустить дубликат, зафиксировать в отчёте | По умолчанию |
| **Overwrite** | Заменить существующую сущность новыми данными | Требует подтверждения |
| **Error** | Остановить импорт, требовать ручного разрешения | Для критичных данных |

## Критерии приёмки

1. Пользователь выбирает стратегию перед импортом (по умолчанию 'Skip').
2. При 'Skip' дубликаты пропускаются и логируются в отчёте.
3. При 'Overwrite' существующие сущности заменяются (создаётся коммит с описанием изменений).
4. При 'Error' импорт останавливается с указанием всех дубликатов.
5. Для каждой стратегии пользователь видит количество затронутых сущностей.
