# Допустимый процент ошибок в Excel-файле для продолжения импорта

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.API.excel-error-threshold |
| **Уровень** | FUN |
| **Атрибут качества** | Functionality |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.6 матрицы качества M2 |

---

## Назначение

Определить порог допустимого процента ошибок в Excel-файле, при превышении которого импорт блокируется.

## Требование

При импорте Excel-файла система проверяет каждую строку на наличие ошибок. Если процент ошибочных строк превышает пороговое значение, импорт блокируется.

**Метрика:** `(количество строк с ошибками) / (общее количество строк) * 100%`

**Пороговое значение:** **≤ 5%** строк с ошибками (Salesforce data import best practice: >5% ошибок указывает на системную проблему с данными).

## Критерии приёмки

1. При проценте ошибок ≤ 5% импорт выполняется (ошибочные строки пропускаются).
2. При проценте ошибок > 5% импорт блокируется.
3. Пользователь видит отчёт с количеством ошибок и процентом.
4. Отчёт содержит список всех ошибочных строк с причинами.
5. При блокировке пользователь может скачать файл с подсвеченными ошибками.
