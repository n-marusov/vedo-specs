## Назначение

Определить поведение системы при превышении допустимого процента ошибок: полная блокировка импорта до исправления данных.

## Требование

При превышении допустимого процента ошибок (> 5%) импорт блокируется полностью. Ни одна строка не импортируется.

**Поведение:**

1. **Валидация:** Система проверяет все строки перед импортом.
2. **Подсчёт ошибок:** Суммирует все ошибки (неверный тип, дубликаты, отсутствие обязательных полей).
3. **Решение:** Если ошибок > 5% — блокировка.
4. **Отчёт:** Пользователь получает детальный отчёт об ошибках.
5. **Исправление:** Пользователь исправляет ошибки и загружает файл повторно.

## Критерии приёмки

1. При ошибках > 5% импорт блокируется.
2. Ни одна строка не импортируется при блокировке.
3. Пользователь видит сообщение о блокировке с указанием процента ошибок.
4. Отчёт содержит список всех ошибок (строка, колонка, причина, предложение).
5. Пользователь может скачать файл с подсвеченными ошибками для исправления.
