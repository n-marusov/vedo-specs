## Назначение

Определить поддерживаемые форматы Excel-файлов для импорта.

## Требование

Система поддерживает импорт файлов в следующих форматах:

| Формат | Расширение | Примечание |
|--------|-----------|------------|
| **Excel (Open XML)** | `.xlsx` | Основной формат |
| **Excel (Macro-enabled)** | `.xlsm` | Макросы не выполняются (только данные) |
| **CSV (UTF-8)** | `.csv` | С разделителем `,` или `;` |

**НЕ поддерживаются:**
- `.xls` (старый бинарный формат Excel 97-2003)
- Файлы с защитой паролем
- Файлы с внешними ссылками

## Критерии приёмки

1. Поддерживаются .xlsx, .xlsm, .csv (UTF-8).
2. .xls файлы отклоняются с сообщением: «Формат .xls не поддерживается. Сохраните файл в .xlsx и повторите попытку.»
3. Файлы с паролем отклоняются с соответствующим сообщением.
4. CSV файлы с разделителем `;` поддерживаются (автоопределение разделителя).
5. При нераспознаваемом формате — ошибка с предложением использовать .xlsx.
