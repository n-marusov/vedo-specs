## Назначение

Определить набор проверок структуры и типов данных Excel-файла, выполняемых до начала импорта.

## Требование

Система валидирует структуру и типы данных в Excel-файле перед импортом.

**Проверки:**

| Проверка | Описание | Действие при ошибке |
|---|---|---|
| **Обязательные колонки** | Проверка наличия обязательных колонок ('Name', 'Parent') | Блокировка |
| **Типы данных** | Проверка соответствия типов (string, integer, date) | Ошибка на уровне строки |
| **Уникальность** | Проверка уникальности идентификаторов (IRI) | Ошибка на уровне строки |
| **Ссылочная целостность** | Проверка существования родительских классов | Ошибка на уровне строки |
| **IRI валидность** | Проверка корректности IRI | Ошибка на уровне строки |

## Критерии приёмки

1. Все проверки выполняются до начала импорта.
2. Ошибки валидации включаются в отчёт об ошибках.
3. При критической ошибке (отсутствие обязательной колонки) импорт блокируется.
4. При некритической ошибке (неверный тип) — ошибка на уровне строки.
5. Время валидации ≤ 5 секунд для 10,000 строк.
