# Постепенное снижение лимитов перед отключением endpoint'а

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.API.gradual-rollback |
| **Уровень** | FUN |
| **Атрибут качества** | Interface |
| **Приоритет** | P2 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.2 матрицы качества M2 |

---

## Назначение

Стимулировать миграцию клиентов через постепенное снижение лимитов deprecated endpoint'а.

## Требование

| Период до отключения | Лимит от исходного |
|----------------------|--------------------|
| Последние 30 дней | 50% |
| Последние 7 дней | 10% |
| Последние 24 часа | 1% |

Клиенты уведомлены о снижении. При обновлении на новую версию лимиты возвращаются. Enterprise могут запросить исключение.

## Критерии приёмки

1. Снижение по расписанию.
2. Клиенты уведомлены.
3. Восстановление при обновлении.
4. Логируется.
5. Enterprise — исключение по запросу.
