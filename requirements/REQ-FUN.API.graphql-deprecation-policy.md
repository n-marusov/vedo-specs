## Подход

GraphQL не требует версионного URL. Изменения в схеме сопровождаются директивами `@deprecated`.

## Политика

- При переходе `v1 -> v2` поля, которые планируется удалить, сначала помечаются `@deprecated`.
- Период устаревания: 1 год как общее правило из M2.2.
- Для frontend GraphQL SLA в ответе также указан срок 9 месяцев: удаление полей только через 9 месяцев после предупреждения.
- В новой major версии deprecated поля могут быть удалены после истечения срока предупреждения.

## Пример схемы

```graphql
type Class {
  id: ID!
  name: String!
  label: String @deprecated(reason: "Use 'name' instead")
  displayName: String!
}
```

## Пример клиента

Клиент v1 может продолжать использовать deprecated поле `label`, пока оно доступно:

```graphql
query GetClass {
  class(id: "Person") {
    id
    label
  }
}
```

Клиент v2 использует новое поле:

```graphql
query GetClass {
  class(id: "Person") {
    id
    displayName
  }
}
```
