## Назначение

Определить подход к предоставлению API для навигации по графу онтологии и аналитических запросов.

## Требование

VEDO Core должен предоставлять API с разделением ответственности:
- **API навигации** для фронтенда: поддержка пагинации, запрос только необходимых полей, вложенные запросы, работа с динамической схемой онтологии (пользовательские классы, свойства и отношения создаются во время работы).
- **API аналитических запросов**: поддержка сложных фильтров, агрегаций и обходов графа переменной глубины к RDF/OWL-графу.

API навигации должен обеспечивать cursor pagination, типизацию на клиенте, встроенный кэш. Динамическая схема онтологии не должна ломать API навигации — пользовательские свойства возвращаются через контейнеры, а не как заранее сгенерированные поля схемы.

Аналитический API должен сохранять полную выразительность W3C-стандарта для сложной аналитики, которая не покрывается навигационной схемой.
