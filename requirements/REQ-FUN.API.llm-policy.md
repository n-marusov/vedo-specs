## Назначение

Определить политику маршрутизации LLM-запросов на основе двух факторов: тип развёртывания VEDO (SaaS / On-premise) и уровень видимости онтологии (Public / Internal / Private).

## Требование

Система применяет политику использования LLM согласно следующей матрице:

| Тип развёртывания | Уровень видимости | Доступные LLM | Примечание |
|---|---|---|---|
| **SaaS** | Public | Внешние (OpenAI, Anthropic) | С предупреждением пользователю |
| **SaaS** | Internal | По умолчанию: ЗАБЛОКИРОВАНЫ. Администратор может разрешить. | Требуется явное административное разрешение |
| **SaaS** | Private | По умолчанию: ЗАБЛОКИРОВАНЫ. Администратор может разрешить. | Требуется явное административное разрешение |
| **On-premise** | Public | Локальная LLM (URL в VPN) | Внешние провайдеры недоступны по сети |
| **On-premise** | Internal | Локальная LLM (URL в VPN) | Внешние провайдеры недоступны по сети |
| **On-premise** | Private | Локальная LLM (URL в VPN) | Внешние провайдеры недоступны по сети |

**Ключевые принципы:**

1. **Локальная LLM существует только в on-premise.** В SaaS локальная LLM не предоставляется.
2. **SaaS использует только внешние LLM-провайдеры** (OpenAI, Anthropic и др.).
3. **On-premise использует только локальную LLM.** Внешние провайдеры недоступны по сети.
4. Для **Internal и Private в SaaS** внешние LLM по умолчанию заблокированы. Администратор может сознательно разрешить (см. `REQ-FUN.UI.external-llm-override`).
5. Для **Public в SaaS** внешние LLM разрешены всегда (с предупреждением пользователю — см. `REQ-USR.UI.external-llm-consent`).

Политика применяется на уровне API Gateway до вызова LLM (см. `ADR-DES.API.llm-policy-router-strategy`).

## Критерии приёмки

1. В SaaS для Public онтологий AI-функции используют внешние LLM-провайдеры.
2. В SaaS для Internal/Private онтологий AI-функции по умолчанию блокируются с кодом ошибки `LLM_BLOCKED_BY_POLICY`.
3. В On-premise все AI-функции используют локальную LLM.
4. Каждое применение политики логируется в audit с полем `llm_policy_decision`.
5. Политика едина для всех AI-функций (NL→OWL, NL-запросы, AI-подсказки).
