## Назначение

Обеспечить клиентов документацией по миграции при deprecation endpoint'ов.

## Требование

Руководство по миграции доступно в день объявления и содержит:

1. **Объявление:** Какой endpoint deprecation, дата отключения.
2. **Причина:** Почему отключается.
3. **Альтернатива:** Какой endpoint использовать вместо deprecated.
4. **Примеры:** Запросы до и после.
5. **FAQ:** Частые вопросы.
6. **Поддержка:** Контакты.

## Критерии приёмки

1. Доступно в день объявления.
2. Все 6 разделов присутствуют.
3. На русском и английском.
4. Ссылка в заголовке `Link`.
5. Обновляется при изменении сроков.
