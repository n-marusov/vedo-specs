# Запрет циклических зависимостей в иерархии классов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.API.no-cyclic-hierarchy |
| **Уровень** | FUN |
| **Атрибут качества** | Functionality |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.2 матрицы качества M2 |

---

## Назначение

Гарантировать отсутствие циклических зависимостей в иерархии классов сгенерированной OWL-онтологии.

## Требование

Сгенерированная OWL-онтология **НЕ ДОЛЖНА** содержать циклических зависимостей в иерархии классов (`rdfs:subClassOf` циклы). Наличие цикла делает онтологию логически несостоятельной.

**Метрика:** Количество циклических зависимостей.

**Пороговое значение:** **0** (абсолютный запрет).

**Метод верификации:**

1. Автоматическая проверка графа классов на наличие циклов.
2. Использование алгоритма обхода графа (DFS) для детекции циклов.
3. При обнаружении цикла — генерация онтологии считается неуспешной.

## Критерии приёмки

1. Validation suite включает проверку на циклы.
2. При обнаружении цикла пользователю показывается ошибка с указанием проблемных классов.
3. Система предлагает варианты исправления (например, инвертировать связь или удалить одну из них).
4. Онтология с циклами не может быть сохранена.
