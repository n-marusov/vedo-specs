## Сценарий

Если on-premise клиент не хочет обновляться на новую major версию API, доступны несколько вариантов.

| Вариант | Описание | Кому подходит |
|---------|----------|---------------|
| Замораживание версии | Клиент остается на v1 без обновлений, даже security | Не рекомендуется из-за рисков безопасности |
| Long Term Support (LTS) | VEDO предоставляет LTS-релизы, например v1 LTS на 2 года | Enterprise с бюрократией |
| Кастомный бэкпорт | Клиент платит за бэкпорт security-фиксов в v1 | Единичные случаи |
| Постепенная миграция | Клиент переводит интеграции на v2 постепенно в течение 6-12 месяцев | Крупные интеграции |

## Выбранная политика

Для критических интеграций предоставляется LTS-версия на 2 года.

Постепенная миграция в течение 6-12 месяцев является предпочтительным вариантом для крупных интеграций.

Замораживание версии без security updates не рекомендуется.
