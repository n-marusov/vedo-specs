## Назначение

Проверять, что DatatypeProperty используют корректные XSD-типы данных — информационная валидация.

## Требование

Система проверяет типы данных DatatypeProperty на соответствие поддерживаемым XSD-типам.

**Поддерживаемые:** `xsd:string`, `xsd:integer`, `xsd:decimal`, `xsd:boolean`, `xsd:date`, `xsd:dateTime`, `xsd:anyURI`.

**Некорректные (с предупреждением и предложением замены):** `xsd:double` → `xsd:decimal`, `xsd:float` → `xsd:decimal`, `xsd:time` → `xsd:dateTime`.

**Тип:** 🟡 Информационная — онтология показывается с предупреждениями.

## Критерии приёмки

1. Проверка выполняется для всех сгенерированных онтологий.
2. Предупреждения отображаются для некорректных типов с предложением замены.
3. Пользователь может продолжить с некорректным типом.
4. Время проверки ≤ 100 мс для 50 свойств.
