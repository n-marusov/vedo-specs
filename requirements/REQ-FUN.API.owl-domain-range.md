## Назначение

Проверять согласованность domain и range для каждого ObjectProperty — информационная валидация.

## Требование

Для каждого ObjectProperty система проверяет:
1. `rdfs:domain` указывает на существующий класс
2. `rdfs:range` указывает на существующий класс
3. Domain и range не конфликтуют (domain — класс, range — литерал)

**Тип:** 🟡 Информационная — онтология показывается с предупреждениями.

## Критерии приёмки

1. Проверка выполняется для всех сгенерированных онтологий.
2. Предупреждения отображаются в экране предпросмотра с указанием проблемного свойства и рекомендацией.
3. Пользователь может продолжить работу с онтологией.
4. Время проверки ≤ 300 мс для 50 свойств.
