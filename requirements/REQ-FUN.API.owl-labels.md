## Назначение

Проверять наличие `rdfs:label` у всех сущностей — информационная валидация для улучшения юзабилити.

## Требование

Система проверяет, что все классы, свойства и индивиды имеют `rdfs:label`. Пустые сущности ухудшают навигацию.

**Тип:** 🟡 Информационная — онтология показывается с предупреждениями.

## Критерии приёмки

1. Проверка выполняется для всех сгенерированных онтологий.
2. Предупреждения отображаются для сущностей без label (тип сущности, IRI, рекомендация).
3. Пользователь может продолжить работу.
4. Время проверки ≤ 100 мс для 100 сущностей.
