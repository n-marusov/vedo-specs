## Назначение

Гарантировать отсутствие циклических зависимостей в графе `rdfs:subClassOf` — блокирующая валидация.

## Требование

Система проверяет, что граф `rdfs:subClassOf` не содержит циклов: построение графа отношений, обход в глубину (DFS), идентификация всех классов в цикле.

**Пример цикла:** Car → Vehicle → Car.

**Тип:** 🔴 Блокирующая — онтология не показывается до исправления.

## Критерии приёмки

1. Проверка выполняется для всех сгенерированных онтологий.
2. При обнаружении цикла онтология не отображается.
3. Сообщение содержит список классов в цикле.
4. Предложение: «Удалите или измените одну из связей: [A] → [B] → [A]».
5. Время проверки ≤ 500 мс для 100 классов.
