## Назначение

Проверять, что все ссылки (`rdfs:subClassOf`, `rdfs:domain`, `rdfs:range`, `owl:inverseOf`) указывают на существующие сущности — информационная валидация.

## Требование

Система проверяет ссылочную целостность: для каждой ссылки проверяется существование целевой сущности в онтологии.

**Пример нарушения:** `:Car rdfs:subClassOf :Vehicle`, где `:Vehicle` не определён.

**Тип:** 🟡 Информационная — онтология показывается с предупреждениями. Пользователь может создать отсутствующую сущность как заглушку.

## Критерии приёмки

1. Проверка выполняется для всех сгенерированных онтологий.
2. Предупреждения отображаются с указанием отсутствующей сущности.
3. Предложение: «Создать отсутствующий класс [сущность]?» с опцией «Да»/«Нет».
4. При выборе «Да» — сущность создаётся как пустой класс с автоматическим IRI.
5. Время проверки ≤ 300 мс для 100 ссылок.
