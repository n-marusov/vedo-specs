## Назначение

Проверять, что сгенерированная OWL-онтология использует только поддерживаемые VEDO Core конструкции — информационная валидация.

## Требование

Система проверяет использование OWL-конструкций на соответствие поддерживаемому профилю OWL DL.

**Поддерживаемые:** `owl:Class`, `rdfs:subClassOf`, `owl:equivalentClass`, `owl:disjointWith`, `owl:ObjectProperty`, `owl:DatatypeProperty`, `rdfs:domain`, `rdfs:range`, `owl:inverseOf`, `owl:TransitiveProperty`, `owl:SymmetricProperty`, `rdfs:label`, `rdfs:comment`, `owl:versionInfo`, `xsd:string`, `xsd:integer`, `xsd:decimal`, `xsd:boolean`, `xsd:date`, `xsd:dateTime`.

**НЕ поддерживаются** (отмечаются предупреждениями): `owl:hasKey`, `owl:propertyChainAxiom`, `owl:sameAs`, `owl:differentFrom`, `owl:AllDifferent`, `owl:oneOf`.

**Тип:** 🟡 Информационная — онтология показывается с предупреждениями.

## Критерии приёмки

1. Проверка выполняется для всех сгенерированных онтологий.
2. Предупреждения отображаются с указанием неподдерживаемой конструкции.
3. Неподдерживаемые конструкции игнорируются или заменяются на поддерживаемый аналог.
4. Документация содержит список поддерживаемых OWL-конструкций.
5. Время проверки ≤ 200 мс для 100 аксиом.
