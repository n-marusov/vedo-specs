## Назначение

Проверять синтаксическую корректность сгенерированной OWL-онтологии с использованием OWL API — блокирующая валидация.

## Требование

Система проверяет сгенерированную OWL-онтологию на синтаксическую корректность для всех поддерживаемых форматов (Turtle, RDF/XML, JSON-LD).

**Проверяемые аспекты:**
1. Корректность IRI (URI/IRI без недопустимых символов)
2. XML-валидность (отсутствие незакрытых тегов)
3. Turtle-синтаксис (корректные префиксы, завершения строк)
4. OWL-конструкции (только известные: owl:Class, owl:ObjectProperty, owl:DatatypeProperty, rdfs:subClassOf, rdfs:domain, rdfs:range)

**Тип:** 🔴 Блокирующая — онтология не показывается до исправления.

## Критерии приёмки

1. Проверка выполняется для всех сгенерированных онтологий.
2. При синтаксической ошибке онтология не отображается.
3. Сообщение содержит: тип ошибки, местоположение (строка/колонка), предложение по исправлению.
4. Валидация поддерживает Turtle, RDF/XML, JSON-LD.
5. Время валидации ≤ 1 секунда для онтологии из 10 классов.
