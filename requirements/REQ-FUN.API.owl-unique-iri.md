## Назначение

Гарантировать уникальность всех IRI в сгенерированной онтологии — блокирующая валидация.

## Требование

Система проверяет, что все IRI уникальны среди классов, ObjectProperty, DatatypeProperty и индивидов. Дубликаты IRI приводят к конфликтам при импорте.

**Проверяемые сущности:** Классы, ObjectProperty, DatatypeProperty, индивиды.

**Тип:** 🔴 Блокирующая — онтология не показывается до исправления.

## Критерии приёмки

1. Проверка выполняется для всех сгенерированных онтологий.
2. При дубликате IRI онтология не отображается.
3. Сообщение содержит список дублирующихся IRI и их типы.
4. Предложение: «Переименуйте дублирующиеся сущности: [IRI] (Класс), [IRI] (Класс)».
5. Время проверки ≤ 200 мс для 100 сущностей.
