## Назначение

Определить требования к корректности свойств (ObjectProperty и DatatypeProperty) при NL→OWL генерации онтологии.

## Требование

При NL→OWL генерации онтологии система должна корректно определять свойства (ObjectProperty и DatatypeProperty). Свойство считается корректным, если его domain и range соответствуют NL-описанию.

**Метрика:** Доля свойств с корректно определёнными domain и range.

**Пороговое значение:** **≥ 75%** свойств должны иметь корректные domain/range.

**Метод верификации:**

1. Сравнение с эталонной онтологией для тестового набора из 50 NL-описаний.
2. Автоматический подсчёт: `(количество свойств с корректными domain/range) / (общее количество свойств) * 100%`.
3. Тест считается пройденным, если значение ≥ 75%.

## Критерии приёмки

1. Evaluation suite проверяет как ObjectProperty, так и DatatypeProperty.
2. CI/CD автоматически запускает проверку при каждом изменении промптов или модели.
3. При значении < 75% билд блокируется.
4. Результаты отображаются в CI/CD отчёте с детализацией по каждому свойству.
