## Назначение

Определить набор протоколов для внутренних и внешних API VEDO Core.

## Требование

API VEDO Core должен использовать многоуровневый протокольный стек, где каждый протокол отвечает своему сценарию использования:
- Внутренние вызовы между сервисами — высокопроизводительный бинарный протокол со строгой типизацией
- Внешний API — стандартный REST (JSON) для широкой совместимости
- Коллаборация в реальном времени — двунаправленный протокол с низкой задержкой
- Навигация по графу для клиентской части — API с поддержкой вложенных запросов и пагинации

API Gateway как единый фасад скрывает внутреннюю топологию сервисов и упрощает версионирование и security.
