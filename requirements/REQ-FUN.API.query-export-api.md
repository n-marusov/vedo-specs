## Назначение

Предоставить программный доступ к экспорту сохранённых запросов через REST API.

## Требование

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/v1/user/queries/export` | POST | Запуск экспорта → `{ "job_id": "...", "status": "processing" }` |
| `/api/v1/user/queries/export/{job_id}` | GET | Проверка статуса → `{ "status": "ready", "download_url": "..." }` |
| `/api/v1/user/queries/export/{job_id}/download` | GET | Скачивание ZIP-архива |

Аутентификация: Bearer JWT. Экспортируются только запросы текущего пользователя (authorization by user_id из токена).

## Критерии приёмки

1. API для запуска, проверки статуса и скачивания доступен.
2. Документация OpenAPI обновлена.
3. API защищён аутентификацией и авторизацией.
4. Rate limiting: 5 экспортов в час на пользователя.
