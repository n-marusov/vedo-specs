## Назначение

Отсеивать низкокачественные AI-подсказки через минимальный порог confidence score.

## Требование

Система показывает только подсказки с confidence score ≥ 70%. Подсказки с более низкой уверенностью не отображаются пользователю.

**Метрика:** Confidence score — оценка LLM в диапазоне 0–100%.

## Критерии приёмки

1. Подсказки с confidence < 70% не отображаются.
2. Confidence score отображается для каждой подсказки.
3. Пользователь может видеть, сколько подсказок было отфильтровано (опционально).
4. Администратор может настроить порог confidence (по умолчанию 70%).
5. В audit-логе фиксируется confidence для каждой сгенерированной подсказки (для анализа качества).
