## Назначение

Обеспечить актуальность AI-подсказок путём их автоматического пересчёта при изменении структуры онтологии.

## Требование

При изменении структуры онтологии (добавление/удаление классов, свойств) система пересчитывает AI-подсказки для всех затронутых сущностей.

**Триггеры пересчёта:**

1. **Добавление нового класса** — пересчёт для классов, которые могут быть связаны.
2. **Добавление нового свойства** — пересчёт для классов, к которым может применяться свойство.
3. **Удаление сущности** — удаление связанных подсказок.
4. **Ручной запрос** — пользователь может запросить пересчёт (кнопка «Обновить подсказки»).

## Критерии приёмки

1. При изменении онтологии подсказки обновляются в течение 5 секунд.
2. Пользователь видит индикатор обновления (спиннер).
3. При удалении сущности связанные подсказки автоматически удаляются.
4. Пользователь может вручную запросить пересчёт.
5. Частота пересчёта ограничена (не чаще 1 раза в 10 секунд для предотвращения избыточных LLM-вызовов).
