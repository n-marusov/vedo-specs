## Назначение

Определить типы OWL-связей, которые AI-подсказки могут предлагать пользователю в зависимости от контекста сущности.

## Требование

Система предлагает различные типы связей в зависимости от контекста редактируемой сущности.

**Типы подсказок:**

| Тип | Описание | Пример |
|---|---|---|
| **subClassOf** | Предложение родительского класса | «Класс 'ЛегковойАвтомобиль' может быть подклассом 'Автомобиль'» |
| **ObjectProperty** | Предложение связи между классами | «Класс 'Водитель' может иметь свойство 'управляет' → 'Автомобиль'» |
| **DatatypeProperty** | Предложение атрибута | «Класс 'Автомобиль' может иметь свойство 'годВыпуска' (integer)» |
| **EquivalentClass** | Предложение эквивалентности | «Класс 'Машина' эквивалентен 'Автомобиль'» |
| **DisjointClass** | Предложение непересекаемости | «Класс 'Спорткар' и 'Внедорожник' — непересекающиеся» |

## Критерии приёмки

1. Подсказки могут предлагать разные типы связей.
2. Тип связи отображается в интерфейсе (иконка/текст).
3. Пользователь может фильтровать подсказки по типу.
4. При применении подсказки создаётся соответствующая OWL-аксиома.
