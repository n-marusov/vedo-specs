# Использование заголовка Sunset (RFC 8594) для deprecation

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.API.sunset-header |
| **Уровень** | FUN |
| **Атрибут качества** | Interface |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | RFC 8594, уточнение стейкхолдера (Блок 3.2) |

---

## Назначение

Использовать стандартный механизм RFC 8594 для информирования клиентов о deprecation через HTTP-заголовки.

## Требование

Все deprecated endpoint'ы возвращают заголовки в каждом ответе:

```
Sunset: Thu, 15 Oct 2026 00:00:00 GMT
Deprecation: true
Link: <https://docs.vedo.io/api/migration-guide>; rel="deprecation"; type="text/html"
```

- `Sunset` — дата, после которой endpoint перестанет работать (RFC 8594)
- `Deprecation: true` — флаг deprecation
- `Link` — ссылка на руководство по миграции

Заголовки возвращаются во всех ответах (200, 400, 500) с момента объявления deprecation.

## Критерии приёмки

1. Все deprecated endpoint'ы возвращают `Sunset` с корректной датой.
2. `Deprecation: true` возвращается вместе с `Sunset`.
3. Ссылка на руководство по миграции в заголовке `Link`.
4. Заголовки присутствуют во всех HTTP-ответах.
