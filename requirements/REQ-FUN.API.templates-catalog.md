## Назначение

Определить первоначальный каталог шаблонов для MVP.

## Требование

В MVP система предоставляет 5 базовых шаблонов для типовых предметных областей:

| # | Шаблон | Категория | Ключевые классы |
|---|--------|-----------|-----------------|
| 1 | **Организация** | Бизнес | Organization, Department, Employee, Position |
| 2 | **Продукт** | Бизнес | Product, Category, Manufacturer, Review |
| 3 | **Процесс** | Бизнес | Process, Step, Input, Output, Agent |
| 4 | **Глоссарий** | Общее | Term, Definition, RelatedTerm, Source |
| 5 | **Событие** | Общее | Event, Participant, Location, DateTime |

Каждый шаблон содержит: TBox (4-6 классов, 3-5 свойств), ABox (1-2 индивида), аннотации, метаданные и документацию.

## Критерии приёмки

1. В каталоге доступно 5 шаблонов.
2. Каждый шаблон проходит полную OWL-валидацию.
3. Каждый шаблон содержит документацию (README.md).
4. Каждый шаблон имеет метаданные (имя, описание, версия, теги, категория).
5. При создании новой онтологии пользователь может выбрать шаблон из каталога.
