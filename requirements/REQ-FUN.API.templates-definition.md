## Назначение

Определить, что представляет собой шаблон онтологии и из каких компонентов он состоит.

## Требование

**Шаблон онтологии** — готовая, структурированная, документированная и валидная OWL-онтология для использования в качестве отправной точки при создании новой онтологии.

**Обязательные компоненты шаблона:**

| Компонент | Описание |
|-----------|----------|
| **TBox (схема)** | Классы, ObjectProperty, DatatypeProperty, иерархии |
| **ABox (данные)** | 1-2 демонстрационных индивида |
| **Аннотации** | `rdfs:label`, `rdfs:comment` (русский/английский) |
| **Аксиомы** | `rdfs:subClassOf`, `rdfs:domain`, `rdfs:range`, `owl:inverseOf` |
| **OWL-конструкции** | Поддерживаемые OWL DL (эквивалентность, транзитивность) |
| **Метаданные** | Название, описание, версия (semver), автор, теги, категория, usage_count |
| **Документация** | Описание предметной области, карта классов, примеры запросов |

**Отличие от обычной онтологии:** Шаблон содержит только демонстрационные данные (1-2 индивида), имеет обязательную документацию, семантическое версионирование и ориентирован на повторное использование.

## Критерии приёмки

1. Шаблон проходит OWL-валидацию (синтаксис, циклы, уникальность IRI).
2. Каждый класс и свойство имеет `rdfs:label` и `rdfs:comment`.
3. Метаданные шаблона соответствуют схеме (13 полей).
4. Документация присутствует в README.md.
5. Хранится в структуре: `templates/<category>/template.owl + metadata.json + README.md`.
