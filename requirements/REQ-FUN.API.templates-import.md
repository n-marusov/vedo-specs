## Назначение

Предоставить пользователю возможность создать шаблон из своей онтологии.

## Требование

Пользователь может создать шаблон из существующей онтологии через кнопку «Сохранить как шаблон».

**Процесс создания:**

1. Пользователь выбирает онтологию → «Сохранить как шаблон».
2. Система предлагает заполнить метаданные: название, описание, категория, теги.
3. Система валидирует онтологию (OWL-валидация, наличие label/comment).
4. При успешной валидации создаётся шаблон: `source="community"`, `version="1.0.0"`, `author_id=<user>`.
5. Шаблон сохраняется в личном каталоге пользователя.
6. Пользователь может предложить шаблон в официальный каталог через PR.

## Критерии приёмки

1. Кнопка «Сохранить как шаблон» доступна в настройках онтологии.
2. Пользователь заполняет метаданные (название, описание, категория, теги).
3. Онтология проходит валидацию перед сохранением как шаблон.
4. Шаблон сохраняется с `source="community"` и `version="1.0.0"`.
5. Пользователь может использовать свой шаблон при создании новых онтологий.
