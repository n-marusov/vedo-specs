## Назначение

Определить требования к корневому HTTP-эндпоинту для метаданных сервисов.

## Требование

Каждый микросервис VEDO Core должен предоставлять единый корневой эндпоинт `/`, возвращающий JSON с метаданными по унифицированной схеме: service, version, status, uptime_seconds, description и links.

Это обеспечивает:
- Единый источник метаданных для любого сервиса
- Упрощение диагностики и service discovery
- Возможность автоматизации runbook-команд и CLI

HTTP management surface каждого внутреннего сервиса должен быть ограничен эндпоинтами `/`, `/health`, `/ready`.
