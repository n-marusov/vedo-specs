## Назначение

Применять те же валидации OWL при импорте онтологии из файла (F8) для обеспечения консистентности данных независимо от источника.

## Требование

При импорте OWL-онтологии:
- 🔴 Блокирующие ошибки (синтаксис, циклы, дубликаты IRI) останавливают импорт.
- 🟡 Информационные предупреждения показываются в отчёте, но импорт продолжается.

## Критерии приёмки

1. Те же 8 валидаций применяются при импорте.
2. Блокирующие ошибки останавливают импорт.
3. Информационные предупреждения показываются в отчёте импорта.
4. Пользователь может просмотреть отчёт с ошибками и предупреждениями.
5. Импорт с блокирующими ошибками не создаёт коммит.
