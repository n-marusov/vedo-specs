## Назначение

Выполнять валидацию изменений онтологии при создании Pull Request — предотвращение слияния невалидных изменений в основную ветку.

## Требование

При создании Pull Request система выполняет полную валидацию изменений онтологии.

**Тип:** 🔴 Блокирующая — PR не может быть слит при наличии блокирующих ошибок.

## Критерии приёмки

1. Валидация выполняется автоматически при создании PR.
2. Результаты валидации отображаются в интерфейсе PR.
3. Блокирующие ошибки блокируют слияние (merge).
4. Информационные предупреждения отображаются, но не блокируют слияние.
5. История валидации сохраняется в комментариях PR.
