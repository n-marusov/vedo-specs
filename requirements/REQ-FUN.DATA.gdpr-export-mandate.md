# Обязательный экспорт данных при удалении аккаунта (GDPR Article 20)

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.DATA.gdpr-export-mandate |
| **Уровень** | FUN |
| **Атрибут качества** | Functionality |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | GDPR Article 20 (Right to data portability), уточнение стейкхолдера (Блок 3.1) |
| **Связанные REQ** | `REQ-NFR.DATA.account-closure-retention` (30-дневный период охлаждения) |

---

## Назначение

Реализовать право пользователя на переносимость данных (GDPR Article 20) применительно к сохранённым запросам.

## Требование

На основе существующего жизненного цикла удаления аккаунта (`REQ-NFR.DATA.account-closure-retention`):

1. В течение 30-дневного периода охлаждения пользователь может экспортировать сохранённые запросы.
2. Экспорт доступен опционально — пользователь может пропустить.
3. После истечения 30 дней данные удаляются без возможности восстановления.
4. Экспорт также доступен в любой момент (не только при удалении).

**Согласование с существующим lifecycle:**
- 30-дневный срок экспорта = 30-дневный период охлаждения из `REQ-NFR.DATA.account-closure-retention`
- Полное удаление после 30 дней — как предусмотрено существующим lifecycle

## Критерии приёмки

1. При запросе на удаление отображается опция экспорта запросов.
2. Пользователь может экспортировать запросы в любой момент (настройки аккаунта).
3. Экспорт доступен в течение 30 дней после запроса на удаление.
4. После 30 дней данные безвозвратно удаляются.
5. Пользователь получает уведомление о доступности экспорта.
