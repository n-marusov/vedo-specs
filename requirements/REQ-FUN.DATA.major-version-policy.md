## Что считается мажорной версией

Для VEDO Core мажорная версия означает обратно несовместимые изменения: схема БД, формат коммитов, API endpoints.

| Тип версии | Пример | Что меняется | Совместимость API | Миграция данных |
|------------|--------|--------------|-------------------|-----------------|
| Мажорная (Major) | v1.0 -> v2.0 | Обратно несовместимые изменения: схема БД, формат коммитов, API endpoints | Несовместима | Обязательна |
| Минорная (Minor) | v1.0 -> v1.1 | Новая функциональность, совместимые изменения | Да | Не требуется |
| Патч (Patch) | v1.0.0 -> v1.0.1 | Исправление ошибок, security-фиксы | Да | Не требуется |

## Правило миграции

Мажорные версии требуют формальной процедуры миграции, которая может включать даунтайм.

Минорные и patch версии не требуют миграции данных, если изменения совместимы с существующей схемой, API и форматом коммитов.
