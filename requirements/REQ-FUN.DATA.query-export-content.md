# Содержимое экспорта сохранённых запросов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.DATA.query-export-content |
| **Уровень** | FUN |
| **Атрибут качества** | Functionality |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.1 матрицы качества M2 |

---

## Назначение

Определить, что включается в экспорт сохранённых запросов пользователя.

## Требование

Экспорт включает **только личные сохранённые запросы пользователя** — не данные tenant, не онтологии, не результаты выполнения.

| Тип данных | Включено | Примечание |
|------------|----------|------------|
| Сохранённые SPARQL-запросы | ✅ | Полный текст, имя, дата, теги |
| Сохранённые CYPHER-запросы | ✅ | Полный текст, имя, дата, теги |
| Метаданные запросов | ✅ | is_public, created_at, updated_at, tags |
| История изменений запросов | ❌ | Только текущая версия |
| Результаты выполнения | ❌ | Только текст запроса |
| Онтологии пользователя | ❌ | Отдельный механизм в `decommission-export` |
| Данные tenant | ❌ | Не личные данные |

## Критерии приёмки

1. Экспорт содержит все сохранённые запросы пользователя.
2. Каждый запрос экспортируется с полным текстом и метаданными.
3. Результаты выполнения и история изменений не включаются.
4. Данные онтологий и tenant не включаются — покрыты `REQ-NFR.DATA.decommission-export`.
