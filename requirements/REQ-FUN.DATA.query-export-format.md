## Назначение

Определить формат ZIP-архива для экспорта сохранённых SPARQL/CYPHER запросов пользователя.

## Требование

Архив имеет структуру:

```
query_export_{user_id}_{timestamp}.zip
├── manifest.json          # метаданные + hash-суммы файлов
├── sparql/
│   ├── {query_id}.sparql  # SPARQL-запрос с комментарием-заголовком
│   └── ...
├── cypher/
│   ├── {query_id}.cypher  # CYPHER-запрос с комментарием-заголовком
│   └── ...
└── metadata/
    └── queries.csv        # опционально, сводная таблица
```

**Файл `.sparql`** — текстовый файл с запросом и комментарием: имя, дата создания, тип, is_public, теги.

**Файл `.cypher`** — аналогично.

**`manifest.json`** содержит: версию экспорта, user_id, username, дату, общее количество запросов, список запросов с метаданными и SHA-256 hash каждого файла.

## Критерии приёмки

1. Экспорт формируется в ZIP-архиве.
2. `.sparql` и `.cypher` файлы содержат запрос и метаданные в заголовке.
3. `manifest.json` содержит полный перечень с hash-суммами.
4. Структура архива соответствует схеме.
5. Hash-суммы позволяют проверить целостность после скачивания.
