## Назначение

Обеспечить проверку целостности сгенерированного экспорта запросов.

## Требование

1. `manifest.json` содержит SHA-256 hash каждого файла.
2. Структура архива проверяется при создании (все обязательные директории присутствуют).
3. `.sparql`/`.cypher` файлы опционально проверяются на синтаксическую корректность.
4. При повреждении архива пользователь видит ошибку до скачивания.

**Инструкция для пользователя (включается в экспорт):**
```
unzip -t query_export_*.zip          # проверка структуры
sha256sum sparql/*.sparql cypher/*.cypher  # проверка hash
```

## Критерии приёмки

1. `manifest.json` содержит hash каждого файла.
2. Валидация выполняется при создании экспорта.
3. При ошибке валидации экспорт не предоставляется пользователю.
4. README с инструкцией по проверке целостности включается в архив.
