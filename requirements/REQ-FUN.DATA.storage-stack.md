## Назначение

Определить компоненты для хранения данных VEDO Core.

## Требование

VEDO Core требует стек хранения данных, покрывающий разные типы данных:
- **Графовое хранилище** — для хранения и запросов RDF/OWL графов (TBox, ABox) с поддержкой Cypher и корпоративной кластеризации
- **Version Store** — реляционное хранение с версионированием (коммиты, ветки, diff)
- **Кэш и блокировки** — TTL-кэширование и распределённые блокировки с низкой задержкой
- **Очереди сообщений** — event-driven конвейер для уведомлений и фоновых задач

Базовый MIT-дистрибутив не должен требовать функций Enterprise-класса (кластеризация, HA/failover, enterprise backup).
