# История AI-подсказок для сущности

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.DATA.suggestion-history |
| **Уровень** | FUN |
| **Атрибут качества** | Functionality |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | vision.md (F5 — аналогичный паттерн комментариев) |

---

## Назначение

Сохранять историю AI-подсказок для каждой сущности с возможностью просмотра и аудита.

## Требование

Система сохраняет историю подсказок для каждой сущности, показывая, какие подсказки были предложены, приняты или отклонены.

**История включает поля:**

- `timestamp` — когда была предложена
- `suggestion_type` — subClassOf / ObjectProperty / DatatypeProperty / EquivalentClass / DisjointClass
- `details` — какая связь предлагалась
- `confidence` — уверенность LLM (0–100%)
- `status` — pending / accepted / rejected / applied_manually
- `action_by` — кто принял/отклонил

## Критерии приёмки

1. История подсказок доступна для каждой сущности.
2. Отображается в отдельной вкладке/панели.
3. Фильтрация по статусу (pending / accepted / rejected).
4. Отклонённая подсказка не предлагается повторно.
5. История хранится в составе версионирования (коммиты).
