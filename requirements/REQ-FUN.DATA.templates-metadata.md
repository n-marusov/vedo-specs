| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.DATA.templates-metadata |
| **Уровень** | FUN |

| **Источник** | Уточнение стейкхолдера по вопросу 2.4 матрицы качества M2 |

---

## Назначение

Определить схему метаданных шаблона онтологии.

## Требование

Каждый шаблон имеет метаданные в формате JSON со следующими полями:

| Поле | Тип | Обязательное | Описание |
|------|-----|-------------|----------|
| `id` | UUID | Да | Уникальный идентификатор |
| `name` | string | Да | Название шаблона |
| `description` | string | Да | Описание назначения и области применения |
| `version` | semver | Да | Версия (MAJOR.MINOR.PATCH) |
| `created_at` | datetime | Да | Дата создания |
| `updated_at` | datetime | Да | Дата последнего обновления |
| `last_reviewed_at` | datetime | Да | Дата последнего пересмотра |
| `author_id` | UUID | Да | Автор шаблона |
| `author_name` | string | Да | Имя автора (отображаемое) |
| `source` | enum | Да | `internal` / `community` |
| `status` | enum | Да | `active` / `deprecated` / `archived` |
| `usage_count` | integer | Да | Количество использований |
| `tags` | string[] | Да | Теги для поиска |
| `category` | string | Да | Категория |
| `example` | string | Нет | Краткий пример использования |
| `ontology_id` | UUID | Нет | Ссылка на онтологию-источник |
| `deprecated_at` | datetime | Нет | Дата deprecation |
| `deprecated_reason` | string | Нет | Причина deprecation |

## Критерии приёмки

1. Все обязательные поля заполнены при создании шаблона.
2. Метаданные хранятся в `metadata.json` рядом с `template.owl`.
3. `version` соответствует semver (MAJOR.MINOR.PATCH).
4. `usage_count` автоматически инкрементируется при использовании шаблона.
5. `updated_at` обновляется при любом изменении метаданных или OWL-файла.
