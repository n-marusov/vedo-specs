## Назначение

Предоставить API для программного доступа к audit-логам MCP-инструментов.

## Требование

**API Endpoints (доступ: администратор tenant):**

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/v1/audit/mcp` | GET | Список логов с фильтрацией |
| `/api/v1/audit/mcp/{id}` | GET | Детали конкретного вызова |
| `/api/v1/audit/mcp/export` | POST | Экспорт логов |

**Параметры фильтрации:** `start_date`, `end_date`, `user_id`, `tool_name`, `status`, `source`, `limit`, `offset`.

## Критерии приёмки

1. API доступен для администратора tenant.
2. Фильтрация работает по всем параметрам.
3. Экспорт доступен.
4. Документация OpenAPI обновлена.
5. Rate limiting применяется (60 запросов/мин).
