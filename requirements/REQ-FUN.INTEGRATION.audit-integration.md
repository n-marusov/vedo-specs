## Назначение

Интегрировать аудит MCP-инструментов с общей системой аудита VEDO.

## Требование

Интеграция включает:

1. **Единое хранилище:** Логи MCP хранятся в той же системе, что и другие аудит-логи
2. **Единый интерфейс:** Поиск и просмотр через общий UI аудита
3. **Единые политики:** Retention, маскировка, доступ — едины для всех типов логов
4. **Единый API:** Доступ через общий `/api/v1/audit` с фильтром `source=mcp`
5. **Единый trace_id:** Связывание MCP-вызовов с observability (OpenTelemetry)

## Критерии приёмки

1. Логи MCP доступны в общей системе аудита.
2. Поиск работает по всем типам логов (включая MCP).
3. Политики retention едины для всех логов.
4. API аудита включает MCP-логи через фильтр `source=mcp`.
5. `trace_id` связывает MCP-логи с OpenTelemetry-трассировкой.
