## Назначение

Определить формулу расчёта стоимости каждого AI-запроса на основе выбранного провайдера, модели и объёма токенов.

## Требование

Система рассчитывает стоимость каждого AI-запроса на основе:

1. **Провайдер и модель** (выбранные пользователем или политикой)
2. **Количество входных токенов** (prompt)
3. **Количество выходных токенов** (completion)
4. **Кэшированные токены** (если применимо — сниженный тариф)

**Формула:**

```
Стоимость (в USD) = input_tokens × цена_input(провайдер, модель) 
                   + output_tokens × цена_output(провайдер, модель)
```

**Таблицы тарифов (reference):**

| Провайдер | Модель | Цена input (за 1M) | Цена output (за 1M) |
|-----------|--------|-------------------|---------------------|
| OpenAI | GPT-4o | $5.00 | $15.00 |
| OpenAI | GPT-4 | $30.00 | $60.00 |
| OpenAI | GPT-4o-mini | $0.15 | $0.60 |
| Anthropic | Claude 3 Opus | $15.00 | $75.00 |
| Anthropic | Claude 3 Sonnet | $3.00 | $15.00 |
| Anthropic | Claude 3 Haiku | $0.25 | $1.25 |
| Google | Gemini 1.5 Pro | $2.50 | $10.00 |
| Google | Gemini 1.5 Flash | $0.075 | $0.30 |
| Local | Llama 3 / Qwen | $0 | $0 |

**Кэшированные токены:** Списываются по тарифу, сниженному на 50% (аналог GitHub Copilot cache discount).

## Критерии приёмки

1. Стоимость рассчитывается по фактическому использованию токенов.
2. Используются актуальные тарифы провайдера (синхронизация не реже 1 раза в сутки).
3. Кэшированные токены списываются по сниженному тарифу (50% от базового).
4. В дашборде отображается детализация по провайдерам и моделям.
5. Аудит фиксирует каждый расчёт стоимости.
