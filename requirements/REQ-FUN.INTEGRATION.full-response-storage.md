# Хранение полных результатов MCP-инструментов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-FUN.INTEGRATION.full-response-storage |
| **Уровень** | FUN |
| **Атрибут качества** | Supportability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.5 матрицы качества M2 |

---

## Назначение

Обеспечить хранение полных результатов MCP-инструментов в отдельном защищённом хранилище.

## Требование

Полные результаты хранятся в S3/MinIO отдельно от основного audit-лога (PostgreSQL):

- **PostgreSQL:** метаданные + `response_truncated` (500 символов) + `response_full_url`
- **S3/MinIO:** полный результат (raw JSON/Turtle/CSV)
- **TTL:** 90 дней, автоматическое удаление
- **Доступ:** только администратор tenant

## Критерии приёмки

1. Полные результаты хранятся в отдельном хранилище (S3/MinIO).
2. Доступ к полным результатам ограничен ролью администратора.
3. Ссылка `response_full_url` сохраняется в audit-записи.
4. Автоматическое удаление через 90 дней.
5. Хранилище защищено: шифрование at rest, доступ по IAM-ролям.
