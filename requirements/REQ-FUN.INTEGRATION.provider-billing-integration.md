## Назначение

Обеспечить интеграцию с биллинговыми API LLM-провайдеров для получения точных данных о затратах на токены.

## Требование

Система интегрируется с биллинговыми API LLM-провайдеров для получения точных данных о затратах на токены и конвертации их в AI Credits.

**Источники данных:**

| Провайдер | API | Данные |
|---|---|---|
| OpenAI | Usage API | Токены input/output, стоимость в USD |
| Anthropic | Usage API | Токены input/output, стоимость в USD |
| Google | Usage API | Токены input/output, стоимость в USD |
| Local (on-premise) | — | Не отслеживается (вне биллинга) |

**Метод получения:**

1. **Периодический опрос:** Каждые 5-15 минут система запрашивает usage API провайдера.
2. **Агрегация:** Суммирует затраты по всем пользователям tenant за текущий месяц.
3. **Конвертация:** Переводит затраты в USD → AI Credits (1 Credit = $1 USD).

## Критерии приёмки

1. Система получает данные usage из API провайдеров.
2. Данные агрегируются по tenant.
3. Задержка ≤ 15 минут.
4. При недоступности API провайдера используется последнее известное значение + предупреждение.
5. Аудит-лог фиксирует все запросы к биллинговым API.
6. 1 AI Credit = $1 USD (фиксированный курс для простоты).
