---

## Назначение

Обеспечить автоматическую синхронизацию тарифов LLM-провайдеров для поддержания актуальности цен.

## Требование

Система может автоматически синхронизировать тарифы с официальными API провайдеров (если доступны) для поддержания актуальности цен.

**Метод синхронизации:**

1. **Периодический опрос:** Ежедневно в 00:00 UTC.
2. **Ручной триггер:** Администратор может запустить синхронизацию вручную.
3. **Webhook:** При изменении тарифов провайдер отправляет webhook (если поддерживает).

## Критерии приёмки

1. Автоматическая синхронизация выполняется ежедневно.
2. Администратор может запустить синхронизацию вручную.
3. При изменении тарифов — уведомление администратору.
4. В случае ошибки синхронизации — используются последние известные тарифы.
5. История синхронизаций доступна в audit.
