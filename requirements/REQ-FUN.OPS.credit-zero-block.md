## Назначение

Определить поведение системы при исчерпании AI Credits — блокировка AI-функций при сохранении работоспособности платформы.

## Требование

При исчерпании AI Credits (баланс ≤ 0) доступ к AI-функциям блокируется для всех пользователей организации до пополнения баланса.

**Поведение:**

1. **При каждом AI-запросе** система проверяет баланс Credits.
2. **При балансе ≤ 0** запрос отклоняется.
3. **Сообщение пользователю:** «AI Credits исчерпаны. Обратитесь к администратору для пополнения баланса.»
4. **Остальные функции VEDO** продолжают работать (платформа не блокируется).
5. **Разблокировка:** При пополнении баланса AI-функции автоматически разблокируются.

## Критерии приёмки

1. При балансе ≤ 0 AI-функции блокируются в течение 5 минут.
2. Пользователи видят понятное сообщение.
3. Администратор получает уведомление о блокировке.
4. Платформа VEDO продолжает работать.
5. При пополнении баланса блокировка снимается автоматически.
