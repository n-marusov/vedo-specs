## Назначение

Предоставить администратору возможность ручного управления circuit breaker через CLI, API и UI.

## Требование

Администратор может перевести circuit breaker в любое состояние для управления инцидентами.

**Доступные команды:** `open`, `close`, `half-open`, `status`.

**Интерфейсы управления:**
- **CLI:** `vedo-cli sparql circuit-breaker --state open`
- **API:** `POST /api/v1/admin/sparql/circuit-breaker`
- **UI:** Административная панель с переключателем состояний

## Критерии приёмки

1. Администратор может перевести circuit breaker через CLI.
2. Администратор может перевести через API (с аутентификацией).
3. Ручное изменение логируется в audit с указанием user_id.
4. При ручном OPEN автоматическое восстановление отключается.
5. При ручном CLOSED автоматический мониторинг возобновляется.
