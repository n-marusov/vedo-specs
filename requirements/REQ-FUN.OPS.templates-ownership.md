## Назначение

Определить модель владения и управления шаблонами онтологий.

## Требование

**Владелец шаблонов (MVP):** Команда VEDO. Сообщество может предлагать новые шаблоны через Pull Request.

**Модель управления:**

| Роль | Права |
|------|-------|
| **Команда VEDO** | Создание, обновление, deprecation, удаление официальных шаблонов |
| **Сообщество** | Предложение шаблонов через PR, использование шаблонов |
| **Пользователь** | Использование шаблонов, создание личных шаблонов из своих онтологий |

**Источники шаблонов:**
- `internal` — созданные и поддерживаемые командой VEDO
- `community` — предложенные сообществом (после review)

## Критерии приёмки

1. Команда VEDO может создавать, обновлять и архивировать официальные шаблоны.
2. Сообщество может предлагать шаблоны через PR в репозиторий шаблонов.
3. Пользователь может создать личный шаблон из своей онтологии (кнопка «Сохранить как шаблон»).
4. Поле `source` в метаданных различает `internal` и `community` шаблоны.
5. Поле `status` поддерживает: `active`, `deprecated`, `archived`.
