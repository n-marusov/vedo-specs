## Назначение

Определить состав и порядок работы автоматического evaluation suite для NL→OWL генерации в CI/CD.

## Требование

CI/CD включает автоматический evaluation suite для NL→OWL генерации. Suite содержит 50 тестовых пар (NL-описание ↔ эталонная OWL-онтология), созданных вручную экспертами-онтологами.

**Состав тестового набора:**

| Категория | Количество | Описание |
|-----------|------------|----------|
| Простая иерархия | 10 тестов | 3-5 классов, 2-3 свойства |
| Средняя сложность | 20 тестов | 8-12 классов, 5-8 свойств |
| Сложная иерархия | 15 тестов | 15-20 классов, 10-15 свойств |
| Edge cases | 5 тестов | Пустое описание, конфликтующие сущности, неоднозначные термины |

**Покрытие предметных областей:**

- Организационная структура
- Продукт/каталог
- Процесс/workflow
- Глоссарий/термины
- Биологические/медицинские (опционально, для тестирования domain-specific лексики)

## Критерии приёмки

1. Suite существует и содержит 50 тестов.
2. Тесты созданы с участием эксперта-онтолога.
3. Suite запускается в CI/CD при каждом изменении AI-промптов или LLM-модели.
4. Результаты доступны в CI/CD отчёте с детализацией по каждому тесту.
5. При падении ниже пороговых значений (`REQ-FUN.API.class-hierarchy-accuracy`, `REQ-FUN.API.properties-accuracy`, `REQ-FUN.API.no-cyclic-hierarchy`, `REQ-FUN.API.owl-syntax-validity`) билд блокируется.
6. Эталонные онтологии в тестовом наборе версионируются вместе с кодом.
