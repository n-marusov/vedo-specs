## Что фиксирует артефакт

Этот артефакт закрывает вопрос M2.2: «Поддерживается ли обратная совместимость API?».

Обратная совместимость API означает, что клиент, написанный под старую версию, например 1.0, продолжает работать с новой версией без изменений кода.

## Решение для VEDO Core

Для VEDO Core как enterprise-ориентированного продукта выбирается расширенная совместимость (`compatible`) между мажорными версиями с периодом устаревания.

Внутри одной мажорной версии действует строгая совместимость: допускаются только добавления, которые не ломают существующих клиентов.

## Типы совместимости

| Тип совместимости | Что не ломается | Что можно менять |
|-------------------|-----------------|------------------|
| Полная (strict) | Всё: URL, параметры, типы, коды ответов | Только добавление новых полей/опций |
| Расширенная | Основные сценарии: CRUD, поиск | Удаление устаревших полей с deprecation |
| Отсутствует | Ничего | Любые изменения |

## Политика по типам API

| Тип API | Что меняется в мажорной версии | Период устаревания | Обратная совместимость |
|---------|-------------------------------|--------------------|------------------------|
| REST API | URL + major версия в пути: `/v1/` -> `/v2/` | 1 год | Одновременная поддержка v1 и v2 |
| GraphQL | Схема и изменения в типах | 1 год | Директива устаревания |
| gRPC | Protobuf, можно добавлять поля | Без периода устаревания | Совместимость по Protocol Buffers |
| SPARQL endpoint | Редко, почти никогда | Не применимо | Совместим всегда как стандарт W3C |

## Ответ заказчику

«VEDO Core обеспечивает обратную совместимость API между мажорными версиями с 12-месячным периодом уведомления.

REST API: версионирование через `/v1`, `/v2`; обе версии работают одновременно не менее года. GraphQL: deprecated-директивы, удаление полей только через 9 месяцев после предупреждения. gRPC: совместимость по правилам Protocol Buffers. SPARQL endpoint: обратно совместим навсегда как стандарт W3C.

Клиенты, использующие старые API, могут продолжать работать, но новые возможности доступны только через актуальные API. Для критических интеграций предоставляется LTS-версия на 2 года. Дата окончания поддержки v1 публикуется не менее чем за 12 месяцев».
