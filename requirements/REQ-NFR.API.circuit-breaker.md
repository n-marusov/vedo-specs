# Circuit breaker для защиты SPARQL endpoint от перегрузки

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.API.circuit-breaker |
| **Уровень** | NFR |
| **Атрибут качества** | Reliability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.3 матрицы качества M2 |

---

## Назначение

Защитить SPARQL endpoint от перегрузки через автоматический circuit breaker, отклоняющий запросы при деградации производительности.

## Требование

Circuit breaker работает в трёх состояниях: CLOSED, OPEN, HALF-OPEN.

**Параметры переключения:**

| Параметр | Значение |
|----------|----------|
| Порог открытия | p95 latency > 5 сек в течение 60 сек |
| Окно измерения | 60 секунд |
| Минимальное количество запросов | 10 (для расчёта p95) |
| Half-open период | Каждые 15 секунд |
| Порог восстановления | 3 успешных запроса подряд |
| Порог повторного открытия | 1 ошибка в HALF-OPEN |

**Поведение по состояниям:**
- **CLOSED:** Все запросы выполняются нормально.
- **OPEN:** Все запросы отклоняются с HTTP 503.
- **HALF-OPEN:** Пропускается ограниченное число запросов для проверки восстановления.

## Критерии приёмки

1. Автоматический переход в OPEN при p95 > 5 сек в течение 60 сек.
2. В OPEN все запросы возвращают HTTP 503.
3. Каждые 15 секунд — half-open проверка.
4. При 3 успешных запросах подряд — переход в CLOSED.
5. При ошибке в HALF-OPEN — возврат в OPEN.
6. Все переходы логируются в audit и отправляют алерт.
