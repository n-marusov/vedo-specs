## Назначение

Обеспечить асинхронный режим импорта для больших файлов с уведомлением пользователя по email при завершении.

## Требование

Для файлов с количеством строк > 1,000 импорт выполняется асинхронно. Пользователь получает уведомление по email при завершении.

**Порог для асинхронного режима:** > 1,000 строк.

**Поведение:**

1. **Запрос:** Пользователь загружает файл, система возвращает task_id.
2. **Статус:** Пользователь может отслеживать прогресс (в % или количестве обработанных строк).
3. **Завершение:** При завершении пользователь получает email с результатом (успех / количество импортированных строк / ошибки).
4. **Ошибка:** При ошибке пользователь получает email с отчётом об ошибках.

## Критерии приёмки

1. При файлах > 1,000 строк импорт переходит в асинхронный режим.
2. Пользователь получает task_id и ссылку на отслеживание статуса.
3. Прогресс отображается в интерфейсе (проценты/строки).
4. При завершении — email с результатом.
5. При ошибке — email с отчётом об ошибках.
