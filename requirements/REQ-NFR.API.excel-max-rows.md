# Максимальное количество строк в Excel-файле для импорта

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.API.excel-max-rows |
| **Уровень** | NFR |
| **Атрибут качества** | Performance |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.6 матрицы качества M2 |

---

## Назначение

Ограничить максимальное количество строк в Excel-файле для импорта.

## Требование

Система поддерживает импорт Excel-файлов с количеством строк до указанного лимита.

**Пороговое значение:** **≤ 10,000 строк**.

**Поведение при превышении:**
Файл отклоняется с сообщением: «Файл содержит более 10,000 строк. Максимальный поддерживаемый размер — 10,000 строк. Пожалуйста, разделите данные на несколько файлов или обратитесь к администратору.»

## Критерии приёмки

1. Файлы с ≤ 10,000 строк принимаются к импорту.
2. Файлы с > 10,000 строк отклоняются.
3. Сообщение об ошибке содержит лимит и рекомендацию.
4. Enterprise-тенанты могут иметь увеличенный лимит (конфигурируется).
5. При частичной загрузке (если разрешено) — обрабатываются первые 10,000 строк.
