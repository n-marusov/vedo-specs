# Максимальный размер Excel-файла в МБ

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.API.excel-max-size |
| **Уровень** | NFR |
| **Атрибут качества** | Performance |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.6 матрицы качества M2 |

---

## Назначение

Ограничить максимальный размер Excel-файла для импорта.

## Требование

Система поддерживает импорт Excel-файлов размером до указанного лимита.

**Пороговое значение:** **≤ 5 МБ**.

**Поведение при превышении:**
Файл отклоняется с сообщением: «Размер файла превышает 5 МБ. Максимальный поддерживаемый размер — 5 МБ. Пожалуйста, оптимизируйте файл или обратитесь к администратору.»

## Критерии приёмки

1. Файлы с размером ≤ 5 МБ принимаются к импорту.
2. Файлы с размером > 5 МБ отклоняются.
3. Сообщение об ошибке содержит лимит и рекомендацию.
4. Enterprise-тенанты могут иметь увеличенный лимит (конфигурируется).
5. Валидация размера выполняется до загрузки файла на сервер (client-side check + server-side enforcement).
