## Подход

SPARQL endpoint считается обратно совместимым «навсегда», потому что SPARQL является стандартом W3C.

VEDO Core не вносит собственных breaking changes на уровне спецификации SPARQL.

## Политика

- Endpoint сохраняет совместимость на уровне спецификации W3C.
- Изменения в major versions VEDO Core не должны ломать стандартное поведение SPARQL.
- Deprecation period не применяется.
