## Назначение

Определить допустимые значения времени генерации AI-подсказок для интерактивного использования.

## Требование

Генерация AI-подсказок должна происходить достаточно быстро, чтобы не нарушать поток работы пользователя.

**Пороговые значения (многомерное распределение latency):**

| Окружение | p50 | p95 | p99 |
|---|---|---|---|
| **SaaS (внешний LLM)** | ≤ 3 сек | ≤ 7 сек | ≤ 10 сек |
| **On-premise (локальная LLM)** | ≤ 5 сек | ≤ 12 сек | ≤ 20 сек |

## Критерии приёмки

1. Метрики времени генерации собираются в production через OpenTelemetry.
2. Алерт срабатывает при p95 > порогового значения.
3. В UI отображается индикатор загрузки при генерации.
4. При превышении времени генерации — подсказки могут не отобразиться (graceful degradation).
5. Кэширование подсказок для часто редактируемых сущностей (TTL 60 сек).
