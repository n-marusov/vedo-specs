# Время выполнения полной валидации OWL-онтологии

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.API.validation-latency |
| **Уровень** | NFR |
| **Атрибут качества** | Performance |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.2 матрицы качества M2 |

---

## Назначение

Определить допустимые значения времени полной валидации OWL-онтологии для интерактивного использования.

## Требование

Время полной валидации должно оставаться в пределах, приемлемых для интерактивной работы.

**Пороговые значения (многомерное распределение latency):**

| Размер онтологии | p50 | p95 | p99 |
|------------------|-----|-----|-----|
| 10 классов, 5 свойств | ≤ 500 мс | ≤ 1 с | ≤ 2 с |
| 50 классов, 25 свойств | ≤ 2 с | ≤ 4 с | ≤ 6 с |
| 100 классов, 50 свойств | ≤ 5 с | ≤ 10 с | ≤ 15 с |

## Критерии приёмки

1. Метрики времени валидации собираются в production через OpenTelemetry.
2. Алерт срабатывает при p95 > порогового значения.
3. В UI отображается индикатор выполнения валидации.
4. При превышении времени пользователь может прервать валидацию.
5. Оптимизация: прерывание при обнаружении первой критической ошибки.
