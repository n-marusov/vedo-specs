# Срок хранения audit-логов MCP-инструментов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.DATA.audit-retention |
| **Уровень** | NFR |
| **Атрибут качества** | Supportability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.5 матрицы качества M2 |

---

## Назначение

Определить сроки хранения различных категорий audit-данных MCP-инструментов.

## Требование

| Тип данных | Срок хранения | Действие после срока |
|------------|---------------|----------------------|
| **Полные логи** (запрос + полный результат) | **90 дней** | Удаление |
| **Метаданные** (без полного текста) | **365 дней** | Архивирование (опционально) |
| **Агрегированная аналитика** | Бессрочно | Хранение обезличенных данных |

**Исключения:**
- Enterprise-тенанты могут запросить увеличенный срок (индивидуально)
- При активном расследовании инцидента логи могут быть заморожены

## Критерии приёмки

1. Полные логи автоматически удаляются через 90 дней.
2. Метаданные хранятся 365 дней.
3. Агрегированная аналитика хранится бессрочно.
4. Администратор может запросить увеличение срока.
5. При активном расследовании логи замораживаются.
