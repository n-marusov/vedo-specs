| **ID** | REQ-NFR.DATA.deprecation-audit |
| **Уровень** | NFR |
| **Атрибут качества** | Supportability |

| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.2 матрицы качества M2 |

---

## Назначение

Логировать все события deprecation и отключения API endpoint'ов.

## Требование

Логируемые события: объявление deprecation, изменение даты (включая grace period), отключение endpoint'а.

Поля: endpoint, дата объявления, дата отключения, причина. Изменения даты — с указанием причины (grace period / перенос). Логи хранятся ≥ 365 дней.

## Критерии приёмки

1. Каждое событие логируется.
2. Все обязательные поля заполнены.
3. Изменения даты логируются с причиной.
4. Отключение логируется.
5. Хранение ≥ 365 дней.
