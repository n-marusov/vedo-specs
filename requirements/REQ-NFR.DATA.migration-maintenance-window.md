## Уведомление заказчиков

Правила уведомления:

- SaaS: email, баннер в интерфейсе, статусная страница минимум за 14 дней.
- On-premise: релизные заметки и документация по миграции; заказчик выбирает окно.
- Приватное облако: согласование окна миграции минимум за 30 дней.

## Окно миграции

SLA по даунтайму:

- SaaS free tier: допустимый даунтайм 8 часов ночью, желаемое окно воскресенье 2:00-10:00 МСК.
- SaaS Enterprise: допустимый даунтайм 2 часа по согласованию, желаемое окно суббота 0:00-6:00 по согласованию.
- On-premise: по SLA с заказчиком, окно по желанию заказчика.

Ориентир: GitHub Enterprise требует около 1 часа даунтайма при мажорном обновлении, на практике около 30 минут.
