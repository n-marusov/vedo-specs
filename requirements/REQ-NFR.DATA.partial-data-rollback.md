## Подход

Вместо полного отката версии можно откатить отдельные изменения через Git-подобный механизм VEDO Core.

Это не требует переключения версии ПО и применяется, если ошибка находится в самих данных, а не в коде или схеме новой версии.

## Пример операции

```bash
vedo-cli log --oneline
vedo-cli rollback --commit=abc1234
```

## Когда применять

Частичный rollback применим, если:

- Ошибка локализована в данных или отдельном классе.
- Данные находятся в версионном хранилище.
- Не требуется откат схемы Neo4j/PostgreSQL.
- Код новой версии работоспособен.

## RTO

Ожидаемый RTO для частичного rollback: 10-30 минут.
