# Аудит экспорта сохранённых запросов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.DATA.query-export-audit |
| **Уровень** | NFR |
| **Атрибут качества** | Supportability |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.1 матрицы качества M2 |

---

## Назначение

Логировать каждый экспорт запросов для compliance-отчётности и chain of custody.

## Требование

**Логируемые поля:** `timestamp`, `user_id`, `export_type` (manual/deletion), `total_queries`, `export_format` (zip), `status` (processing/ready/downloaded/deleted), `download_count`, `ip_address` (опционально).

Логи хранятся минимум 365 дней (как метаданные аудита). Доступ ограничен администратором VEDO.

## Критерии приёмки

1. Каждый экспорт логируется.
2. Все обязательные поля заполнены.
3. Логи хранятся ≥ 365 дней.
4. Доступ ограничен администратором.
5. Логи используются для compliance-отчётности (GDPR Article 20 compliance).
