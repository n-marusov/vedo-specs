# Автоматическое удаление экспорта по истечении срока

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.DATA.query-export-auto-delete |
| **Уровень** | NFR |
| **Атрибут качества** | Reliability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.1 матрицы качества M2 |

---

## Назначение

Автоматически удалять файлы экспорта и записи в БД по истечении срока хранения.

## Требование

**PostgreSQL (ежедневный скрипт):**
```sql
DELETE FROM query_exports
WHERE status = 'ready'
  AND ((created_at < NOW() - INTERVAL '7 days' AND is_deletion_export = false)
    OR (created_at < NOW() - INTERVAL '30 days' AND is_deletion_export = true));
```

**S3 lifecycle:** Автоматическое удаление объектов старше 30 дней в префиксе `exports/queries/`.

## Критерии приёмки

1. Экспорты автоматически удаляются по истечении срока.
2. Удаление включает файлы (S3) и записи (PostgreSQL).
3. Пользователь получает уведомление перед удалением.
4. Удаление логируется в audit.
5. После удаления восстановление невозможно.
