# Срок хранения экспорта сохранённых запросов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.DATA.query-export-retention |
| **Уровень** | NFR |
| **Атрибут качества** | Reliability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.1 матрицы качества M2 |
| **Связанные REQ** | `REQ-NFR.DATA.decommission-export` (7-дневная ссылка) |

---

## Назначение

Определить сроки хранения сгенерированного экспорта запросов.

## Требование

Сроки согласованы с существующими политиками (`REQ-NFR.DATA.decommission-export`):

| Сценарий | Срок | После |
|----------|------|-------|
| **Экспорт по запросу (не при удалении)** | **7 дней** | Автоудаление (как в `decommission-export`) |
| **Экспорт при удалении аккаунта** | **30 дней** | Совпадает с периодом охлаждения (`account-closure-retention`) |
| **После удаления аккаунта** | **0 дней** | Безвозвратное удаление |

## Критерии приёмки

1. Экспорт по запросу доступен 7 дней (согласовано с `decommission-export`).
2. Экспорт при удалении доступен 30 дней (согласовано с `account-closure-retention`).
3. Ссылка деактивируется автоматически.
4. Пользователь получает напоминание за 2 дня до истечения.
5. После удаления аккаунта экспорт удаляется безвозвратно.
