# Поддержка экспорта большого количества запросов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.DATA.query-export-scaling |
| **Уровень** | NFR |
| **Атрибут качества** | Performance |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.1 матрицы качества M2 |

---

## Назначение

Обеспечить стабильную работу экспорта при большом количестве сохранённых запросов.

## Требование

| Количество запросов | Время | Режим |
|---------------------|-------|-------|
| ≤ 50 | ≤ 5 сек | Синхронный |
| 51-500 | ≤ 30 сек | Асинхронный (email) |
| 501-5000 | ≤ 5 мин | Асинхронный (email + прогресс) |
| > 5000 | ≤ 30 мин | Асинхронный (email + ссылка) |

## Критерии приёмки

1. ≤ 50 запросов — синхронно.
2. > 50 запросов — асинхронно.
3. При > 500 запросах — прогресс-бар.
4. При > 5000 запросах — email-уведомление.
5. Система не деградирует при большом количестве запросов.
