## Цель

VEDO Core должен снижать вероятность полного rollback мажорной версии за счет предварительных проверок, постепенного включения и быстрого обнаружения проблем.

## Механизмы

| Механизм | Описание | Позволяет избежать rollback |
|----------|----------|-----------------------------|
| Бэкап перед миграцией | Полный backup TBox, ABox, Version Store, LFS | Нет, но обеспечивает восстановление |
| Тестовая миграция в песочнице | Production-like migration на копии данных | Да |
| Feature flag для миграции данных | Миграция включается постепенно: 0%, 1%, 100% трафика | Да |
| Откат отдельных классов | Ошибка в одном классе откатывается через commit | Да |
| Canary deployment | 1% трафика на новую версию | Да |
| Shadow mode | Новая версия получает трафик, но не отвечает пользователю | Да |
| Grafana dashboards | Ошибки, latency, health и признаки деградации | Да |
| Rollback plan | Runbook процедуры восстановления | Нет, но уменьшает RTO |
