> Определяет, какие языки используются для разных типов контента в VEDO Core.

---

## Назначение

VEDO Core ведётся русскоязычной командой и ориентирован на клиентов, для которых русскоязычные артефакты, документация, runbooks и материалы для заказчиков являются базовым требованием. Одновременно пользовательский интерфейс должен поддерживать многоязычность, чтобы продукт мог поставляться SaaS, on-premise и корпоративным клиентам в разных юрисдикциях.

---

## Языковая политика

| Тип контента | Язык | Обоснование |
|-------------|------|-------------|
| Human-артефакты, документация, runbooks, материалы для заказчиков | Русский | Соответствует языковой среде команды и заказчиков |
| UI (интерфейс пользователя) | i18n (русский по умолчанию MVP + английский второй язык) | Многоязычные поставки без переписывания компонентов |
| Технические идентификаторы, API, error codes | Английский | Точность терминов, совместимость с инструментами и протоколами |

---

## Требования

### Human-артефакты и документация

1. Все документы в `human/artifacts/` пишутся на русском языке.
2. Customer-facing документация, runbooks и руководства пишутся на русском языке.
3. Технические термины (IRI, SPARQL, OWL, RDF, API и т.д.) сохраняются на английском внутри русскоязычных документов.

### UI и интернационализация

1. UI-строки выносятся в файлы переводов (i18n framework).
2. Русский язык обязателен для MVP.
3. Английский язык — второй язык или запасной вариант (fallback).
4. Переключение языка не сбрасывает контекст: онтологию, ветку, фильтры, выбранный объект.
5. Допускается добавление других языков через i18n без изменения кода компонентов.

### Технические идентификаторы

1. Все API endpoints, protocol names, code blocks, error codes пишутся на английском.
2. Локализация технических идентификаторов запрещена — это ломает точность, совместимость и трассируемость.
