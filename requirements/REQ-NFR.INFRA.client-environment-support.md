## Категории поддержки

| Категория | MVP | Release 1.0 (Enterprise) |
|-----------|-----|--------------------------|
| Браузеры | Chrome (последние 2 версии), Firefox (последние 2) | + Safari (последние 2), + Edge |
| ОС | Windows 10/11, macOS Ventura+, Linux (Ubuntu 22.04+) | + Windows Server (on-premise) |
| Устройства | Desktop (1920×1080 minimum) | + Tablet (iPad, 1024×768), + Laptop (1366×768) |
| Минимальная сеть | 5 Mbps, latency < 200 ms | 2 Mbps, latency < 500 ms |
| Локали | ru-RU, en-US | + de-DE, + zh-CN (partial) |
| Масштабирование UI | До 150% без потери функциональности | До 200% |

## Hardware Requirements

### Minimal hardware configuration (для базовой работы)

| Компонент | Минимальное требование | Рекомендованное требование |
|-----------|------------------------|----------------------------|
| **RAM** | 4 GB | 8 GB |
| **CPU** | 2 ядра, 2.0 GHz | 4 ядра, 2.5 GHz+ |
| **Видеокарта** | Не требуется (WebGL на CPU) | Опционально (для 3D графа) |
| **Дисковое пространство** | 1 GB (кэш браузера + данные) | 5 GB (при активной работе) |

## Network Requirements

| Параметр | Минимальное требование | Рекомендованное требование | Примечание |
|----------|------------------------|----------------------------|------------|
| **Latency (RTT)** | ≤ 200 ms | ≤ 50 ms | Для приемлемой отзывчивости UI |
| **Download bandwidth** | ≥ 5 Mbps | ≥ 20 Mbps | Для загрузки графа и онтологий |
| **Upload bandwidth** | ≥ 1 Mbps | ≥ 5 Mbps | Для сохранения изменений и коммитов |
| **WebSocket latency** | ≤ 100 ms | ≤ 50 ms | Для чата (комментарии) |
| **Packet loss** | ≤ 1% | ≤ 0.1% | Влияет на стабильность WebSocket |

### Особенности при работе с большими онтологиями

При работе с онтологиями > 500 000 триплетов:

- RAM: **8 GB** (минимально), **16 GB** (рекомендовано)
- Bandwidth: **≥ 20 Mbps** (для загрузки подграфов)
- Latency: **≤ 100 ms** (для пагинации и ленивой загрузки)

### Измерение

- Клиентские метрики собираются через Performance API браузера (opt-in).
- Мониторинг latency — через API Gateway (замеры времени запросов).

## Тестирование

CI запускает browserstack/saucelabs на матрице браузеров при каждом релизе. Падение на любой обязательной конфигурации блокирует релиз.

## Бизнес-правила

- Chrome и Firefox (последние 2 major версии) обязательны для MVP.
- Safari и Edge добавляются в Release 1.0.
- Desktop разрешение 1920×1080 является минимальным для MVP.
- Минимальная скорость сети: 5 Mbps, latency < 200 ms для MVP.
- UI масштабируется до 150% без потери функциональности на MVP.
- Локали: ru-RU и en-US обязательны для MVP; de-DE и zh-CN (partial) — для Release 1.0.
- CI блокирует релиз при падении тестов на любой обязательной конфигурации браузера/ОС.
