## Что описывает

Определяет требования к отказоустойчивости control plane, независимости от data plane и аварийному контуру управления.

## Обязательные требования изоляции

| Требование | Критерий |
|---|---|
| Разделение control/data plane | Отдельные deployment units, namespaces и сетевые политики |
| Независимые зависимости | Control plane не должен зависеть от tenant data path для базовых операций управления |
| Межрегиональный failover control plane | RTO <= 15 минут |
| Доступность control API | >= 99.95% за 30 дней |

## Break-glass control channel

- Обязателен out-of-band канал управления (отдельная auth цепочка, отдельные credentials).
- Канал должен проходить ежемесячный smoke test доступности.
- Доля успешных smoke tests: 100%.

## Нагрузочные и аварийные тесты

- Ежеквартальный game day с симуляцией отказа control plane в primary регионе.
- Целевое время активации failover runbook: <= 5 минут.
- Целевое время восстановления операций управления: <= 15 минут.

## Бизнес-правила

- Изменения control plane без теста аварийного failover запрещены.
- Общие секреты между control plane и tenant workloads запрещены.
- Потеря control plane observability дольше 5 минут классифицируется как P0.
