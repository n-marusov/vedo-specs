## Назначение

Обеспечить сбор аналитики по AI-подсказкам для оценки качества и итеративного улучшения моделей.

## Требование

Система собирает аналитику по AI-подсказкам для оценки качества и улучшения промптов.

**Метрики:**

| Метрика | Описание |
|---|---|
| **Acceptance rate** | Доля принятых подсказок от всех предложенных |
| **Rejection rate** | Доля отклонённых подсказок |
| **Confidence vs acceptance** | Корреляция confidence и acceptance rate |
| **Average confidence** | Средняя уверенность всех подсказок |
| **Latency** | Время генерации подсказок (p50/p95/p99) |
| **Top suggestion types** | Какие типы подсказок чаще всего принимаются |
| **User feedback** | Ручная оценка качества подсказок (лайк/дизлайк) |

## Критерии приёмки

1. Метрики собираются анонимно (опционально для пользователей).
2. Дашборд доступен для продуктовой команды VEDO.
3. Данные используются для улучшения промптов и настройки порога confidence.
4. Пользователь может оценить подсказку (👍/👎) — опционально.
5. Конфиденциальность: данные не содержат контент онтологии (только метаданные и статистику).
