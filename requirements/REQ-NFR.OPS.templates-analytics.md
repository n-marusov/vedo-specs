# Аналитика использования шаблонов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.OPS.templates-analytics |
| **Уровень** | NFR |
| **Атрибут качества** | Supportability |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.4 матрицы качества M2 |

---

## Назначение

Обеспечить сбор аналитики использования шаблонов для принятия решений об обновлении, deprecation и удалении.

## Требование

Система собирает следующие метрики по шаблонам:

| Метрика | Описание | Использование |
|---------|----------|---------------|
| `usage_count` | Количество созданных онтологий из шаблона | Критерий удаления (< 5 за 6 мес) |
| `usage_trend` | Динамика использования за 6 месяцев | Выявление падения популярности |
| `avg_retention_days` | Среднее время жизни онтологии, созданной из шаблона | Оценка полезности шаблона |
| `modification_rate` | Доля онтологий, где пользователь изменил > 50% структуры | Оценка «пригодности» шаблона |
| `search_impressions` | Количество показов в каталоге | Оценка видимости |
| `search_clicks` | Количество кликов по шаблону в каталоге | Оценка привлекательности |
| `preview_to_apply_rate` | Конверсия из preview в применение | Оценка качества preview |

## Критерии приёмки

1. Все метрики собираются автоматически.
2. Дашборд доступен команде VEDO.
3. `usage_count` и `usage_trend` используются для автоматического deprecation (< 5 за 6 мес).
4. `avg_retention_days` и `modification_rate` используются для ручного анализа качества.
5. Данные анонимизированы (не содержат контент онтологий пользователей).
