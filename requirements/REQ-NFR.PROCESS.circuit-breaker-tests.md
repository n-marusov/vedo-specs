# Тестирование circuit breaker в CI/CD

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.PROCESS.circuit-breaker-tests |
| **Уровень** | NFR |
| **Атрибут качества** | Reliability |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.3 матрицы качества M2 |

---

## Назначение

Обеспечить автоматическое тестирование circuit breaker в CI/CD для предотвращения регрессий.

## Требование

**Тестовые сценарии:**

| Сценарий | Ожидаемый результат |
|----------|---------------------|
| Симуляция p95 > 5 сек в течение 60 сек | Переход в OPEN |
| В OPEN, через 15 сек | Переход в HALF-OPEN |
| В HALF-OPEN, 3 успешных запроса | Переход в CLOSED |
| В HALF-OPEN, 1 ошибка | Возврат в OPEN |
| API: `admin/circuit-breaker/open` | Ручной переход в OPEN |
| API: `admin/circuit-breaker/close` | Ручной переход в CLOSED |

## Критерии приёмки

1. Тесты выполняются в CI/CD и staging (не в production).
2. Каждый сценарий проверяет корректное поведение.
3. При регрессии билд блокируется.
4. Тесты обновляются при изменении параметров.
5. Результаты доступны в CI/CD отчёте.
