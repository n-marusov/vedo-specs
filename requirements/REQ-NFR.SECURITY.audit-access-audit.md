# Аудит доступа к audit-логам MCP-инструментов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.SECURITY.audit-access-audit |
| **Уровень** | NFR |
| **Атрибут качества** | Security |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.5 матрицы качества M2 |

---

## Назначение

Обеспечить аудит всех операций доступа к audit-логам (chain of custody).

## Требование

Каждое обращение к audit-логам MCP логируется:

| Событие | Описание |
|---------|----------|
| **Просмотр лога** | Пользователь открыл страницу с логами |
| **Экспорт логов** | Пользователь экспортировал логи |
| **Доступ к полному результату** | Пользователь запросил полный результат |
| **Удаление лога** | Автоматическое удаление по истечении срока |

**Поля записи:** `user_id`, `timestamp`, `action`, `resource_id`, `ip_address`, `trace_id`.

## Критерии приёмки

1. Каждый доступ к логам логируется.
2. Логи доступа хранятся 365 дней.
3. Администратор может просмотреть историю доступа.
4. Аномальный доступ (> 10 запросов за минуту) создаёт алерт P2.
