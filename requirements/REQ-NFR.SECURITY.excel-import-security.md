## Назначение

Обеспечить безопасность импорта Excel-файлов: защита от вредоносного кода, инъекций и несанкционированного доступа.

## Требование

Импорт Excel-файлов должен быть безопасным и не создавать угроз для системы.

**Меры безопасности:**

1. **Антивирусная проверка:** Файлы сканируются на вирусы перед обработкой.
2. **Запрет макросов:** Макросы в .xlsm файлах не выполняются (данные извлекаются без execution).
3. **Защита от инъекций:** Данные из Excel экранируются перед записью в базу данных.
4. **Ограничения размера:** Лимиты на размер файла (≤ 5 МБ) и количество строк (≤ 10,000).
5. **Аутентификация:** Только аутентифицированные пользователи с правами на запись могут импортировать.
6. **Аудит:** Все импорты логируются с указанием пользователя, файла, количества строк и результата.

## Критерии приёмки

1. Файлы проходят антивирусную проверку (интеграция с ClamAV или эквивалент).
2. Макросы не выполняются — извлекаются только данные ячеек.
3. Данные экранируются от SQL/SPARQL-инъекций перед записью.
4. Лимиты размера и строк проверяются до обработки файла.
5. Аудит всех импортов доступен администратору (user_id, filename, row_count, error_count, timestamp, status).
