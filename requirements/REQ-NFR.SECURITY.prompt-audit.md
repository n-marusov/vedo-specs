---

## Назначение

Обеспечить полный аудит всех блокировок промпт-инъекций для анализа инцидентов и реагирования.

## Требование

Каждая блокировка промпт-инъекции логируется в audit-системе.

**Логируемые поля:**

| Поле | Описание |
|------|----------|
| `timestamp` | Время блокировки |
| `user_id` | Кто отправил запрос |
| `ontology_id` | Какая онтология |
| `visibility_level` | public / internal / private |
| `request_preview` | Первые 100 символов запроса (с маскировкой sensitive data) |
| `blocked_by` | Фильтр / структура / длина |
| `blocked_pattern` | Какая фраза или паттерн вызвал блокировку |
| `trace_id` | OpenTelemetry trace_id |

## Критерии приёмки

1. Каждая блокировка создаёт audit-запись со всеми обязательными полями.
2. Записи хранятся минимум 90 дней.
3. Поиск по `user_id`, `ontology_id`, `blocked_by` работает.
4. Отчёт по заблокированным запросам доступен администратору.
5. При повторных блокировках от одного пользователя (> 5 за час) — уведомление администратору.
