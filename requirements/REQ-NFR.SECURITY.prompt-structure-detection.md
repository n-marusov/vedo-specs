## Назначение

Детектировать и блокировать NL-запросы, содержащие вложенные JSON/XML структуры, используемые для переопределения контекста LLM.

## Требование

Система детектирует попытки передачи вложенных JSON или XML структур в NL-запросах.

**Алгоритм детекции:**

1. **JSON детекция:** Поиск пар `{` и `}` с подсчётом уровня вложенности.
2. **XML детекция:** Поиск тегов `<...>` с проверкой на наличие закрывающих тегов и атрибутов.
3. **Порог вложенности JSON:** Блокировка при > 3 уровнях.
4. **Порог XML:** Блокировка при наличии XML-тегов с атрибутами.

## Критерии приёмки

1. Запросы с JSON-вложенностью > 3 блокируются.
2. Запросы с XML-тегами блокируются.
3. Пользователь получает сообщение: «Запрос содержит вложенные структуры данных и был заблокирован.»
4. Блокировка логируется в audit.
5. Порог вложенности конфигурируется администратором.
