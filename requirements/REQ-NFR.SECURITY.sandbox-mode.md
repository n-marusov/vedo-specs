# Режим «песочницы» для подозрительных NL-запросов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.SECURITY.sandbox-mode |
| **Уровень** | NFR |
| **Атрибут качества** | Security |
| **Приоритет** | P2 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.1 матрицы качества M2 |

---

## Назначение

Обеспечить изолированное выполнение подозрительных NL-запросов в режиме «песочницы» с ограниченными правами.

## Требование

При обнаружении подозрительных паттернов запрос выполняется в изолированном окружении:

1. **Ограничение контекста:** В LLM передаётся только минимальный контекст (без структуры онтологии).
2. **Ограничение прав:** Запрос не может модифицировать данные.
3. **Лимит токенов:** Уменьшенный лимит (50% от обычного).
4. **Аудит:** Повышенный уровень логирования.
5. **Результат:** При успешном выполнении возвращается с пометкой «песочница».

## Критерии приёмки

1. Подозрительные запросы выполняются в режиме «песочницы».
2. Режим «песочницы» ограничивает контекст и права.
3. Результат содержит пометку о выполнении в «песочнице».
4. Аудит фиксирует выполнение в «песочнице».
5. Администратор может настроить порог подозрительности.
