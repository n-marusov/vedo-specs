## Назначение

Обеспечить интеграцию защиты от промпт-инъекций с существующими системами безопасности VEDO.

## Требование

Система интегрируется с существующими системами безопасности:

1. **SIEM:** Отправка событий безопасности (блокировки, подозрительные запросы).
2. **WAF:** Web Application Firewall для защиты API-эндпоинтов.
3. **Rate limiting:** Ограничение количества запросов от одного пользователя.
4. **Threat intelligence:** Обновление чёрного списка из внешних источников (опционально).

## Критерии приёмки

1. События безопасности отправляются в SIEM (при наличии).
2. API-эндпоинты защищены WAF.
3. Rate limiting применяется к NL-запросам.
4. Чёрный список может обновляться из внешних источников.
5. Интеграции конфигурируются через переменные окружения.
