# Конфиденциальность при генерации AI-подсказок

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-NFR.SECURITY.suggestion-privacy |
| **Уровень** | NFR |
| **Атрибут качества** | Security |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | `ADR-DES.API.llm-policy-router-strategy` |

---

## Назначение

Обеспечить соблюдение политики конфиденциальности LLM при генерации AI-подсказок связей.

## Требование

Генерация AI-подсказок подчиняется политике конфиденциальности LLM согласно `ADR-DES.API.llm-policy-router-strategy`:

| Уровень онтологии | Используемый LLM |
|---|---|
| **Public** | Внешний или локальный (по выбору) |
| **Internal** | Только локальный (если администратор не разрешил внешний) |
| **Private** | Только локальный (если администратор не разрешил внешний) |

## Критерии приёмки

1. Для Internal/Private онтологий подсказки генерируются через локальную LLM (если внешние не разрешены администратором).
2. Для Public онтологий может использоваться внешний LLM (с consent-диалогом).
3. В audit-логе фиксируется, какой LLM использовался для генерации подсказок.
4. При использовании внешнего LLM — предупреждение пользователю согласно `REQ-USR.UI.external-llm-consent`.
