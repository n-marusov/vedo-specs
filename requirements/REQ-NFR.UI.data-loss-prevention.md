## Назначение

Определить требования к предотвращению потери введённых пользователем данных в VEDO Core.

## Требование

UI VEDO Core должен предотвращать потерю данных при:
- Сбое вкладки браузера
- Случайной перезагрузке страницы
- Потере сетевого соединения
- Ложном сообщении об успехе при рассинхронизации кэша и сервера

Требуется:
- Локальное хранение черновиков (Draft Store) на клиентской стороне
- Подтверждённое server-side persistence через read-after-write
- Единая UI state machine для отслеживания состояния сохранения (draft, saving, persisted, failed, stale)
