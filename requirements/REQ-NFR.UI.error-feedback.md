## Назначение

Определить требования к отображению ошибок в интерфейсе VEDO Core.

## Требование

Пользователи VEDO Core включают инженеров знаний, ИТ-архитекторов, бизнес-пользователей и аналитиков. Технические ошибки вида "Invalid IRI", "Error 403", "domain is null" без привязки к объекту или полю недопустимы.

Требуется:
- Единый структурированный error contract между серверной и клиентской частью
- Error Presentation Layer для отображения понятных пользователю сообщений
- Привязка ошибок к конкретным полям, объектам или операциям
- Локализация сообщений об ошибках
- Recovery hints для пользователя
