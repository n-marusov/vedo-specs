# Уведомление клиентов о deprecation API endpoint'ов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.API.deprecation-notification |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.2 матрицы качества M2 |

---

## Назначение

Обеспечить многоуровневое уведомление клиентов о deprecation API endpoint'ов.

## Требование

**Каналы:** Email (зарегистрированные клиенты), Status page, Blog, In-app.

**Тайминг уведомлений:**

| Событие | Тайминг |
|---------|---------|
| Первое уведомление | День объявления deprecation |
| Напоминание | За 30 дней до отключения |
| Финальное напоминание | За 7 дней до отключения |
| Уведомление об отключении | День отключения |

Уведомление содержит: название endpoint'а, дату отключения, руководство по миграции.

## Критерии приёмки

1. Уведомление в день объявления.
2. Напоминания за 30 и 7 дней.
3. Содержит endpoint, дату, руководство.
4. Доступно на статус-странице.
5. Enterprise — персональное уведомление.
