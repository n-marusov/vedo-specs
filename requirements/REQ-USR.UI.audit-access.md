# Доступ к audit-логам MCP-инструментов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.audit-access |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.5 матрицы качества M2 |

---

## Назначение

Определить уровни доступа к audit-логам MCP-инструментов для разных ролей.

## Требование

| Роль | Доступ | Что видит |
|------|--------|-----------|
| **Пользователь** | Только свои логи | Метаданные + truncated результат |
| **Администратор tenant** | Все логи tenant | Полные логи, включая полный результат |
| **Поддержка VEDO** | Ограниченный | Метаданные без sensitive data |
| **Администратор VEDO** | Полный (с аудитом) | Все логи всех tenant'ов (при инцидентах) |

## Критерии приёмки

1. Пользователь видит только свои логи.
2. Администратор tenant видит все логи с полными результатами.
3. Поддержка VEDO имеет ограниченный доступ (без sensitive data).
4. Администратор VEDO имеет полный доступ с аудитом каждого обращения.
5. Доступ к полным результатам — только у администратора tenant.
