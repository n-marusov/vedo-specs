## Назначение

Предоставить администратору tenant возможность экспорта полных логов MCP для расследования инцидентов.

## Требование

**Экспорт включает:** полные запросы и ответы (не truncated), метаданные, `trace_id`.

**Процесс экспорта:**
1. Администратор выбирает период и критерии фильтрации.
2. Система генерирует экспорт (асинхронно для больших объёмов).
3. Администратор получает временную ссылку на скачивание (ZIP с JSON/CSV).
4. Экспорт логируется: кто, когда, что экспортировал.

## Критерии приёмки

1. Экспорт доступен администратору tenant.
2. Экспорт содержит полные запросы и ответы.
3. Экспорт защищён временной ссылкой (действует 1 час).
4. Экспорт логируется в audit.
5. Асинхронная генерация для объёмов > 1000 записей.
