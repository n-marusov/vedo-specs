## Назначение

Предоставить администратору tenant интерфейс для просмотра и фильтрации audit-логов MCP.

## Требование

Администратор tenant имеет доступ к интерфейсу с функциями:

1. **Просмотр:** Список всех вызовов с пагинацией
2. **Фильтрация:** По дате, пользователю, инструменту, статусу
3. **Поиск:** По тексту запроса, `trace_id`
4. **Детали:** Полная информация о вызове при клике
5. **Экспорт:** CSV/JSON для анализа
6. **Полный результат:** Доступ к `response_full_url` (только администратор)

## Критерии приёмки

1. Интерфейс доступен в административной панели.
2. Фильтрация работает по всем полям.
3. Поиск работает по тексту запроса и trace_id.
4. При клике открывается детальная информация.
5. Экспорт доступен в CSV/JSON.
6. Доступ к полному результату — только у администратора.
