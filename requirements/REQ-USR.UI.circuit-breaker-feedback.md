# Обратная связь пользователю при активации circuit breaker

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.circuit-breaker-feedback |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.3 матрицы качества M2 |

---

## Назначение

Предоставить пользователю понятное сообщение при временной недоступности SPARQL endpoint из-за активации circuit breaker.

## Требование

При состоянии OPEN пользователь видит сообщение: «SPARQL сервис временно перегружен. Пожалуйста, подождите несколько минут и повторите запрос. Если проблема повторяется, обратитесь в поддержку.»

Сообщение содержит ссылку на статус-страницу и автоматически скрывается при восстановлении (без перезагрузки страницы).

## Критерии приёмки

1. При OPEN отображается понятное сообщение.
2. Сообщение содержит рекомендацию и ссылку на статус-страницу.
3. При переходе в CLOSED сообщение автоматически скрывается.
4. Сообщение доступно для пользователей с ограниченными возможностями (WCAG 2.1 AA).
