# Визуальная индикация уверенности для каждой подсказки

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.confidence-indicator |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.5 матрицы качества M2 |

---

## Назначение

Обеспечить визуальную индикацию уверенности AI для каждой подсказки, позволяющую пользователю быстро оценить надёжность предложения.

## Требование

Каждая AI-подсказка отображает визуальный индикатор уверенности.

**Отображение:**

| Диапазон confidence | Цвет | Индикатор | Текст подсказки |
|---|---|---|---|
| **90–100%** | Зелёный | ●●●●● | «Высокая уверенность» |
| **80–89%** | Светло-зелёный | ●●●●○ | «Средняя уверенность» |
| **70–79%** | Жёлтый | ●●●○○ | «Базовая уверенность» |
| **< 70%** | Не отображается | — | — |

## Критерии приёмки

1. Каждая подсказка имеет цветовой индикатор.
2. При наведении — отображается точное значение confidence (%).
3. Индикатор обновляется при пересчёте подсказок.
4. Доступно для пользователей с ограниченными возможностями (WCAG 2.1 AA: не полагаться только на цвет).
