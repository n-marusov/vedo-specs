# Процесс отзыва согласия на передачу данных LLM-провайдерам

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.consent-withdrawal |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | GDPR Article 7(3), уточнение стейкхолдера (Блок 3.3) |
| **Связанные REQ** | `REQ-USR.UI.external-llm-consent` (первичное согласие), `REQ-NFR.DATA.llm-audit` (аудит) |

---

## Назначение

Детализировать процесс отзыва согласия на передачу данных — дополняет `REQ-USR.UI.external-llm-consent`, где описан только факт согласия, но не механика отзыва.

## Требование

**Процесс отзыва:**
1. Настройки аккаунта → «Конфиденциальность и данные» → «Отозвать согласие на передачу данных LLM».
2. Диалог подтверждения: «AI-функции (NL→OWL, NL-запросы, AI-подсказки) будут заблокированы. Продолжить?»
3. После отзыва — все AI-функции недоступны.
4. Повторное согласие — в любой момент через тот же интерфейс.
5. Отзыв и повторное согласие логируются (user_id, action, timestamp).

**Блокируемые функции при отзыве:** NL→OWL генерация, NL-режим запросов, AI-подсказки. Текстовый SPARQL/CYPHER и визуальный конструктор продолжают работать.

## Критерии приёмки

1. Опция отзыва в настройках аккаунта.
2. Подтверждение через диалог.
3. Мгновенная блокировка AI-функций.
4. Возобновление доступно.
5. Аудит каждого действия (grant/withdraw).
