## Назначение

Обеспечить прозрачность стоимости AI-запросов для конечных пользователей.

## Требование

Пользователи видят ориентировочную стоимость каждого AI-запроса, чтобы понимать влияние на бюджет организации.

**Отображение:**

1. **Перед выполнением запроса:** Ориентировочная стоимость в Credits (USD) с учётом выбранного провайдера и модели.
2. **После выполнения:** Фактическая стоимость (в Credits) с детализацией по токенам.
3. **Индикатор в интерфейсе:** Текущий статус баланса организации (зелёный/жёлтый/красный).
4. **Сравнение моделей:** При выборе провайдера/модели отображается ориентировочная стоимость для типового запроса.

## Критерии приёмки

1. Ориентировочная стоимость отображается перед выполнением запроса.
2. Фактическая стоимость отображается после выполнения запроса.
3. Индикатор статуса баланса отображается в интерфейсе.
4. При низком балансе — предупреждение.
5. Для Enterprise — возможность скрыть стоимость от пользователей.
