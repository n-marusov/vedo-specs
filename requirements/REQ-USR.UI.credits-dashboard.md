# Дашборд использования AI Credits для администратора

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.credits-dashboard |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | GitHub Copilot usage dashboard |

---

## Назначение

Предоставить администратору дашборд использования AI Credits с детализацией по провайдерам, моделям, пользователям и функциям.

## Требование

Администратор имеет доступ к дашборду использования AI Credits в реальном времени.

**Содержание дашборда:**

| Метрика | Описание | Визуализация |
|---|---|---|
| **Остаток Credits** | Текущий баланс организации | Цифровое значение |
| **Использовано за месяц** | Всего израсходовано Credits | Цифровое значение |
| **Включённый лимит** | Credits по тарифному плану | Цифровое значение |
| **Прогноз исчерпания** | Дата, когда Credits будут исчерпаны | Дата |
| **Расход по провайдерам** | OpenAI / Anthropic / Google / Local | Круговая диаграмма |
| **Расход по моделям** | GPT-4o / Claude 3 Opus / др. | Круговая диаграмма |
| **Расход по пользователям** | Топ-10 пользователей | Таблица |
| **Расход по функциям** | NL→OWL / NL-запросы / AI-подсказки | Столбчатая диаграмма |
| **Дневное использование** | График за последние 30 дней | График |
| **Экономия от кэширования** | Сколько Credits сэкономлено | Цифровое значение |

## Критерии приёмки

1. Дашборд доступен в административном интерфейсе.
2. Данные обновляются в реальном времени (задержка ≤ 15 минут).
3. При балансе < 20% — красный индикатор.
4. Возможность экспорта в PDF/CSV.
5. Возможность фильтрации по пользователям, группам, провайдерам, моделям.
