## Назначение

Определить требования к подтверждению и восстановлению опасных действий в онтологии.

## Требование

Опасные действия в VEDO Core (удаление класса, перемещение в иерархии, массовый импорт, массовое редактирование) должны:
- Показывать пользователю preview последствий до подтверждения (dry-run)
- Быть обратимыми (undo/rollback)
- Иметь единый flow: preview → confirm → execute → undo

Каждое опасное действие должно моделироваться как Command с обязательным dry-run preview и обратимым исполнением через единый Dangerous Action Flow.
