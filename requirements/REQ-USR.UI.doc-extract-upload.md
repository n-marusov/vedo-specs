## Назначение

Определить требования к пользовательскому интерфейсу загрузки документов и предпросмотра.

## Требование

### 1. Компонент загрузки файла

```
┌────────────────────────────────────────────┐
│  Загрузить документ для извлечения         │
│  онтологии                                 │
│                                            │
│  ┌──────────────────────────────────────┐  │
│  │                                      │  │
│  │        📄 Перетащите файл сюда       │  │
│  │                                      │  │
│  │        или нажмите для выбора        │  │
│  │                                      │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  Поддерживаемые форматы: MD, TXT, PDF,    │
│  DOCX, JSON, XML, CSV, XLSX               │
│  Максимальный размер: 20 MB               │
│                                            │
│  [Стратегия импорта: ▼]                    │
│    • Слияние (merge) — добавить к          │
│      существующей онтологии                │
│    • Замена (replace) — удалить            │
│      существующую, импортировать новую     │
│    • Новая ветка (version) — импорт в      │
│      отдельную ветку                       │
└────────────────────────────────────────────┘
```

### 2. Индикатор прогресса

При обработке файла (особенно для PDF/DOCX > 50 стр.):

```
┌────────────────────────────────────────────┐
│  Извлечение онтологии из document.pdf     │
│                                            │
│  ████████░░░░░░░░░░  45%                   │
│  ──── Извлечение текста... ✅              │
│  ──── Анализ LLM... ████                   │
│  ──── Построение sequence...               │
│                                            │
│  [Отмена]                                  │
└────────────────────────────────────────────┘
```

### 3. Предпросмотр sequence

После обработки LLM:

```
┌────────────────────────────────────────────┐
│  Результат извлечения из document.pdf     │
│                                            │
│  Будет создано: 12 классов, 8 свойств,    │
│  4 уровня иерархии                         │
│                                            │
│  ┌─ Шаги ───────────────────────────────┐  │
│  │ ✓  create_class  Customer           │  │
│  │ ✓  create_class  Product            │  │
│  │ ✓  set_parent    Customer → Person  │  │
│  │ ✓  create_object Customer → Order   │  │
│  │ ⚠  create_class  Order             │  │
│  │     (уже существует, пропускаем)     │  │
│  │                                      │  │
│  │ [+ Добавить шаг]  [✕ Удалить]       │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  Commit message:                           │
│  ┌──────────────────────────────────────┐  │
│  │ Извлечено из document.pdf            │  │
│  └──────────────────────────────────────┘  │
│                                            │
│  [✓ Подтвердить импорт]  [✗ Отмена]       │
└────────────────────────────────────────────┘
```

### 4. Поведение

1. Drag-n-drop зона подсвечивается при перетаскивании файла.
2. При недопустимом формате — красное предупреждение с указанием поддерживаемых форматов.
3. Прогресс-бар показывает текущую стадию (парсинг, LLM, сборка).
4. Если LLM обработка > 5 сек — показывать оценочное время.
5. Предпросмотр:
   - Каждый шаг — строка таблицы с чекбоксом для включения/исключения.
   - Предупреждения о конфликтах (дубликаты, невалидные ссылки) — жёлтым.
   - Ошибки — красным.
   - Можно редактировать label, comment, parent, domain, range прямо в таблице (inline edit).
6. После подтверждения — переход на страницу онтологии с уведомлением об успешном импорте.

## Критерии приёмки

1. Пользователь может загрузить файл через drag-n-drop и через диалог выбора файла.
2. Неподдерживаемые форматы отклоняются с понятным сообщением.
3. Прогресс-бар отображается для всех стадий обработки.
4. Preview показывает все шаги с возможностью включения/исключения.
5. Inline editing в preview работает для label, comment, parent, domain, range.
6. Подтверждение запускает ApplySequence, отмена возвращает к редактору.
7. После успешного импорта — уведомление и обновление дерева классов.
