# Детальный отчёт об ошибках при импорте Excel

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.excel-error-report |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.6 матрицы качества M2 |

---

## Назначение

Предоставить пользователю детальный отчёт об ошибках импорта Excel-файла с указанием строки, колонки, причины и предложения по исправлению.

## Требование

При импорте Excel-файла система генерирует детальный отчёт об ошибках.

**Структура отчёта:**

| Колонка | Описание |
|---------|----------|
| **Строка** | Номер строки в Excel (1-based) |
| **Колонка** | Название колонки |
| **Значение** | Значение в ячейке |
| **Тип ошибки** | invalid_type / duplicate / missing_required / invalid_iri / invalid_range / invalid_date |
| **Сообщение** | Человекочитаемое описание |
| **Предложение** | Как исправить |

**Типы ошибок и предложения:**

| Тип ошибки | Сообщение | Предложение |
|---|---|---|
| `invalid_type` | «Ожидался тип integer, получено 'abc'» | «Замените на число» |
| `duplicate` | «Класс 'Car' уже существует» | «Используйте уникальное имя или выберите 'overwrite'» |
| `missing_required` | «Отсутствует обязательное поле 'name'» | «Добавьте значение в колонку 'name'» |
| `invalid_iri` | «Некорректный IRI» | «Используйте латиницу или URL-кодирование» |
| `invalid_range` | «Значение вне допустимого диапазона» | «Используйте значение от 1 до 100» |
| `invalid_date` | «Некорректный формат даты» | «Используйте формат ГГГГ-ММ-ДД» |

## Критерии приёмки

1. Отчёт генерируется при каждой попытке импорта (успешной или нет).
2. Отчёт содержит все ошибки с указанием строки и колонки.
3. Отчёт содержит предложения по исправлению.
4. Отчёт доступен для скачивания в CSV/Excel.
5. Отчёт отображается в интерфейсе (с пагинацией при > 50 ошибок).
