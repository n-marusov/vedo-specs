| **Источник** | Уточнение стейкхолдера по вопросу 1.6 матрицы качества M2 |

---

## Назначение

Предоставить пользователю возможность экспортировать отчёт об ошибках импорта для последующего исправления данных.

## Требование

Пользователь может экспортировать отчёт об ошибках в Excel/CSV для последующего исправления данных.

**Содержание экспорта:**

| Исходная строка | Ошибка | Предложение |
|---|---|---|
| 5 | Неверный тип в колонке 'Type' | Замените на 'ObjectProperty' или 'DatatypeProperty' |
| 12 | Дубликат 'Car' | Используйте уникальное имя |

**Форматы экспорта:** `.xlsx` и `.csv`.

## Критерии приёмки

1. Кнопка «Экспортировать ошибки» доступна в отчёте об ошибках.
2. Экспорт доступен в форматах .xlsx и .csv.
3. Экспорт содержит исходные данные (ошибочные строки) и описания ошибок.
4. Экспорт содержит предложения по исправлению.
5. Файл экспорта можно импортировать обратно после исправления ошибок.
