# Предпросмотр маппинга колонок перед импортом Excel

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.excel-preview |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.6 матрицы качества M2 |

---

## Назначение

Предоставить пользователю предпросмотр маппинга колонок Excel на поля онтологии с возможностью ручной корректировки.

## Требование

Перед импортом Excel-файла система показывает предпросмотр первых 3-5 строк с автоматическим маппингом колонок на поля онтологии. Пользователь может скорректировать маппинг.

**Отображение:**

```
┌─────────────────────────────────────────────────────────────────┐
│  📊 Предпросмотр импорта                                       │
│                                                                 │
│  Файл: ontology_import.xlsx (3.2 MB, 1,234 строк)              │
│                                                                 │
│  ┌───────────────┬───────────────┬───────────────────────────┐ │
│  │ Колонка       │ Маппинг       │ Пример (строка 1)         │ │
│  ├───────────────┼───────────────┼───────────────────────────┤ │
│  │ A: "Name"     │ → Class Name  │ "Car"                     │ │
│  │ B: "Parent"   │ → Parent Class│ "Vehicle"                 │ │
│  │ C: "Property" │ → Property    │ "hasEngine"               │ │
│  │ D: "Type"     │ → Type        │ "ObjectProperty"          │ │
│  └───────────────┴───────────────┴───────────────────────────┘ │
│                                                                 │
│  [Настроить маппинг]  [Продолжить]  [Отмена]                   │
└─────────────────────────────────────────────────────────────────┘
```

## Критерии приёмки

1. Предпросмотр отображается перед импортом.
2. Система автоматически определяет маппинг колонок (по именам).
3. Пользователь может изменить маппинг для каждой колонки.
4. Отображаются первые 3-5 строк данных (примеры).
5. Предпросмотр обновляется при изменении маппинга.
