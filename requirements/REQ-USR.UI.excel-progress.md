## Назначение

Обеспечить визуальную индикацию прогресса импорта Excel-файла.

## Требование

При импорте Excel-файла система отображает прогресс-бар с детальной информацией о ходе выполнения.

**Отображение:**

```
┌─────────────────────────────────────────────────────────────────┐
│  Импорт данных...                                              │
│                                                                 │
│  ████████████████░░░░░░░░░░░░░░░░░░ 45% (450/1000 строк)      │
│                                                                 │
│  Текущий этап: Обработка строк 401-450                         │
│  Успешно: 430 строк, Ошибок: 20 строк                         │
│  Время выполнения: ~2 мин 30 сек                               │
│                                                                 │
│  [Отменить импорт]                                             │
└─────────────────────────────────────────────────────────────────┘
```

## Критерии приёмки

1. Прогресс-бар отображается при импорте.
2. Отображается количество обработанных строк и общее количество.
3. Отображается процент выполнения.
4. Отображается текущий этап.
5. Пользователь может отменить импорт.
6. После завершения — уведомление (in-app + email для асинхронного режима).
