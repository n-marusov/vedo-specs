## Назначение

Предоставить пользователям шаблоны Excel с правильной структурой для импорта онтологий.

## Требование

Система предоставляет шаблоны Excel для импорта онтологий, чтобы пользователи знали правильную структуру данных.

**Структура шаблона:**

| Name (required) | Parent | Property | Type | Range | Comment |
|---|---|---|---|---|---|
| Car | Vehicle | hasEngine | ObjectProperty | Engine | Основной класс |
| Vehicle | | | | | Родительский класс |
| Engine | | | | | Дочерний класс |

**Обязательные колонки:** `Name` (имя класса).

**Опциональные колонки:** `Parent` (родительский класс), `Property` (свойство), `Type` (ObjectProperty / DatatypeProperty), `Range` (диапазон), `Comment` (комментарий).

## Критерии приёмки

1. Шаблон доступен для скачивания в интерфейсе импорта (кнопка «Скачать шаблон»).
2. Шаблон содержит все обязательные и опциональные колонки.
3. Шаблон содержит примеры заполнения (не менее 3 строк).
4. Шаблон содержит комментарии с пояснениями к каждой колонке.
5. Шаблон доступен на русском и английском языках.
