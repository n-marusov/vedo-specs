# Отображение прогресса NL→OWL генерации

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.generation-progress |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.2 матрицы качества M2 |
| **Связанные REQ** | `REQ-NFR.API.generation-latency` |

---

## Назначение

Определить UX отображения прогресса NL→OWL генерации — замена неопределённого спиннера на информативный прогресс-бар.

## Требование

При NL→OWL генерации система отображает прогресс-бар с текстовыми этапами, чтобы пользователь понимал, что происходит в каждый момент времени.

**Этапы (отображаются последовательно):**

| Этап | Что происходит |
|------|---------------|
| 1. «Анализ текста» | Парсинг NL-описания: извлечение сущностей, выявление связей |
| 2. «Построение иерархии классов» | Определение parent-child отношений между классами |
| 3. «Генерация свойств» | Создание ObjectProperty и DatatypeProperty с domain/range |
| 4. «Валидация OWL-структуры» | Проверка синтаксиса, циклов и логической состоятельности |
| 5. «Подготовка предпросмотра» | Формирование визуализации и отчёта о качестве |

**Обработка ошибок:**

При ошибке на любом этапе пользователь видит:
- Название этапа, на котором произошла ошибка.
- Причину ошибки (человекочитаемое сообщение).
- Кнопку «Повторить» или «Вернуться к редактированию описания».

## Критерии приёмки

1. Прогресс-бар отображается во время генерации (заменяет спиннер).
2. Отображается текущий этап текстом (не только иконкой).
3. Прогресс обновляется при переходе между этапами.
4. При ошибке на любом этапе — отображается сообщение с указанием этапа и причины.
5. Прогресс-бар доступен для пользователей с ограниченными возможностями (WCAG 2.1 AA: aria-label, role="progressbar").
6. Общее время генерации с прогресс-баром не превышает порогов из `REQ-NFR.API.generation-latency`.
