# Режим graceful degradation при недоступности всех LLM-провайдеров

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.graceful-degradation |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.3 матрицы качества M2 |
| **Связанные ADR** | `ADR-DES.UI.degraded-mode-ux-strategy` |
| **Связанные REQ** | `REQ-NFR.INTEGRATION.max-downtime`, `REQ-USR.UI.provider-status-indicator` |

---

## Назначение

Определить UX-поведение системы при недоступности всех LLM-провайдеров — режим graceful degradation, при котором NL-функции недоступны, но ядро VEDO продолжает работать.

## Требование

При недоступности всех настроенных LLM-провайдеров система переходит в режим graceful degradation:

**Поведение:**

1. **NL-функции недоступны:**
   - Кнопка NL→OWL («Создать онтологию из описания») — неактивна.
   - Кнопка NL-режима запросов («Микрофон») — неактивна.
   - Панель AI-подсказок связей — скрыта или неактивна с сообщением.
   - При попытке использования — сообщение вместо выполнения.

2. **Остальные функции VEDO работают** в полном объёме без деградации:
   - Просмотр и навигация по онтологии
   - Редактор TBox / ABox
   - Версионирование (коммиты, ветки, история)
   - SPARQL / CYPHER запросы (текстовый редактор, визуальный конструктор)
   - Импорт / экспорт
   - Все функции, не зависящие от LLM

3. **Сообщение пользователю:**

   > «AI-функции временно недоступны»
   >
   > Все LLM-провайдеры в данный момент недоступны. Техническая поддержка уведомлена и работает над восстановлением.
   >
   > Остальные функции VEDO работают в обычном режиме.
   >
   > [Проверить статус] [Обновить страницу]

4. **Автоматическое восстановление:**
   - При восстановлении хотя бы одного провайдера (health check возвращает `healthy`) NL-функции автоматически становятся доступны.
   - Восстановление происходит без перезагрузки страницы (polling статуса каждые 30 секунд или через WebSocket).
   - Пользователь видит уведомление: «AI-функции снова доступны».

## Критерии приёмки

1. При недоступности всех провайдеров кнопки AI-функций неактивны с визуальной индикацией.
2. Остальные функции VEDO (просмотр, редактор, версионирование, SPARQL) продолжают работать в полном объёме.
3. При восстановлении провайдера AI-функции автоматически становятся доступны без перезагрузки страницы.
4. Сообщение о недоступности содержит ссылку на статус-страницу (`status.vedo.example.com`).
5. Индикатор статуса провайдеров в UI (см. `REQ-USR.UI.provider-status-indicator`) синхронизирован с состоянием graceful degradation.
