# Максимальное количество AI-подсказок связей, показываемых одновременно

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.max-suggestions |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.5 матрицы качества M2 |

---

## Назначение

Ограничить количество AI-подсказок связей, показываемых одновременно, для предотвращения информационной перегрузки и confirmation fatigue.

## Требование

При просмотре сущности (класса, свойства) система показывает не более 5 AI-подсказок связей одновременно.

**Обоснование:** Исследования GitHub Copilot и UX-практики показывают, что более 5 рекомендаций одновременно приводят к снижению качества принятия решений (confirmation fatigue).

## Критерии приёмки

1. При открытии сущности отображается не более 5 подсказок.
2. Подсказки ранжированы по убыванию confidence.
3. Если подсказок > 5 — отображаются только 5 лучших.
4. Пользователь может запросить дополнительные подсказки (кнопка «Показать ещё»).
5. При запросе дополнительных подсказок — ещё 5 подсказок (максимум 10 всего).
