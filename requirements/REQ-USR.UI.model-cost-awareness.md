## Назначение

Обеспечить информирование пользователя о стоимости различных LLM-моделей в селекторе для принятия осознанных решений.

## Требование

При выборе LLM-модели пользователь видит не только название, но и ориентировочную стоимость для типового запроса.

**Отображение в селекторе моделей:**

| Модель | Провайдер | Ориентировочная стоимость (запрос 2K/1.5K токенов) |
|--------|-----------|---------------------------------------------------|
| GPT-4o | OpenAI | ~$0.0325 |
| GPT-4 | OpenAI | ~$0.1500 |
| GPT-4o-mini | OpenAI | ~$0.0012 |
| Claude 3 Opus | Anthropic | ~$0.1425 |
| Claude 3 Sonnet | Anthropic | ~$0.0285 |
| Claude 3 Haiku | Anthropic | ~$0.0024 |
| Gemini 1.5 Pro | Google | ~$0.0200 |
| Gemini 1.5 Flash | Google | ~$0.0006 |

## Критерии приёмки

1. В селекторе моделей отображается ориентировочная стоимость.
2. Стоимость рассчитывается для типового запроса (NL→OWL, 10 классов).
3. Пользователь может сортировать модели по стоимости.
4. При выборе модели отображается предупреждение о стоимости, если баланс низкий.
5. Для Enterprise — возможность скрыть стоимость от пользователей.
