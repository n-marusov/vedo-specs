## Назначение

Определить требования к визуальному представлению онтологических типов для снижения порога входа для неэкспертов.

## Требование

Новички и бизнес-пользователи могут путать классы, свойства, индивиды, domain/range и наследование. UI VEDO Core должен:

- Использовать единый слой presentation metadata для онтологических типов и связей
- Обеспечивать одинаковую визуальную семантику (иконки, цвета, подписи, allowed actions) во всех UI-представлениях (дерево, граф, карточки, результаты поиска, diff)
- Снижать порог входа для неэкспертов через progressive disclosure терминов OWL/RDF без потери точности для инженеров знаний
- Исключить расхождение визуальных правил между разными компонентами
