# Обратная связь пользователю при блокировке запроса

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.prompt-block-feedback |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.1 матрицы качества M2 |

---

## Назначение

Предоставить пользователю понятное сообщение с объяснением причины блокировки NL-запроса.

## Требование

При блокировке NL-запроса пользователь получает сообщение, соответствующее причине блокировки.

**Сообщения в зависимости от причины:**

| Причина | Сообщение |
|---------|-----------|
| **Запрещённая инструкция** | «Ваш запрос содержит инструкции, пытающиеся изменить поведение AI-ассистента. Такие запросы не поддерживаются.» |
| **Вложенная структура** | «Ваш запрос содержит вложенные структуры данных (JSON/XML). Для генерации онтологии используйте текстовое описание.» |
| **Превышение длины** | «Запрос превышает максимальную длину в 2000 символов. Пожалуйста, сократите запрос.» |
| **Неизвестная причина** | «Запрос не может быть обработан. Пожалуйста, попробуйте переформулировать.» |

## Критерии приёмки

1. При блокировке отображается сообщение с указанием причины.
2. Сообщение содержит рекомендацию по исправлению.
3. Пользователь может скопировать сообщение для обращения в поддержку.
4. Сообщение доступно для пользователей с ограниченными возможностями (WCAG 2.1 AA).
