# Уведомление об изменении списка LLM-провайдеров

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.provider-change-notification |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера (Блок 3.3) |
| **Связанные REQ** | `REQ-USR.UI.llm-selector` (выбор провайдера), `REQ-FUN.API.llm-policy` (политика LLM) |

---

## Назначение

Уведомлять пользователей при изменении списка доступных LLM-провайдеров (добавление нового или удаление существующего).

## Требование

При изменении списка провайдеров все активные пользователи получают уведомление:

> «Обновление: VEDO Hub теперь использует [новый/удалённый провайдер] для AI-функций. Ознакомьтесь с политикой конфиденциальности: [ссылка].»

**Каналы:** In-app (banner, 7 дней) + Email (однократно).

Уведомление содержит: название провайдера, ссылку на его privacy policy, дату изменения.

## Критерии приёмки

1. Уведомление при добавлении нового провайдера.
2. Уведомление при удалении провайдера.
3. Ссылка на privacy policy провайдера.
4. In-app banner на 7 дней + email.
5. Не применяется к on-premise (локальная LLM).
