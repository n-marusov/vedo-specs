# Индикация статуса LLM-провайдеров в UI

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.provider-status-indicator |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.3 матрицы качества M2 |
| **Связанные REQ** | `REQ-USR.UI.visibility-indicator`, `REQ-USR.UI.graceful-degradation` |

---

## Назначение

Обеспечить визуальную индикацию статуса LLM-провайдеров в интерфейсе AI-функций, чтобы пользователь понимал текущий режим работы (штатный / резервный / недоступен).

## Требование

В интерфейсе AI-функций отображается индикатор статуса LLM-провайдеров, дополняющий индикатор политики видимости (`REQ-USR.UI.visibility-indicator`).

**Отображение статуса:**

| Статус | Иконка | Цвет | Текст | Когда |
|--------|--------|------|-------|-------|
| Все провайдеры доступны | ● | Зелёный | «AI-сервис доступен» | Все health checks = healthy |
| Основной провайдер недоступен, работает резервный | ● | Жёлтый | «AI-сервис: резервный режим (используется [provider])» | Failover активен |
| Частичная деградация (основной работает, резервный недоступен) | ● | Жёлтый | «AI-сервис работает, резервный провайдер недоступен» | Один из провайдеров unavailable |
| Все провайдеры недоступны | ● | Красный | «AI-сервис временно недоступен» | Все провайдеры unavailable |
| Локальная LLM (on-premise) | ● | Серый | «Локальная LLM» | On-premise режим |

**Размещение:** индикатор отображается рядом с индикатором политики видимости, в верхней части панели AI-функций.

**Детализация при наведении (tooltip):**

```
Статус LLM-провайдеров:
● OpenAI GPT-4 — доступен (latency: 1.2s)
● Anthropic Claude — доступен (latency: 1.8s)
Режим: основной (OpenAI)
```

**Обновление статуса:**

- Статус обновляется через polling каждые 30 секунд (GET `/api/v1/llm/providers/status`).
- При изменении статуса (failover / восстановление) — мгновенное обновление через WebSocket или SSE.

## Критерии приёмки

1. Индикатор отображается во всех AI-интерфейсах рядом с индикатором видимости.
2. При наведении — tooltip с детальным статусом каждого провайдера.
3. При переключении на резервного провайдера — индикатор меняется на жёлтый в течение ≤ 30 секунд.
4. При восстановлении — индикатор возвращается в зелёный.
5. При недоступности всех провайдеров — красный индикатор + сообщение graceful degradation.
6. Цвета и иконки проходят accessibility-проверку (WCAG 2.1 AA contrast, не полагаться только на цвет).
