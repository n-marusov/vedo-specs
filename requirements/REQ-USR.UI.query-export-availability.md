# Доступность экспорта сохранённых запросов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.query-export-availability |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.1 матрицы качества M2 |

---

## Назначение

Обеспечить доступность экспорта сохранённых запросов через UI и API.

## Требование

| Способ | Где | Режим |
|--------|-----|-------|
| **Настройки аккаунта** | Кнопка «Экспортировать запросы» | ≤ 50 запросов — синхронно; > 50 — асинхронно с email |
| **При удалении аккаунта** | Опция в процессе удаления | Асинхронно с email |
| **API** | `POST /api/v1/user/queries/export` | Асинхронно |

**Пороги:**
- ≤ 50 запросов: немедленная загрузка (≤ 5 сек)
- > 50 запросов: асинхронно, email со ссылкой

## Критерии приёмки

1. Кнопка доступна в настройках аккаунта.
2. Опция доступна при удалении аккаунта (в течение 30-дневного периода).
3. API доступен для программного доступа.
4. При ≤ 50 запросах файл скачивается сразу.
5. При > 50 запросах пользователь получает email со ссылкой.
