## Назначение

Сохранить пользовательские данные в экспорте без изменений — данные принадлежат пользователю.

## Требование

Метаданные экспортируются в том виде, в котором их создал пользователь:
- Названия запросов, теги, описания — без изменений
- Даты — в ISO 8601
- `manifest.json` — ключи на английском (стандартный формат), значения — как созданы пользователем

Дополнительная локализация не требуется.

## Критерии приёмки

1. Названия и теги запросов экспортируются без изменений.
2. Даты — ISO 8601.
3. Ключи manifest.json — английский (машиночитаемый формат).
4. Значения — без изменений, на языке пользователя.
