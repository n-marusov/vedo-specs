# Уведомления о завершении экспорта запросов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.query-export-notifications |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 3.1 матрицы качества M2 |

---

## Назначение

Информировать пользователя о статусе асинхронного экспорта.

## Требование

| Событие | Канал | Содержание |
|---------|-------|------------|
| Экспорт готов | Email + In-app | «Экспорт запросов готов. Ссылка действительна 7 дней.» |
| Истекает срок | Email (за 2 дня) | «Ссылка на экспорт будет удалена через 2 дня.» |
| Экспорт удалён | Email | «Экспорт запросов удалён по истечении срока.» |

## Критерии приёмки

1. Уведомление при готовности экспорта.
2. Напоминание за 2 дня до удаления.
3. Уведомление после удаления.
4. Пользователь может отключить необязательные уведомления.
