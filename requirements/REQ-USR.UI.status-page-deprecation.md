## Назначение

Публиковать информацию о deprecation API endpoint'ов на публичной статус-странице.

## Требование

Статус-страница содержит: название endpoint'а, даты (объявления/отключения), статус (`active`/`deprecated`/`sunset`/`decommissioned`), альтернативу, ссылку на руководство, контакты поддержки.

История deprecation доступна для просмотра. Информация обновляется при изменении сроков.

## Критерии приёмки

1. Информация публикуется на статус-странице.
2. Статус endpoint'а в реальном времени.
3. Ссылка на руководство доступна.
4. Обновляется при изменениях.
5. История доступна.
