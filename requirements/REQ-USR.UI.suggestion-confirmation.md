# Ручное подтверждение перед применением AI-подсказки

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.suggestion-confirmation |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 1.5 матрицы качества M2 |

---

## Назначение

Гарантировать, что AI-подсказки не применяются автоматически — пользователь явно контролирует каждое изменение.

## Требование

AI-подсказки **НЕ** применяются автоматически. Пользователь должен явно подтвердить применение каждой подсказки.

**Поведение:**

1. **Принять:** Нажатие на кнопку «Применить» — связь создаётся, создаётся коммит.
2. **Отклонить:** Нажатие на кнопку «Отклонить» — подсказка скрывается для этой сущности.
3. **Игнорировать:** Подсказка остаётся, но не применяется (до закрытия сущности).

## Критерии приёмки

1. Кнопка «Применить» доступна для каждой подсказки.
2. Кнопка «Отклонить» доступна для каждой подсказки.
3. При принятии подсказки создаётся коммит (изменение фиксируется в истории версий).
4. При отклонении подсказки она больше не показывается для этой сущности.
5. При игнорировании подсказка остаётся до закрытия сущности.
