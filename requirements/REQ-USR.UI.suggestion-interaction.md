## Назначение

Обеспечить интерактивное взаимодействие пользователя с AI-подсказками: просмотр, применение, отклонение, запрос пояснений.

## Требование

Пользователь может интерактивно взаимодействовать с подсказками: просматривать детали, применять, отклонять, запрашивать пояснения.

**Взаимодействия:**

1. **Просмотр деталей:** Клик по подсказке показывает подробности (обоснование, связанные сущности).
2. **Применение:** Кнопка «Применить» создаёт связь.
3. **Отклонение:** Кнопка «Отклонить» скрывает подсказку для сущности.
4. **Пояснение:** Кнопка «Почему?» показывает объяснение от LLM.
5. **Все подсказки:** Кнопка «Показать все» (если скрыты некоторые).

## Критерии приёмки

1. При клике на подсказку открывается панель с деталями.
2. Обоснование доступно для каждой подсказки (опционально, с учётом производительности).
3. Применение/отклонение выполняется одним кликом.
4. История применённых/отклонённых подсказок доступна.
5. При повторном открытии сущности отклонённые подсказки не показываются.
