## Назначение

Обеспечить UX выбора и применения шаблона при создании новой онтологии.

## Требование

При создании новой онтологии пользователь может выбрать один из двух вариантов:

1. **Пустая онтология** — создание с нуля (F14.1 NL→OWL или ручное редактирование).
2. **Из шаблона** — выбор из каталога, preview, создание копии шаблона.

**Процесс применения:**
1. Пользователь выбирает «Создать из шаблона».
2. Открывается каталог шаблонов с поиском и фильтрацией по категориям/тегам.
3. Пользователь выбирает шаблон → preview (диаграмма классов, свойства, документация).
4. Пользователь подтверждает → система создаёт новую онтологию как копию шаблона.
5. Новая онтология автоматически сохраняется с ссылкой на шаблон-источник (`template_id`).

## Критерии приёмки

1. При создании онтологии доступен выбор «Создать из шаблона».
2. Каталог отображает 5+ шаблонов с возможностью фильтрации по категориям и поиска по тегам.
3. Preview содержит: диаграмму классов, список свойств, краткое описание, метаданные.
4. При применении создаётся полная копия шаблона как новая онтология.
5. `usage_count` шаблона инкрементируется.
