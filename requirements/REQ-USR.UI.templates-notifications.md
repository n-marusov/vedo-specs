# Уведомления об изменениях шаблонов

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.templates-notifications |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.4 матрицы качества M2 |

---

## Назначение

Информировать пользователей об изменениях в шаблонах, которые они использовали.

## Требование

Пользователи получают уведомления при:

| Событие | Канал | Сообщение |
|---------|-------|-----------|
| Новая PATCH/MINOR версия шаблона | In-app | «Шаблон [name] обновлён до версии [version]. Изменения: [changelog]. [Обновить онтологию]» |
| Новая MAJOR версия шаблона | In-app + Email | «Вышла новая MAJOR-версия шаблона [name] ([version]). Автоматическое обновление недоступно. [Просмотреть изменения]» |
| Шаблон переведён в `deprecated` | In-app + Email | «Шаблон [name] помечен как устаревший. Ваши онтологии продолжают работать. [Подробнее]» |
| Шаблон архивирован | Email | «Шаблон [name] архивирован. Ваши онтологии продолжают работать, но новые из этого шаблона создать нельзя.» |

## Критерии приёмки

1. Уведомления отправляются при каждом событии из таблицы.
2. Для PATCH/MINOR доступна кнопка «Обновить онтологию» (вручную).
3. Для MAJOR — только информация, автоматическое обновление не предлагается.
4. Уведомления содержат ссылку на changelog шаблона.
5. Пользователь может отключить уведомления в настройках.
