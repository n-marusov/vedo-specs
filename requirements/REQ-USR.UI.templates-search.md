## Назначение

Обеспечить категоризацию и поиск шаблонов в каталоге.

## Требование

Каталог шаблонов поддерживает:

1. **Фильтрацию по категориям:** Бизнес, Общее, Наука, Технологии, Медицина (расширяемый список).
2. **Поиск по тегам:** Полнотекстовый поиск по `tags`, `name`, `description`.
3. **Сортировку:** По популярности (usage_count), по дате обновления, по названию.
4. **Фильтрацию по источнику:** `internal` (официальные), `community` (сообщества), `my` (личные).
5. **Фильтрацию по статусу:** `active` (активные), `deprecated` (устаревшие).

## Критерии приёмки

1. Каталог отображает фильтры по категориям и источнику.
2. Поиск работает по `name`, `description`, `tags`.
3. Сортировка доступна по usage_count, updated_at, name.
4. Фильтрация по статусу скрывает `deprecated`/`archived` по умолчанию.
5. Личные шаблоны пользователя отображаются в отдельной вкладке.
