## Время до первой задачи

`time-to-first-task` измеряется после входа в систему. Аутентификация через SSO, Keycloak или режим "Запомнить меня" не входит в замер, потому что в реальном рабочем процессе пользователь уже авторизован.

Первое успешное действие для MVP: создать класс в онтологии и увидеть его в дереве классов.

| Группа | Целевое время | Допустимое (yellow) | Критичное (red) |
|--------|---------------|---------------------|------------------|
| Новички (бизнес-пользователь) | 1.5 минуты (90 сек) | 3 минуты | > 4 минут |
| Опытные (Инженер знаний) | 20 секунд | 45 секунд | > 1.5 минут |

Время сокращено относительно первоначальной оценки: на 30 секунд для новичков и на 10 секунд для экспертов, потому что вход в систему исключён из измерения.

---

## Условия измерения

- Пользователь уже авторизован.
- Для новичков стартовая точка: момент появления главного экрана после входа.
- Для опытных стартовая точка: онтология уже открыта как последний проект.
- Зачётная точка: новый класс появился в дереве классов.
- Для новичков используется юзабилити-тест.
- Для опытных используется синтетический мониторинг через Playwright.

---

## Разбивка для новичков

Целевой сценарий укладывается в 70 секунд с запасом до 90 секунд.

| Действие | Целевое время | Технические требования |
|----------|---------------|------------------------|
| Открыть VEDO, если вкладка уже открыта | 0 сек | Возможность держать вкладку открытой. Сохранение сессии при обновлении страницы. |
| Выбрать или создать онтологию | 15 сек | Понятный список проектов или кнопка "Новая онтология". Если открыт последний проект — автоматически загружать его. |
| Найти кнопку "Создать класс" | 10 сек | Кнопка в левой панели, всегда видима, иконка +, тултип при наведении. |
| Заполнить поля формы | 35 сек | Label, необязательное описание, выбор родительского класса. |
| Нажать "Сохранить" и увидеть класс в дереве | 10 сек | Отклик < 500 мс, анимация появления нового узла в дереве. |

Детализация заполнения формы:

| Поле | Целевое время | Требование |
|------|---------------|------------|
| Наименование (label) | 10 сек | Плейсхолдер: "Введите название, например, Person" |
| Описание (comment) | 10 сек | Плейсхолдер: "Описание (необязательно)" |
| Родительский класс | 15 сек | Родитель по умолчанию: `owl:Thing`. Выпадающее дерево классов, не более 2 кликов до выбора. |

## Разбивка для опытных

Целевой сценарий укладывается в 20 секунд.

| Действие | Целевое время |
|----------|---------------|
| Онтология уже открыта как последний проект | 0 сек |
| Найти или использовать кнопку "Создать класс" | 5 сек |
| Быстро заполнить label | 5 сек |
| Выбрать родителя из истории или оставить по умолчанию | 5 сек |
| Сохранить | 5 сек |

## Технические требования

| Требование | Метрика | Проверка |
|------------|---------|----------|
| Сохранение последней открытой онтологии | При следующем входе открывается последний проект | UI тест, проверка localStorage |
| Генерация ID из label | Нажал "Сохранить" — ID создан автоматически | UI тест: создать класс "Тестовый Класс", ID = "ТестовыйКласс" |
| Родитель по умолчанию | Выбран `owl:Thing`, пользователь не обязан его менять | Визуальная проверка |
| Отклик UI при сохранении | < 500 мс | Performance API |
| Возможность пропустить описание (comment) | Поле необязательно, нет ошибки | UI тест |
| Класс появляется в дереве без обновления страницы | Узел появился после сохранения | WebSocket или push-state тест |

## Риски

| Риск | Влияние | Смягчение |
|------|---------|-----------|
| Пользователь забыл, какой проект открыт, и теряет время на поиски | +20 сек | Автоматически открывать последний проект, чёткое название в шапке |
| Выбор родителя — большое дерево, прокрутка, поиск | +15 сек | Родитель по умолчанию `owl:Thing` и поиск по дереву при необходимости |
| Интерфейс перегружен, кнопка "Создать класс" не заметна | +10 сек | Кнопка должна быть яркой, с иконкой + |
| Первое сохранение тормозит из-за бэкенда (> 500 мс) | +5 сек | Оптимизация Neo4j, асинхронное сохранение с optimistic UI |

## Метод измерения

### Новички

1. Подготовить аккаунт с уже созданной пустой онтологией или автоматически открыть демо-проект.
2. Дать задание: "Создайте класс «Автомобиль» без родителя, с описанием «Транспортное средство»".
3. Засечь время от момента появления главного экрана после входа до появления класса в дереве.
4. В зачёт идёт медиана по 5-7 пользователям.

### Опытные

1. Playwright-скрипт имитирует эксперта.
2. Скрипт открывает проект, нажимает "Создать класс", заполняет label, оставляет родителя по умолчанию и нажимает "Сохранить".
3. Замеряются чистые операции без случайных задержек.

## Определение готовности для MVP

`time-to-first-task` входит в определение готовности MVP.

- Новички: 1.5 минуты (90 секунд) после авторизации.
- Опытные: 20 секунд после авторизации.
- При превышении red-порога UI возвращается на доработку.
- Метрика проверяется юзабилити-тестами и автоматическими прогонами Playwright.

## Время освоения интерфейса

Освоение интерфейса означает, что пользователь без чтения документации способен выполнить базовый набор действий: создать или отредактировать класс, найти элемент, открыть карточку, сохранить изменение и понять статус результата.

| Группа | Целевое время | Допустимое (yellow) | Критичное (red) |
|--------|---------------|---------------------|------------------|
| Бизнес-пользователь | 30 минут | 60 минут | > 2 часов |
| Инженер знаний | 15 минут | 30 минут | > 60 минут |

---

## Метод измерения освоения интерфейса

1. Пользователь начинает после авторизации и без предварительного чтения документации.
2. Модератор выдаёт сценарий: создать или отредактировать класс, найти элемент, открыть карточку, сохранить изменение и объяснить по UI, успешно ли оно применилось.
3. Время измеряется от появления главного экрана до успешного завершения всех базовых действий.
4. Для бизнес-пользователей и инженеров знаний метрики считаются отдельно.
5. В зачёт идёт медиана по группе пользователей.

---

## Определение готовности по обучаемости интерфейса

- Бизнес-пользователь осваивает базовый сценарий за 30 минут target, 60 минут yellow, red при превышении 2 часов.
- Инженер знаний осваивает базовый сценарий за 15 минут target, 30 минут yellow, red при превышении 60 минут.
- При red-результате интерфейс возвращается на доработку: навигация, заметность основных действий, тексты статусов и подсказки.
