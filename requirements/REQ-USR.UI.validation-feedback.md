# Отображение результатов валидации в экране предпросмотра

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.validation-feedback |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P0 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.2 матрицы качества M2 |

---

## Назначение

Отображать результаты валидации в экране предпросмотра с чётким разделением на блокирующие ошибки и информационные предупреждения.

## Требование

Результаты валидации отображаются в двух секциях:
- 🔴 **Блокирующие ошибки** (красный цвет, иконка ❌) — онтология не может быть сохранена.
- 🟡 **Информационные предупреждения** (жёлтый цвет, иконка ⚠️) — онтология может быть сохранена.

Каждая запись содержит: описание, местоположение, предложение по исправлению.

## Критерии приёмки

1. Блокирующие ошибки и информационные предупреждения отображаются в разных секциях.
2. Блокирующие ошибки — красный цвет и иконка ❌.
3. Информационные предупреждения — жёлтый цвет и иконка ⚠️.
4. Кнопка «Продолжить» недоступна при наличии блокирующих ошибок.
5. Кнопка «Продолжить» доступна при наличии только предупреждений.
6. Время отображения результатов ≤ 100 мс.
