# Интерактивное исправление ошибок валидации

| Атрибут | Значение |
|---------|----------|
| **ID** | REQ-USR.UI.validation-fix |
| **Уровень** | USR |
| **Атрибут качества** | Usability |
| **Приоритет** | P1 |
| **Статус** | ЧЕРНОВИК |
| **Источник** | Уточнение стейкхолдера по вопросу 2.2 матрицы качества M2 |

---

## Назначение

Предоставить пользователю возможность исправлять ошибки валидации непосредственно в экране предпросмотра без возврата к исходному NL-описанию.

## Требование

Для каждого типа ошибки доступно интерактивное действие по исправлению:

| Тип ошибки | Действие |
|------------|----------|
| Невалидный IRI | Редактирование в текстовом поле с валидацией в реальном времени |
| Циклическая иерархия | Удаление одной из связей (выбор из вариантов) |
| Дубликат IRI | Переименование с предложением альтернативы |
| Отсутствующий класс в ссылке | Создание класса-заглушки или исправление ссылки |
| Отсутствующий label | Добавление через текстовое поле |
| Некорректный тип данных | Выбор корректного типа из выпадающего списка |

## Критерии приёмки

1. Для каждой ошибки доступно действие по исправлению.
2. При исправлении ошибки валидация перезапускается автоматически.
3. Пользователь может исправить несколько ошибок одновременно.
4. Исправления сохраняются в истории изменений (коммит).
5. Время ответа на исправление ≤ 500 мс.
