## Назначение

Обеспечить визуальную индикацию текущей LLM-политики в интерфейсе AI-функций, чтобы пользователь понимал, куда направляются данные онтологии.

## Требование

В интерфейсе AI-функций (NL→OWL, NL-режим запросов, панель AI-подсказок) отображается индикатор текущей LLM-политики.

**Индикация для SaaS:**

| Уровень | Внешние LLM? | Иконка | Цвет | Текст подсказки |
|---------|-------------|--------|------|-----------------|
| Public | Да (по политике) | 🌐 | Зелёный | «Public онтология — данные отправляются [provider_name]» |
| Internal | Нет (по умолчанию) | 🔒 | Синий | «Internal онтология — внешние LLM заблокированы. Администратор может разрешить.» |
| Internal | Да (админ разрешил) | ⚠️ | Жёлтый | «Internal онтология — внешние LLM разрешены администратором. Данные отправляются [provider_name].» |
| Private | Нет (по умолчанию) | 🔐 | Красный | «Private онтология — внешние LLM заблокированы. Администратор может разрешить.» |
| Private | Да (админ разрешил) | ⚠️ | Жёлтый | «Private онтология — внешние LLM разрешены администратором. Данные отправляются [provider_name].» |

**Индикация для On-premise:**

| Все уровни | Иконка | Цвет | Текст подсказки |
|-----------|--------|------|-----------------|
| Любой | 🏠 | Серый | «On-premise — используется локальная LLM. Данные не покидают периметр.» |

**Размещение:** индикатор отображается в верхней части панели AI-функций, рядом с заголовком или селектором языка запроса.

## Критерии приёмки

1. Индикатор виден во всех AI-интерфейсах (NL→OWL, NL-режим, подсказки).
2. Индикатор показывает статус и используемого провайдера.
3. При наведении — tooltip с подробной информацией.
4. При переключении между онтологиями индикатор обновляется.
5. Для Internal/Private с административным разрешением — жёлтый цвет и иконка предупреждения.
6. Цвета и иконки проходят accessibility-проверку (WCAG 2.1 AA contrast).
