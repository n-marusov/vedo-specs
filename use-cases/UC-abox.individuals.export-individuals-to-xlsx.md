### UC-abox.individuals.export-individuals-to-xlsx: Экспортировать индивидов в XLSX
**Актор:** Инженер знаний  
**Приоритет:** P1 (планируется)  
**Ключевая функция:** F4.10 — Экспорт индивидов  
**Канал:** GUI/API  

**Описание:** Экспорт выбранных индивидов с настраиваемыми колонками (какие свойства включить).
**Основной поток:**
1. Пользователь открывает список индивидов класса.
2. Выбирает набор индивидов и колонки для выгрузки.
3. Система формирует экспортный файл.
4. Пользователь скачивает файл.
**Постусловия:** Экспорт с выбранными полями выполнен.
**Источник требований:** `human/artifacts/requirements/REQ-USR.UI.abox-editor.md`
