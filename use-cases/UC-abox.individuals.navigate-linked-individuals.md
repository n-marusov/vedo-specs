### UC-abox.individuals.navigate-linked-individuals: Переходить к связанным индивидам
**Актор:** Инженер знаний  
**Приоритет:** P1 (планируется)  
**Ключевая функция:** F4.11 — Переход по ссылке  
**Канал:** GUI  

**Описание:** Быстрый переход от значения ссылочного свойства к карточке связанного индивида.
**Основной поток:**
1. Пользователь открывает карточку индивида.
2. Выбирает ссылочное свойство.
3. Выполняет переход к связанному индивиду.
4. Система открывает карточку целевого индивида.
**Постусловия:** Пользователь перешел к связанному индивиду без ручного поиска.
**Источник требований:** `human/artifacts/requirements/REQ-USR.UI.abox-editor.md`
