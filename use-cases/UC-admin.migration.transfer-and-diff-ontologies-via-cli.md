### UC-admin.migration.transfer-and-diff-ontologies-via-cli: Переносить и сравнивать онтологии через `vedo-cli`
**Акторы:** Администратор онтологий, ИТ-архитектор  
**Приоритет:** P1 (высокий)  
**Ключевая функция:** F9.4 — Экспорт/импорт/diff онтологий между окружениями  

**Описание:** Экспорт, импорт и сравнение онтологий между окружениями без воздействия на production.
**Основной поток:**
1. Администратор выполняет `vedo-cli ontology export --env production --format turtle --canonical`.
2. `vedo-cli` экспортирует TBox в canonical Turtle.
3. Администратор загружает файл в staging через `vedo-cli ontology import`.
4. Выполняет `vedo-cli ontology diff` для сравнения production/staging или двух версий ontology artifact.
5. Результат diff используется для проверки корректности миграции или подготовки изменений.
**Альтернативные потоки:**
- А1: Проверка импорта завершилась ошибкой — `vedo-cli` показывает ошибки SHACL/OWL/domain-range validation.
- А2: Diff содержит неожиданные удаления — изменение блокируется до явного подтверждения.
**Постусловия:** Онтология перенесена в целевое окружение или различия явно показаны администратору.
