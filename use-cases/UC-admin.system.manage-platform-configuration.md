### UC-admin.system.manage-platform-configuration: Управлять системой
**Акторы:** Администратор, DevOps, ИТ-архитектор  
**Приоритет:** P1 (высокий)  
**Ключевая функция:** F9.1 — Backup/restore (административный контур)  

**Описание:** Администрирование платформы.
**Основной поток (точки доступа):**
1. Администратор создаёт точку доступа (изолированную онтологию)
2. Указывает префикс, корневой элемент
3. Привязывает хранилища (Neo4j, PostgreSQL)
**Основной поток (хранилища):**
1. Администратор настраивает физическое хранилище
2. Указывает тип (Fuseki, PostgreSQL, MongoDB)
3. Привязывает классы к хранилищу (TBox → Neo4j, ABox → PostgreSQL)
4. Настраивает маппинг свойств на столбцы
**Основной поток (квоты):**
1. Администратор устанавливает лимиты:
   - Максимальный размер хранилища (GB)
   - Количество классов/индивидов
   - Количество коммитов для auto-prune
2. Система отслеживает превышение лимитов
**Альтернативный поток (бэкапы):**
1. Администратор настраивает политику бэкапов
2. Система выполняет резервное копирование:
   - Репликация Git-репозитория
   - Snapshots PostgreSQL
   - Архивирование LFS-объектов
**Постусловия:** Система сконфигурирована
