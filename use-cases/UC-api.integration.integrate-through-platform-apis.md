### UC-api.integration.integrate-through-platform-apis: Интегрироваться через API
**Актор:** Разработчик  
**Приоритет:** P1 (высокий)  
**Ключевая функция:** F6.1, F6.2, F6.3 — REST API, аутентификация, webhooks  

**Описание:** Программный доступ к функциям VEDO Core.
**Основной поток:**
1. Разработчик получает JWT-токен через Keycloak
2. Формирует HTTP-запрос к API Gateway
3. Указывает Bearer-токен в заголовке Authorization
4. API Gateway валидирует токен
5. Маршрутизирует запрос к соответствующему сервису
6. Сервис обрабатывает запрос (CRUD, SPARQL, коммиты)
7. Возвращает ответ в JSON
**Доступные API:**
- REST API — для отраслевых приложений
- GraphQL — для фронтенда
- SPARQL endpoint — для семантических запросов
- Webhooks — для событий интеграции
**Альтернативный поток (вебхуки):**
1. Разработчик настраивает webhook-подписку
2. При наступлении события (create/update/delete) система отправляет POST
3. Внешняя система обрабатывает уведомление
**Постусловия:** Внешняя система успешно интегрирована
