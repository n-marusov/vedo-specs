### UC-browse.graph.view-ontology-graph-with-pagination: Просматривать граф онтологии с пагинацией
**Акторы:** Инженер знаний, Аналитик  
**Приоритет:** P0 (критичный)  
**Ключевая функция:** F1.2, F1.3 — Пагинация/ленивая загрузка и детализация узла  

**Описание:** Пользователь просматривает граф онтологии в 2D или 3D. Система загружает начальную сцену и подгружает связи, свойства и дочерние элементы порциями, чтобы крупная онтология не загружалась целиком.

**Основной поток:**
1. Пользователь открывает экран визуализации графа.
2. Система загружает корневые классы или классы по поисковому запросу.
3. Пользователь кликает по узлу.
4. Система запрашивает дочерние классы, родительские классы и исходящие связи через навигационный API.
5. Система отображает полученную порцию узлов и связей в графе.
6. Пользователь прокручивает список связей или раскрывает следующий уровень.
7. Система использует cursor pagination и запрашивает следующую страницу по `after`.
8. Пользователь наводит курсор или кликает по узлу.
9. Система подгружает детали и динамические свойства узла.

**Альтернативные потоки:**
- Превышен depth limit или query complexity — система возвращает ошибку и предлагает уменьшить глубину, сузить типы связей или уменьшить размер страницы.
- Запрошено более N элементов без пагинации — система отклоняет запрос и требует использовать cursor pagination.

**Постусловия:** Пользователь получил порционный интерактивный обзор графа без полной загрузки онтологии.
