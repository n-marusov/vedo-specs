### UC-browse.public.view-published-ontology: Просматривать опубликованную онтологию без авторизации
**Акторы:** Аналитик данных, Внешний партнёр, Разработчик
**Приоритет:** P1 (высокий)
**Ключевая функция:** F11.1, F11.2, F11.3 — Публичный просмотр, навигация, поиск

**Описание:** Внешний пользователь просматривает опубликованную онтологию без создания аккаунта VEDO Core.

**Основной поток:**
1. Пользователь открывает публичную ссылку на опубликованную онтологию.
2. Система отображает Browse UI: навигация по классам, свойствам и связям в 2D/3D.
3. Пользователь навигирует по онтологии без авторизации.
4. Пользователь выполняет полнотекстовый поиск по элементам онтологии.

**Альтернативные потоки:**
- А1: Онтология не найдена или публикация отозвана — система отображает сообщение об ошибке.

**Постусловия:** Пользователь просмотрел структуру и содержимое опубликованной онтологии.
