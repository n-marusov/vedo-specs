### UC-browse.search.search-ontology-elements: Искать элементы
**Актор:** Аналитик, Инженер знаний  
**Приоритет:** P0 (критичный)  
**Ключевая функция:** F1.4, F2.6, F4.7 — Поиск зависимостей, сущностей и индивидов  

**Описание:** Поиск классов, свойств и индивидов.
**Основной поток (быстрый поиск):**
1. Пользователь вводит текст в строку поиска
2. Система ищет по наименованиям (rdfs:label) и идентификаторам
3. Отображает выпадающий список результатов
4. Пользователь выбирает элемент → переход к карточке
**Основной поток (параметрический поиск):**
1. Пользователь выбирает класс для поиска индивидов
2. Заполняет значения свойств для фильтрации
3. Система выполняет запрос к хранилищу
4. Отображает таблицу результатов
5. Пользователь настраивает отображаемые столбцы
6. Экспортирует результаты в Excel
**Альтернативный поток (каскадный поиск):**
1. Пользователь получает результаты первого поиска
2. Нажимает "Использовать в поиске других объектов"
3. Выбирает свойство-ссылку
4. Система ищет связанные объекты
**Постусловия:** Найдены релевантные элементы
