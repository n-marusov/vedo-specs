### UC-browse.tree.view-ontology-tree-and-graph: Просматривать онтологию
**Акторы:** Инженер знаний, Аналитик  
**Приоритет:** P0 (критичный)  
**Ключевая функция:** F1.1, F1.3 — 2D/3D навигация и детализация узла  

**Описание:** Визуализация и навигация по структуре онтологии.
**Основной поток (дерево классов):**
1. Пользователь открывает левую панель
2. Видит иерархию классов в виде дерева
3. Раскрывает/сворачивает узлы
4. Ищет класс по наименованию (фильтрация в реальном времени)
**Основной поток (граф):**
1. Пользователь открывает визуализацию графа
2. Система загружает данные из Neo4j
3. Отображает узлы (классы, свойства, индивиды) и связи
4. Пользователь управляет:
   - Zoom, pan
   - Глубиной отображения (1-10 уровней)
   - Фильтрацией по типу узлов
5. При клике на узел — открывает карточку элемента
**Расширения:**
- 3D-режим (опционально, для сложных онтологий)
- Полнотекстовый поиск по аннотациям и наименованиям
**Постусловия:** Пользователь получил визуальное представление онтологии
