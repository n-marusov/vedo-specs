### UC-editor.classes.manage-class-lifecycle: Управлять классами
**Актор:** Инженер знаний  
**Приоритет:** P0 (критичный)  
**Ключевая функция:** F2.1.1, F2.1.2, F2.1.3, F2.1.4, F2.1.5 — Управление классами  

**Описание:** Полный цикл управления классами включает: создание, редактирование, удаление, просмотр иерархии (subClassOf), drag-n-drop для изменения родителя, поиск и фильтрацию по дереву классов.
**Основной поток (создание):**
1. Пользователь выбирает родительский класс или корень
2. Нажимает "Создать класс"
3. Вводит наименование (rdfs:label), описание (rdfs:comment)
4. Система автоматически генерирует ID (транслитерация, CamelCase)
5. Система поддерживает множественное наследование (несколько родителей)
6. Система валидирует OWL 2 DL (циклы, непротиворечивость)
7. Система сохраняет в Neo4j
8. Обновляет граф в реальном времени
**Основной поток (редактирование):**
1. Пользователь выбирает класс
2. Перетаскивание в дереве классов изменяет иерархию
3. Пользователь изменяет наименование, описание, флаги (abstract, deprecated)
4. Система обновляет зависимости (потомки наследуют изменения)
**Основной поток (удаление):**
1. Пользователь выбирает класс
2. Система проверяет наличие индивидов
3. Система проверяет ссылки других классов
4. Пользователь подтверждает (мягкое удаление с archive=true или жёсткое)
5. Система удаляет и обновляет граф
**Альтернативные потоки:**
- А1: Циклическое наследование — блокировка
- А2: Удаление с зависимостями — предупреждение, каскад или отмена
**Постусловия:** Класс создан/изменён/удалён, граф обновлён
