### UC-editor.classes.manage-data-quality-rules: Контролировать качество данных
**Актор:** Инженер знаний, ИТ-архитектор  
**Приоритет:** P1 (высокий)  
**Ключевая функция:** F2 — В vision.md нет более низкой декомпозиции для SHACL quality rules  

**Описание:** Управление качеством данных через правила SHACL.
**Основной поток:**
1. Пользователь конструирует SHACL-правило через визуальный конструктор:
   - Выбирает класс-мишень
   - Добавляет условия (свойство + оператор + значение)
   - Объединяет условия операторами (AND, OR)
2. Устанавливает уровень проверки:
   - Обязательное (блокирует сохранение)
   - Предупреждение (только уведомление)
3. Сохраняет правило
4. Система применяет правило ко всем объектам класса
5. При нарушении — создаёт объект-результат (shacl:ValidationResult)
**Альтернативный поток (поиск дубликатов):**
1. Пользователь настраивает правило поиска дубликатов
2. Указывает ключевые атрибуты (например, ИНН)
3. Система находит пары дубликатов
4. Пользователь объединяет их, выбирая основную запись
**Постусловия:** Правило сохранено, нарушения выявлены
