### UC-editor.classes.validate-ontology-with-shacl: Валидировать онтологию
**Актор:** Инженер знаний, ИТ-архитектор  
**Приоритет:** P1 (высокий)  
**Ключевая функция:** F2 — В vision.md нет более низкой декомпозиции для OWL/SHACL-валидации  

**Описание:** Проверка онтологии на соответствие OWL 2 DL и бизнес-правилам.
**Основной поток:**
1. Пользователь открывает панель валидации
2. Выбирает класс для проверки
3. Нажимает "Проверить"
4. Система запускает валидацию:
   - Синтаксис OWL
   - SHACL-ограничения
5. Система отображает отчёт:
   - Нарушенные правила
   - Объекты с ошибками
6. При клике на ошибку — переход к элементу
**Альтернативный поток (автоматическая валидация):**
1. Пользователь сохраняет изменение
2. Система автоматически проверяет затронутые правила
3. При нарушении обязательного правила — блокирует сохранение
**Постусловия:** Выявлены нарушения или система подтвердила корректность
