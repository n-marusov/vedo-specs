### UC-editor.properties.manage-ontology-annotations: Управлять аннотациями
**Актор:** Инженер знаний  
**Приоритет:** P1 (высокий)  
**Ключевая функция:** F2.4 — Управление аннотациями  

**Описание:** Добавление метаданных к классам, свойствам и индивидам.
**Основной поток (стандартные аннотации):**
1. Пользователь выбирает элемент онтологии
2. Заполняет rdfs:label (наименование)
3. Заполняет rdfs:comment (описание)
4. При необходимости указывает rdfs:seeAlso (внешние ссылки)
**Основной поток (пользовательские аннотации):**
1. Пользователь создаёт AnnotationProperty (через UC-editor.properties.manage-property-lifecycle)
2. Свойство автоматически появляется в формах редактирования
3. Пользователь заполняет значение
**Альтернативный поток (многоязычность):**
1. Пользователь переключает язык контента
2. Вводит значения label/comment на выбранном языке
3. Система сохраняет с языковым тегом
**Постусловия:** Аннотации сохранены, доступны в интерфейсе и API
