### UC-editor.properties.manage-property-lifecycle: Управлять свойствами
**Актор:** Инженер знаний  
**Приоритет:** P0 (критичный)  
**Ключевая функция:** F2.2, F2.3 — Управление ObjectProperty и DatatypeProperty  

**Описание:** Создание и редактирование DatatypeProperty и ObjectProperty.
**Основной поток:**
1. Пользователь выбирает класс (domain) для свойства
2. Выбирает тип: DatatypeProperty или ObjectProperty
3. Заполняет:
   - Наименование и описание
   - Domain (класс(ы)-носители, может быть несколько)
   - Range (XSD-тип для DatatypeProperty, класс(ы) для ObjectProperty)
4. Для ObjectProperty:
   - Указывает характеристики (транзитивность, симметричность, функциональность)
   - Указывает инверсное свойство (inverseOf)
5. Устанавливает кардинальность (minCardinality, maxCardinality)
6. Система валидирует (существование domain/range, совместимость типов)
7. Система сохраняет свойство, связывая с domain
8. Свойство наследуется всеми подклассами domain
**Альтернативные потоки:**
- А1: Domain из нескольких классов — через объединение (unionOf)
- А2: Range из нескольких классов — через объединение или пересечение
**Постусловия:** Свойство создано/изменено, наследуется подклассами
