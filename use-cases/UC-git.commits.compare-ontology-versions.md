### UC-git.commits.compare-ontology-versions: Сравнивать версии
**Актор:** Инженер знаний  
**Приоритет:** P2 (средний)  
**Ключевая функция:** F3.5 — Сравнение версий (Semantic Diff)  

**Описание:** Визуальное сравнение двух версий онтологии.
**Основной поток:**
1. Пользователь открывает панель сравнения
2. Выбирает младшую и старшую версии
3. Система загружает дельту из PostgreSQL
4. Отображает изменения по категориям:
   - Классы (добавленные, удалённые, изменённые)
   - Свойства
   - Индивиды
5. Пользователь фильтрует по типу изменений
6. При выборе элемента показывает детали изменений
**Постусловия:** Пользователь получил визуальное представление изменений
