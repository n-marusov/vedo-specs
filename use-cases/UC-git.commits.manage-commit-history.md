### UC-git.commits.manage-commit-history: Управлять версиями
**Актор:** Инженер знаний  
**Приоритет:** P1 (высокий)  
**Ключевая функция:** F3.1, F3.4, F3.6 — Коммиты, история, откат  

**Описание:** Git-подобное версионирование онтологии.
**Основной поток (коммит):**
1. Пользователь нажимает "Зафиксировать изменения"
2. Система показывает diff изменений (семантический, на уровне сущностей)
3. Пользователь вводит сообщение коммита
4. Система вычисляет хэш SHA-256
5. Сохраняет коммит с дельтой в PostgreSQL (JSONB)
6. Публикует событие в RabbitMQ
**Вывод:** Коммит создан, история обновлена
**Основной поток (откат):**
1. Пользователь выбирает коммит в истории
2. Нажимает "Откатить"
3. Система создаёт новый коммит с инвертированным diff
4. Обновляет активную ветку
**Основной поток (сравнение):**
1. Пользователь выбирает два коммита или ветки
2. Система отображает визуальный diff:
   - Добавленные узлы (зелёный)
   - Удалённые узлы (красный)
   - Изменённые атрибуты (жёлтый)
**Постусловия:** История изменений сохранена, возможен откат
