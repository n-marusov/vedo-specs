### UC-io.forms.configure-import-form-templates: Настраивать шаблоны форм импорта
**Акторы:** Инженер знаний, ИТ-архитектор  
**Приоритет:** P2 (планируется)  
**Ключевая функция:** F8.5 — Конструктор форм  
**Канал:** GUI  

**Описание:** Настройка шаблонов форм для последующего импорта данных в онтологию.
**Основной поток:**
1. Пользователь открывает конструктор форм импорта.
2. Настраивает поля и маппинг на свойства онтологии.
3. Сохраняет шаблон формы.
4. Использует шаблон при импорте.
**Постусловия:** Шаблон формы импорта создан и доступен для повторного использования.
**Источник требований:** `human/artifacts/vision.md` (F8.5)
