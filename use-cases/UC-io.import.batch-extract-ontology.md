### UC-io.import.batch-extract-ontology: Пакетное извлечение онтологии из нескольких документов
**Акторы:** Аналитик, Инженер знаний  
**Приоритет:** P2 (планируется)  
**Ключевая функция:** F14.7 — Пакетная загрузка документов  
**Канал:** GUI

**Описание:** Пользователь загружает несколько документов (разных форматов) и VEDO Hub объединяет результаты в единую онтологию с дедупликацией.

**Основной поток:**
1. Пользователь нажимает «Пакетная загрузка» на странице онтологии.
2. Система отображает интерфейс множественной загрузки файлов.
3. Пользователь выбирает несколько файлов (до 10).
4. Система загружает каждый файл в document-extractor:
   - Каждый файл обрабатывается последовательно.
   - Для каждого файла LLM генерирует sequence.
5. Система объединяет все sequence в один:
   - Автоматическая дедупликация сущностей по IRI/id.
   - При конфликте (разные label для одного id) — отмечает для пользователя.
6. Система отображает объединённый preview с группировкой по файлам-источникам.
7. Пользователь просматривает, редактирует и подтверждает импорт.
8. Система применяет sequence через ApplySequence (атомарно).

**Альтернативный поток (ошибка в одном файле):**
- 5a. Один из файлов не удалось обработать.
- Система продолжает обработку остальных файлов.
- В preview показывает: «Файл document2.pdf: ошибка обработки».
- Пользователь может повторить обработку только этого файла.

**Постусловия:** Все сущности из загруженных документов добавлены в онтологию. Создан коммит с перечислением всех файлов-источников.

**Источник требований:** `specs/vision.md` (F14.7)
