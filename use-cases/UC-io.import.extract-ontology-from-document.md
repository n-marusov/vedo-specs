### UC-io.import.extract-ontology-from-document: Извлечь онтологию из загружаемого документа
**Акторы:** Аналитик, Инженер знаний, Бизнес-пользователь  
**Приоритет:** P1 (планируется)  
**Ключевая функция:** F14.6 — Извлечение онтологии из текстовых документов  
**Канал:** GUI

**Описание:** Пользователь загружает файл (MD, TXT, PDF, DOCX, JSON, XML, CSV, XLSX) и VEDO Hub автоматически извлекает OWL-онтологию с помощью LLM. Пользователь просматривает результат, вносит правки и подтверждает импорт.

**Основной поток:**
1. Пользователь открывает онтологию и нажимает «Загрузить документ».
2. Система отображает диалог загрузки с drag-n-drop зоной.
3. Пользователь выбирает файл (или перетаскивает) и выбирает стратегию импорта (merge/replace/version).
4. Система загружает файл в document-extractor service:
   - Определяет формат и извлекает текст/структуру.
   - Отправляет содержимое LLM-провайдеру.
   - LLM возвращает sequence операций (классы, свойства, связи, иерархия).
   - Система валидирует sequence.
5. Система отображает preview: список шагов с возможность включения/исключения и inline-редактирования.
6. Пользователь просматривает результат, при необходимости редактирует шаги.
7. Пользователь нажимает «Подтвердить импорт».
8. Система отправляет sequence в ontology-service через gRPC ApplySequence:
   - ontology-service выполняет все шаги в одной Neo4j транзакции.
   - Создаётся коммит в versioning-service.
   - Исходный файл прикрепляется к коммиту как артефакт.
9. Система отображает уведомление об успешном импорте с количеством созданных сущностей.

**Альтернативный поток (ошибка LLM):**
- 4a. LLM возвращает невалидный sequence.
- Система повторяет запрос до 3 раз с уточняющим промптом.
- Если все попытки неудачны — сообщение пользователю: «Не удалось извлечь онтологию из документа. Попробуйте упростить содержимое.»

**Альтернативный поток (конфликт):**
- 5a. Sequence содержит классы, уже существующие в онтологии.
- Preview отмечает такие шаги предупреждением жёлтым цветом.
- Пользователь может исключить эти шаги или оставить (skipped at import).

**Постусловия:** Онтология обновлена (новые классы, свойства, связи добавлены). Создан коммит. Исходный документ доступен как артефакт коммита.

**Источник требований:** `specs/vision.md` (F14.6)
