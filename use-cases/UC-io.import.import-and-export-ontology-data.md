### UC-io.import.import-and-export-ontology-data: Обмениваться данными
**Акторы:** Инженер знаний, ИТ-архитектор, Разработчик  
**Приоритет:** P0 (критичный)  
**Ключевая функция:** F8.1, F8.3, F8.4 — Импорт/экспорт в XLSX, OWL, XML  

**Описание:** Импорт и экспорт онтологий в стандартных форматах.
**Основной поток (импорт):**
1. Пользователь выбирает файл (Turtle, RDF/XML, OWL)
2. Система парсит формат
3. Валидирует на соответствие OWL 2 DL
4. Предлагает стратегию импорта:
   - Замена (replace)
   - Слияние (merge)
   - Новая версия (create new version)
5. Импортирует в Neo4j через Ontology Service
6. Создаёт коммит с дельтой изменений
**Основной поток (экспорт):**
1. Пользователь выбирает формат экспорта
2. Указывает ветку или коммит
3. Система генерирует канонический Turtle (стабильный diff для Git)
4. Предлагает скачать файл
5. Опционально: Push в удалённый Git-репозиторий
**Альтернативный поток (массовый импорт через Excel):**
1. Пользователь выгружает шаблон для класса
2. Заполняет данные в Excel
3. Загружает файл
4. Система обрабатывает, возвращает отчёт с ошибками
**Постусловия:** Данные импортированы/экспортированы
