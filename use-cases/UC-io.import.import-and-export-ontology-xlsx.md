### UC-io.import.import-and-export-ontology-xlsx: Импортировать и экспортировать онтологию в XLSX
**Акторы:** Инженер знаний, Администратор онтологий  
**Приоритет:** P1 (планируется)  
**Ключевая функция:** F8.1 — Импорт/экспорт xlsx  
**Канал:** GUI/API  

**Описание:** Обмен данными онтологии в табличном формате XLSX.
**Основной поток:**
1. Пользователь выбирает сценарий import/export XLSX.
2. Система применяет схему маппинга колонок к сущностям/свойствам.
3. Система выполняет импорт или формирует экспортный файл.
4. Пользователь получает отчет о результате.
**Постусловия:** Табличный обмен данными выполнен.
**Источник требований:** `human/artifacts/vision.md` (F8.1)
