### UC-io.import.import-structured-data: Импортировать структурированные данные как онтологию
**Акторы:** Бизнес-аналитик, Инженер знаний  
**Приоритет:** P1 (планируется)  
**Ключевая функция:** F14.4 — Импорт из структурированных данных → OWL  
**Канал:** GUI

**Описание:** Пользователь загружает файл структурированных данных (XLSX, CSV, JSON, XML) и система преобразует его в OWL-онтологию.

**Основной поток:**
1. Пользователь открывает онтологию и нажимает «Импорт структурированных данных».
2. Система отображает диалог загрузки с выбором формата.
3. Пользователь выбирает файл:
   - Для XLSX/CSV: система определяет колонки и предлагает маппинг (какая колонка → класс, родитель, свойство, тип).
   - Для JSON: система показывает структуру ключей.
   - Для XML: система показывает теги и атрибуты.
4. Пользователь подтверждает маппинг (или использует автоматический).
5. Система отправляет данные в LLM для генерации OWL-онтологии.
6. Система отображает preview с возможностью редактирования.
7. Пользователь подтверждает импорт.
8. Система применяет sequence через ApplySequence.

**Постусловия:** Данные из структурированного файла преобразованы в онтологию. Создан коммит.

**Источник требований:** `specs/vision.md` (F14.4)
