### UC-io.publish.publish-ontology-snapshot: Публиковать снэпшот онтологии
**Акторы:** Инженер знаний, ИТ-архитектор
**Приоритет:** P1 (высокий)
**Ключевая функция:** F11.1 — Публичный просмотр (через публикацию снэпшота)

**Описание:** Создание и публикация снэпшота онтологии для внешнего просмотра через 2D/3D навигацию.

**Основной поток (оптимистичный интерфейс):**
1. Инженер знаний открывает раздел "Публикации" в интерфейсе.
2. Нажимает "Опубликовать".
3. Система сразу отображает статус "Публикация выполняется..." и возвращает управление пользователю.
4. Система копирует текущее состояние TBox + ABox из основного Neo4j в отдельный read-only инстанс.
5. При успехе публикация становится доступна по ссылке.
6. При ошибке инженеру высылается уведомление о неудачной публикации.

**Альтернативные потоки:**
- А1: Копирование завершилось с ошибкой — пользователь видит уведомление об ошибке, может повторить попытку.
- А2: Обновление существующей публикации — создаётся новая копия, старая версия сохраняется в истории.

**Постусловия:** Онтология опубликована и доступна по публичной ссылке, либо инженер получил уведомление об ошибке.
