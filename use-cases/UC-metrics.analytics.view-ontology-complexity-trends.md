### UC-metrics.analytics.view-ontology-complexity-trends: Просматривать графики сложности онтологии
**Акторы:** ИТ-архитектор, Инженер знаний  
**Приоритет:** P2  
**Ключевая функция:** F7.2 — Графики сложности  
**Канал:** GUI/API  

**Описание:** Просмотр метрик сложности онтологии: глубина иерархии, коэффициент ветвления, orphan/deep классы.
**Основной поток:**
1. Пользователь открывает раздел аналитики онтологии.
2. Система загружает исторические метрики сложности.
3. Пользователь выбирает период и фильтры.
4. Система отображает графики и агрегаты.
**Постусловия:** Пользователь получил тренды сложности по онтологии.
**Источник требований:** `human/artifacts/requirements/REQ-NFR.OPS.metrics.md`
