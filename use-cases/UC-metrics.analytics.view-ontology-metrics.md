### UC-metrics.analytics.view-ontology-metrics: Анализировать метрики
**Актор:** Инженер знаний  
**Приоритет:** P2 (средний)  
**Ключевая функция:** F7.1 — Счетчики элементов онтологии  

**Описание:** Просмотр статистики по онтологии.
**Основной поток:**
1. Пользователь открывает пункт меню "Метрика"
2. Система отображает:
   - Количество классов
   - Количество ObjectProperty
   - Количество DatatypeProperty
   - Количество индивидов (опционально)
3. Система обновляет метрики при изменении онтологии
**Постусловия:** Пользователь получил количественную оценку онтологии
