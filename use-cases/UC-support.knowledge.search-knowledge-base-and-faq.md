### UC-support.knowledge.search-knowledge-base-and-faq: Искать ответы в базе знаний и FAQ
**Акторы:** Пользователь, Инженер поддержки  
**Приоритет:** P1  
**Ключевая функция:** F12.2 — База знаний (Knowledge Base)  
**Канал:** Portal  

**Описание:** Поиск и использование статей базы знаний и FAQ для решения типовых задач без обращения в поддержку.
**Основной поток:**
1. Пользователь открывает базу знаний.
2. Выполняет поиск по ключевым терминам.
3. Открывает релевантную инструкцию/FAQ.
4. Выполняет шаги из документации.
**Постусловия:** Пользователь получает self-service решение по документации.
**Источник требований:** `human/artifacts/requirements/REQ-NFR.DOC.documentation-training.md`, `human/artifacts/vision.md` (F12.2)
