### UC-support.tickets.create-and-track-support-ticket: Создавать и отслеживать тикеты поддержки
**Акторы:** Авторизованный пользователь, Инженер поддержки  
**Приоритет:** P0  
**Ключевая функция:** F12.1 — Портал поддержки (Service Desk)  
**Канал:** Portal/API  

**Описание:** Создание тикета через форму поддержки в VEDO GUI, автоматическая классификация и отслеживание пользовательской проекции статуса. Операторские действия выполняются через `vedo-cli`.
**Основной поток:**
1. Пользователь открывает форму: сайдбар -> Помощь -> Поддержка.
2. Заполняет тему, описание, категорию, severity и при необходимости добавляет файлы.
3. Система обогащает тикет метаданными и присваивает приоритет.
4. Тикет проходит статусы New -> In Review -> In Progress -> Resolved -> Closed.
5. Пользователь отслеживает статус в VEDO GUI в виде: получен / в работе / отклонён / решён.
**Постусловия:** Тикет зарегистрирован в едином бэкенде; пользователь видит только пользовательскую проекцию статуса без внутренних ссылок на GitLab.
**Источник требований:** `human/artifacts/requirements/REQ-FUN.INTEGRATION.ticket-management.md` (T-01..T-08, T-15, T-38..T-42, T-48..T-50)
