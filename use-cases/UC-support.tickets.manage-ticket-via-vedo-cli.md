### UC-support.tickets.manage-ticket-via-vedo-cli: Управлять тикетами поддержки через vedo-cli
**Акторы:** Инженер поддержки, DevOps/SRE  
**Приоритет:** P1  
**Ключевая функция:** F12.1 — Операторский workflow тикетов  
**Канал:** CLI  

**Описание:** Оператор выполняет lifecycle-операции по тикетам через `vedo-cli` без использования админского GUI в VEDO.
**Основной поток:**
1. Инженер поддержки получает список тикетов через `vedo-cli ticket list`.
2. Просматривает детали через `vedo-cli ticket get`.
3. Добавляет комментарий или меняет статус через `vedo-cli ticket comment|close|reopen|update`.
4. Действия пишутся в единый аудит.
**Постусловия:** Тикет обновлён в едином бэкенде, изменение отражено в аудите и пользовательской проекции статуса.
**Источник требований:** `human/artifacts/requirements/REQ-FUN.INTEGRATION.ticket-management.md` (T-43..T-47, T-50)
