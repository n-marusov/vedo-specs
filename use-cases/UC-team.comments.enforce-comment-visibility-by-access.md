### UC-team.comments.enforce-comment-visibility-by-access: Применять доступ к комментариям по правам на сущность
**Акторы:** Viewer, Editor, Maintainer, Owner  
**Приоритет:** P0  
**Ключевая функция:** F5.4 — Доступность для команды  
**Канал:** API/GUI  

**Описание:** Ограничения доступа к комментариям наследуются от прав доступа к соответствующей сущности.
**Основной поток:**
1. Пользователь запрашивает комментарии к сущности.
2. Система проверяет права на сущность.
3. Система возвращает только допустимые комментарии и действия.
4. При недостатке прав система отклоняет доступ.
**Постусловия:** Видимость комментариев соответствует модели доступа.
**Источник требований:** `human/artifacts/requirements/REQ-FUN.INTEGRATION.collaboration.md` (C-06)
