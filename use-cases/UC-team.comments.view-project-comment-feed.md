### UC-team.comments.view-project-comment-feed: Просматривать общую ленту комментариев проекта
**Акторы:** Инженер знаний, Maintainer, Администратор  
**Приоритет:** P1  
**Ключевая функция:** F5.2 — Лента обсуждений (чат)  
**Канал:** GUI/WebSocket  

**Описание:** Просмотр всех комментариев по проекту в единой ленте, отсортированной по времени, с фильтрацией по сущности, автору и статусу.
**Основной поток:**
1. Пользователь открывает ленту комментариев проекта.
2. Система загружает комментарии в хронологическом порядке.
3. Пользователь применяет фильтры (сущность, автор, статус).
4. Система обновляет ленту и показывает новые сообщения в реальном времени.
**Постусловия:** Пользователь получил полный контекст обсуждений проекта.
**Источник требований:** `human/artifacts/requirements/REQ-FUN.INTEGRATION.collaboration.md` (C-12, C-13, C-14)
