# E2E-commenting.flow: Комментирование и уведомления

```gherkin
@E2E-commenting.flow @e2e @collaboration @P1
Feature: E2E-commenting.flow Комментирование и уведомления

  Scenario: Инженер знаний комментирует класс и получает уведомления
    Given пользователь аутентифицирован как "Инженер знаний"
    And открыта онтология "University" на ветке "main"
    And существует класс "Person" в дереве классов
    When пользователь выделяет класс "Person"
    And открывает панель комментариев
    And добавляет комментарий "Need to add address property" для класса "Person"
    Then комментарий отображается в ленте активности онтологии
    And в ленте присутствует запись "Need to add address property"
    When другой пользователь добавляет ответ "Agreed, adding address field" на комментарий
    Then ответ отображается под исходным комментарием
    And автор исходного комментария получает уведомление об ответе
    When пользователь обновляет ленту активности
    Then лента содержит все комментарии и ответы в хронологическом порядке
```
