# US-a11y.auth.authentication: Прохождение аутентификации с клавиатуры

```gherkin
@US-a11y.auth.authentication @A12 @P0 @accessibility @auth
Feature: US-a11y.auth.authentication Прохождение аутентификации с клавиатуры

  Background:
    Given пользователь использует keyboard-only навигацию

  Scenario: Пользователь входит через OAuth с клавиатуры
    When пользователь фокусируется на кнопке входа через OAuth
    And активирует её через Enter
    Then страница аутентификации провайдера полностью доступна с клавиатуры
    And после успешного входа пользователь возвращается в приложение

  Scenario: Пользователь восстанавливает пароль с клавиатуры
    When пользователь активирует ссылку восстановления пароля
    Then форма восстановления полностью доступна с клавиатуры
    And сообщения об ошибках доступны для screen reader
```
