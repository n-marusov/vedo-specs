# US-browse.graph.paginated: Просмотр графа онтологии с пагинацией и ленивой подгрузкой

```gherkin
@US-browse.graph.paginated @UC-browse.graph.view-ontology-graph-with-pagination @P0 @ontology @graph @pagination
Feature: US-browse.graph.paginated Просмотр графа онтологии с пагинацией и ленивой подгрузкой

  Background:
    Given пользователь аутентифицирован как "Инженер знаний" или "Аналитик"
    And открыта крупная онтология

  Scenario: Пользователь просматривает граф без полной загрузки онтологии
    Given граф онтологии содержит больше элементов, чем можно загрузить за один запрос
    When пользователь открывает экран визуализации графа онтологии
    Then система загружает начальную сцену с корневыми классами или результатами запроса
    When пользователь раскрывает узел графа
    Then система подгружает связанные элементы в пределах разрешённой глубины
    And система использует пагинацию по курсору для дочерних элементов и связей
    And интерфейс остаётся отзывчивым без полной загрузки графа

  Scenario: Система ограничивает слишком сложный запрос графа
    Given пользователь запросил глубину или размер страницы выше допустимого лимита
    When система обрабатывает запрос графа
    Then система отклоняет запрос с объяснением причины
    And предлагает уменьшить глубину, сузить типы связей или использовать пагинацию
```
