# US-editor.rules.deduplicate: Поиск и объединение дубликатов индивидов по ИНН

```gherkin
@US-editor.rules.deduplicate @UC-editor.classes.manage-data-quality-rules @P1 @quality @duplicate
Feature: US-editor.rules.deduplicate Поиск и объединение дубликатов индивидов по ИНН

  Background:
    Given пользователь аутентифицирован как "Разработчик"
    And открыта онтология "TestOntology"

  Scenario: Разработчик находит и объединяет дубликаты индивидов
    Given существуют индивиды класса "Person"
      | ИНН          | ФИО         |
      | 123456789012 | Иванов Иван |
      | 123456789012 | Иванов И.И. |
      | 987654321098 | Петров Пётр |
    When пользователь запускает поиск дубликатов по правилу "по ИНН"
    Then система находит пару дубликатов "Иванов Иван" и "Иванов И.И."
    When пользователь выбирает основную запись "Иванов Иван"
    And подтверждает объединение
    Then индивид "Иванов И.И." удалён
    And индивид "Иванов Иван" содержит объединённые данные
```
