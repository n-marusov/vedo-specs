# US-io.publish.snapshot: Публикация снэпшота онтологии

```gherkin
@US-io.publish.snapshot @UC-io.publish.publish-ontology-snapshot @P1 @publish @snapshot
Feature: US-io.publish.snapshot Публикация снэпшота онтологии

  Background:
    Given пользователь аутентифицирован как "Инженер знаний"
    And открыта онтология "ProductOntology"

  Scenario: Инженер знаний публикует снэпшот с оптимистичным интерфейсом
    When пользователь нажимает "Опубликовать"
    Then система сразу отображает статус "Публикация выполняется..."
    And управление возвращается пользователю
    When публикация завершается успешно
    Then публикация становится доступна по ссылке
    And статус обновляется на "Опубликовано"

  Scenario: При ошибке публикации инженер получает уведомление
    When пользователь нажимает "Опубликовать"
    Then система сразу отображает статус "Публикация выполняется..."
    When публикация завершается с ошибкой
    Then инженер получает уведомление об ошибке
    And пользователь может повторить попытку

  Scenario: Обновление существующей публикации
    Given существует опубликованная версия "v1.0"
    When пользователь нажимает "Опубликовать новую версию"
    Then создаётся новая копия в read-only хранилище
    And предыдущая версия "v1.0" сохраняется в истории
```
